## 2. Правильная категоризация болей

Старая моя таблица (8 болей через буквы A-H) была частично натянута на рамку, заданную предыдущим разговором о CEO-инструменте. Правильная карта — **5 категорий по фактическому позиционированию игроков:**

### Категория 1 — Employee Clone
**Боль:** «Критичная экспертиза заперта в голове конкретного человека, доступна только в его рабочее время и только пока он есть».

Закрывает три use-case в одной категории:
- Continuity при уходе (Viven, Sensay).
- Доступ 24/7 без эксперта (MyPersonas, Cloneable).
- Разгрузка эксперта от повторяющихся вопросов (Eightfold Digital Twin).

**Подкатегории по принципу:**
- Horizontal employee clone (Viven) — для всех ролей в компании.
- Vertical employee clone (Cloneable) — для одной отрасли с дорогими экспертами.
- Multimodal (MyPersonas) — видео + голос + текст для онбординга.

### Категория 2 — Company Brain как memory substrate
**Боль:** «AI-агенты компании не имеют общего контекста, каждая модель = голый интеллект без памяти о компании».

Это **AI-to-AI инфраструктурная боль**, не human-to-human. Sentra манифестирует: **«Memory is state, not service»** — память это состояние компании, а не сервис, к которому ходят.

**Игроки:** Sentra, Hyper, flowscope (как сервис), Notion+Claude Managed Agents (как distribution-play).

### Категория 3 — Enterprise Knowledge Graph (старая школа)
**Боль:** «У enterprise нет объектной модели бизнеса. Excel + wiki + email = хаос».

**Игроки:** Palantir Foundry. В РФ — фрагментарно через госконтракты.

### Категория 4 — RAG-чат-бот по корпусу (Company Brain «лайт»)
**Боль:** «Сотрудники не находят ответы в своей wiki/чатах/документах».

**Игроки:** Glean, Guru, Dust (отчасти), Metamentor (РФ), TEAMLY (РФ), Сбер, Яндекс, MTS AI.

### Категория 5 — Meeting Memory (наша текущая категория)
**Боль:** «Встречи не оставляют следа, обсуждаем то же самое».

**Игроки:** Granola, Otter, Fireflies, mymeet.ai (РФ), Z.

## 3. Главные сдвиги в понимании

### 3a. Memory substrate для AI-агентов — это другая боль
Раньше формулировал «знание распылено, не найти» — это Категория 4. Но **Категория 2 (Sentra-style)** — это не про поиск, это про **общий контекст между AI-агентами**. Компания будущего = компания с AI-агентами; им нужен общий substrate, иначе каждый агент — голая модель.

### 3b. Notion + Claude Managed Agents — главная угроза снизу
30M+ пользователей Notion **автоматически получают memory layer**. Это distribution-play, который убивает все стартапы Категории 4 (RAG-чат-бот по корпусу) и угрожает Категории 2.

### 3c. YC явно выделил «Company Brain» в RFS лета 2026
Это значит, осенью 2026 будет волна стартапов в Категории 2. **Окно закрывается за 6-12 месяцев.**

### 3d. В РФ ни одна из «продвинутых» категорий не закрыта
- Категория 1 (Employee Clone) — пусто.
- Категория 2 (Memory substrate) — пусто.
- Категория 3 (Knowledge Graph) — фрагментарно (госконтракты).
- Категория 4 (RAG-чат-бот) — занято: Metamentor (выручка 61.5M руб), TEAMLY, Сбер, Яндекс.
- Категория 5 (Meeting Memory) — частично: mymeet.ai, Z.

### 3e. Три двери для Z (через линзу новых данных)
1. **Расширение в Категорию 1 (Employee Clone) через AI-встречи.** Технический моат: записи встреч + отдельные дорожки = идеальный материал для клона. Viven из переписок такого качества не получит.
2. **Расширение в Категорию 2 (Memory substrate) с MCP-наружу.** Z как memory layer, к которому ходят AI-агенты компании через MCP. Инфраструктурная игра.
3. **Удержание в Категории 5 + узкая вертикаль** (как Cloneable для встреч). AI-встречи + клон эксперта для одной отрасли (юрфирмы / медицина / промышленный консалтинг).

Категория 4 в РФ занята — туда лезть не стоит. Категория 3 — не наш масштаб.

## 5. Карта рынка в одной фразе

> На западе сформировалось **три явные категории**: клоны людей (Viven, Cloneable, MyPersonas), memory substrate всей компании (Sentra, Hyper), enterprise knowledge graph старой школы (Palantir).
> В России **ни одна из этих категорий не закрыта продуктом** — есть только базы знаний (Metamentor, TEAMLY) и платформенные стеки (Яндекс, Сбер).
> **Окно открыто, но закрывается быстро** — у YC уже отдельная категория «Company Brain» в RFS лета 2026.
