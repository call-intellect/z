## Часть 5. Приоритет разработки — параллельно, две команды

### Структура команды (минимум)

- **2-3 backend разработчика** — параллельно ведут:
  - Доделки 21 sub-ТЗ Кора v2 (α-фаза доделки, β-фаза социальные специалисты, γ-фаза мышление, δ-фаза оркестрация)
  - Phase 1 трекера (модели + REST + Webhooks + Ingest в knowledge-core)
- **1-2 frontend разработчика** — параллельно ведут:
  - UI новых sub-ТЗ Кора v2 (γ-2 Concierge UI, β-8 COO Dashboard, спецстраницы для специалистов)
  - Phase 2 трекера (mobile-first, Cmd+K, чат-в-задаче, PWA)
- **1-2 RN-разработчика** — отдельная команда нативной мобилки (Expo, 10-12 нед параллельно)
- **0.3-0.5 DevOps** — инфра, мониторинг, релизы, миграции
- **0.3 дизайнер** — адаптации UI под мобайл, спецэкраны

### Приоритеты первой волны (первые 6 недель)

В таком порядке (для каждой колонки видно зависимости):

1. **Phase 1 трекера** (модели + REST + Ingest) — фундамент всего
2. **α-2 signalType расширение** — добавление 15+ новых signalType (task_*, help_*, thanks_*, plan_item, blocker, и т.д.) — нужно для ingest задач в knowledge-core
3. **β-8 PersonalRelation + COO Dashboard + DailyCheckIn** — критично для AI-COO ценности
4. **α-5 DialogService + Cache** — нужен для Cmd+K (Phase 2 трекера) и AI Q&A (Phase 3 трекера)
5. **γ-2 Concierge Agent** — реализует Cmd+K в трекере
6. **Подготовка RN-проекта** (Expo + auth + базовая навигация) — параллельно

### Полный календарь (приблизительно)

```
Месяц 1: Wave 1 — фундамент (Phase 1 трекера + α-2 + RN preparation + старт Кора v2 доделок)
Месяц 2-3: Wave 2 — UI + AI + Feeds + Gamification + продолжение Кора v2
Месяц 4: Wave 3 — РФ + Импорт + COO Dashboard + Helpfulness Agent
Месяц 5: Стабилизация, тесты, релиз публичной беты веб-версии
Месяц 6-7: Мобилка v1 выходит в магазины
```

**Итого до публичного запуска ~5-6 месяцев календарного времени.**

## Часть 6. Архитектурный принцип «трекер = источник для второго мозга»

**Подтверждено.** Каждое событие в трекере + переписка коллег в чатах задач + голосовые сообщения → `RawEvent` через `IngestService` (новый TrackerAdapter в `modules/ingest/adapters/tracker/`) → `core.raw-events` очередь → `block-ingest.worker` → `IdeaBlock` с правильным signalType → специалисты Слоя 3 → карточки + дашборды + AI-чат компании.

Без этого принципа AI-COO будет слепым относительно реальной работы команды (видит только встречи и чек-ины, не видит повседневную работу в задачах). Принцип неизменяемый.

### Что это даёт на практике

- **Insights Radar** (β-4) сам замечает «у Иванова 5 задач в blocked за неделю — это паттерн».
- **Decisions Registry** (β-3) видит обсуждения решений в комментариях задач.
- **Knowledge Clone** (β-2) собирает что человек знает из реальной работы (а не только из встреч).
- **COO Dashboard** (β-8) имеет данные для дневных и недельных сводок.
- **Helpfulness Agent** (Specialist 3.8) видит кто кому помогает в комментариях.

### Приватность

- Переписка в задачах считается **рабочей коммуникацией** — попадает в граф знаний организации (как и встречи).
- Личные сообщения сотрудников вне платформы — НЕ обрабатываются.
- Каждый сотрудник имеет страницу `/me/clone` и `/me/social-contribution` — видит что AI про него знает, может пометить как ошибку.

## Часть 7. Цены — отдельная тема, не фиксируем

**Решение:** конкретные цифры тарифов **не зафиксированы в sub-ТЗ**. В коде и документации оставляем placeholder. Цены утвердим **отдельно** перед публичным запуском.

### Что это означает для разработки

- В `entitlements` и `tariffs` моделях — поля под `priceRub`, `priceUsd` остаются (готовы к заполнению), но в seed-данных не указываются.
- Структура тарифов **остаётся**: Free + Pro + Business + Enterprise (4 уровня).
- Структура фич по тарифам **остаётся** (см. зонтичный документ, gamification-and-motivation, tracker-as-entry-wedge — там описано что в каком тарифе).
- В лендинге блок «Цены» — заглушка «Цены утверждаются».
- При публичном запуске — отдельный sub-ТЗ для финализации pricing.

### Что обсудить отдельно

Когда дойдём до ценообразования (отдельная встреча):
- Какие лимиты в Free? (юзеры, AI-операции/мес, проекты)
- Точные цифры Pro / Business / Enterprise
- Скидки за годовую оплату
- Льготы для НКО / стартапов / образовательных
- Триал-периоды
- Способы оплаты (карта, счёт, договор для Enterprise)
