# Dzen Content Research

Скилл для глубокого контентного исследования в Дзене. Не «погуглить и посмотреть», а пройти полный цикл: поиск → отбор хитов → чтение → разбор крючков → синтез.

## Когда применять

- Пользователь хочет понять, **что заходит** в Дзене по конкретной теме/нише.
- Нужен разбор: **какие заголовки, форматы, углы** дают много прочтений.
- Positioning / messaging / контент-стратегия: ищем готовые «крючки», которые уже доказали работоспособность.
- Анализ конкурентов в контенте.

## Когда НЕ применять

- Просто открыть одну ссылку и посмотреть — хватит прямого `mcp__playwright__browser_navigate` + `browser_snapshot`.
- Поиск по YouTube / VK / Telegram — это другие платформы и другие инструменты (vidIQ для YouTube уже есть).
- Если пользователь явно просит «только список без анализа» — пропусти Stage 3 и 4.

## Технические предпосылки

- Playwright MCP должен быть запущен (`mcp__playwright__browser_*`).
- **Используй `browser_evaluate` с JS, а не парсинг `browser_snapshot`** — Дзен рендерит через React, accessibility-дерево даёт мусор без классов, JS позволяет получить структурированный JSON.
- Если упёрся в капчу Яндекса — **не пытайся обходить**, сообщи пользователю и останови выполнение. Капча = end of run.

## ⚠ Критические находки из реального прогона (2026-05-23)

1. **У статей в выдаче поиска просмотры скрыты!** Дзен показывает счётчик прочтений только у видео. У статей в карточке выдачи — только дата («1 месяц назад»). **Это значит:** отбирать «залетевших» по выдаче статей **невозможно**. Нужно сначала зайти в каждую статью, на странице публикации просмотры есть.
2. **Контейнер контента статьи:** `div[class*="article-render__container"]`. НЕ `<article>` (он есть, но пустой).
3. **Статья по умолчанию свёрнута.** Перед извлечением текста нужно кликнуть кнопку «Показать ещё» (через `browser_evaluate`, ищи кнопку, чей `innerText` начинается с этой фразы).
4. **Header статьи в `body.innerText`** идёт в формате: `Канал \n N подписчиков \n Подписаться \n Title \n Date \n Views \n N мин`. Парсится регуляркой после «Подписаться».
5. **Реакции (лайки) в кнопках с пустым innerText кроме цифры** — собирай через `Array.from(document.querySelectorAll('button')).map(b => b.innerText.trim()).filter(t => /^\d+$/.test(t))`.

## Параметры запуска (уточни у пользователя, если не указано)

| Параметр | Default | Когда менять |
|---|---|---|
| `query` | (обязательный) | — |
| `min_views` | 10 000 | Узкая ниша — снизить до 1 000 / 5 000 |
| `top_n` | 5 | Если «залетевших» больше — возьми больше |
| `mode` | `full` | `quick` = только Stage 1, без чтения и разбора |
| `content_type` | `all` | `articles` — только статьи (`&type_filter=article%2Cbrief`); `videos` — только видео |

## Stage 1 — Discovery (поиск и отбор)

1. **Открой выдачу:**
   ```
   https://dzen.ru/search?query=<URL-encoded query>
   ```
   Если нужны только статьи — добавь `&type_filter=article%2Cbrief`.

2. **Сделай snapshot.** Каждая карточка в выдаче — это `article "Карточка этажа"`. Из неё достаём:
   - **Заголовок** — из текста ссылки на статью/видео
   - **URL** — `/url:` ссылки (нормализуй: убери `?rid=...&referrer_clid=...&secdata=...` хвост, оставь `https://dzen.ru/a/<id>` или `https://dzen.ru/video/watch/<id>`)
   - **Канал** — текст внутри `generic "<имя канала>"`
   - **URL канала** — из ссылки «Аватар канала»
   - **Метрика** — текст вида `8919 смотрели · 9 месяцев назад` или `188,9 тыс смотрели · 1 год назад` или `175 читали · 1 год назад`
   - **Тип** — видео (есть длительность `47:30`) или статья (есть превью-текст)
   - **Превью** (только для статей) — первый абзац

3. **Парсинг счётчика:**
   - `8919 смотрели` → 8 919 (видео)
   - `37,8 тыс смотрели` → 37 800
   - `188,9 тыс смотрели` → 188 900
   - `1,2 млн смотрели` → 1 200 000
   - `175 читали` → 175 (статья)
   - **нет цифры** → 0 (свежий пост, ещё не накопил, или Дзен скрыл)

4. **Подгрузи больше выдачи:** прокрути вниз 2–3 раза (`browser_press_key` с `End`, либо `browser_evaluate` с `window.scrollTo(0, document.body.scrollHeight)`), каждый раз делая короткий `browser_wait_for(time=2)` для подгрузки.

5. **Отбор «залетевших»:**
   - Все с `views >= min_views`, отсортированные по убыванию.
   - Если их меньше `top_n` — добери до `top_n` по убыванию просмотров (даже если ниже порога).
   - Если «залетевших» вообще нет (всё <1000) — сообщи пользователю и спроси: снижать порог или менять запрос.
   - **Для статей (article, не video) — Дзен скрывает счётчик в выдаче.** Отбирай по: (а) свежесть (≤3 мес), (б) «крючковость» заголовка (контр-нарратив, цифры, метафора, провокация), (в) авторитетные каналы (>1к подписчиков). Реальные просмотры/лайки получишь только зайдя внутрь на Stage 2.

6. **Сохрани промежуточный результат** в `plans/analysis/YYYY-MM-DD-dzen-<query-slug>/00-index.md`:

   ```markdown
   # Dzen content research: «<query>»

   **Дата:** YYYY-MM-DD
   **Запрос:** «<query>»
   **URL выдачи:** https://dzen.ru/search?query=...
   **Параметры:** min_views=10000, top_n=5, mode=full
   **Найдено карточек:** N (из них «залетевших» по порогу: M)

   ## Топ для глубокого разбора

   | # | Заголовок | Канал | Просмотры | Дата | Тип | URL |
   |---|---|---|---|---|---|---|
   | 01 | ... | ... | 188 900 | 1 год | статья | https://dzen.ru/a/... |
   | 02 | ... | ... | 37 800 | 2 года | видео | https://dzen.ru/video/watch/... |

   ## Вся выдача (для контекста)

   | Заголовок | Канал | Просмотры | Тип |
   |---|---|---|---|
   | ... |
   ```

   `query-slug` — транслит запроса, нижний регистр, дефисы вместо пробелов и спецсимволов. Пример: «AI операционный директор» → `ai-operacionnyy-direktor`.

   Если режим `quick` — на этом останавливаемся, отдаём пользователю файл и завершаемся.

## Stage 2 — Deep Read (чтение каждой залетевшей)

Для каждой статьи из топа:

1. **Открой URL** через `browser_navigate`.
2. **Раскрой свёрнутый контент:** через `browser_evaluate` найди и кликни кнопку, чей `innerText.trim().startsWith('Показать ещё')`. Без этого в `article-render__container` будет только начало статьи.
3. **Один большой `browser_evaluate`** для извлечения всего: title, meta-header (дата/просмотры/мин), подписчики, full_text из `div[class*="article-render__container"]` (обходи `h2, h3, h4, p, li, blockquote`, конвертируй в markdown-разметку).
4. **Извлеки:**
   - **Точное число прочтений** (на странице статьи цифра обычно точнее, чем в выдаче)
   - **Лайки** — если отображаются (кнопка с цифрой возле «нравится»/палец вверх)
   - **Комментарии** — счётчик под статьёй (если есть)
   - **Подписчиков канала** — открой URL канала отдельным шагом, на главной канала есть «N подписчиков»
   - **Полный текст** — все абзацы, подзаголовки, списки, цитаты, врезки. Сохрани разметку (h2/h3, маркеры списка).
   - **Картинки** — описание превью / основных изображений (alt-текст и расположение)
   - **Длина** — посчитай примерное количество слов и время чтения (1 минута = ~150 слов на русском)
   - **Дата публикации** — точная если показана, иначе относительная как есть

4. **Если страница не открылась / отдала пустоту** — попробуй ещё раз через `browser_wait_for(time=3)`. Если повторно — пропусти статью, отметь в отчёте `[не удалось загрузить]` и двигайся дальше.

5. **Сохрани в** `plans/analysis/YYYY-MM-DD-dzen-<query-slug>/<NN>-<channel-slug>-<short-title-slug>.md`:

   ```markdown
   ---
   url: https://dzen.ru/a/...
   channel: Метод Сократа
   channel_url: https://dzen.ru/metodsokrata
   type: article | video
   views: 188900
   likes: 1234
   comments: 87
   subscribers: 245000
   date: 2025-08-15
   words: 2400
   reading_min: 16
   ---

   # <Заголовок>

   ## Лид
   <первый абзац как есть>

   ## Полный текст
   <всё содержимое со структурой>

   ## Анализ
   (заполняется на Stage 3)
   ```

## Stage 3 — Анализ крючков (по каждой статье)

В блок `## Анализ` каждого файла дозаполни по чек-листу:

### 1. Хук заголовка
Какой тип крючка использован? Бывают:
- **Вопрос** («Почему X не работает?»)
- **Провокация / контр-нарратив** («X — это миф»)
- **Число / список** («7 признаков того, что…»)
- **Личный опыт** («Я работал в X 10 лет и понял…»)
- **Шок / парадокс** («X убивает Y, и вот как»)
- **Curiosity gap** («То, что узнаешь, изменит…»)
- **Авторитет / разоблачение** («Что скрывают X»)
- **Угроза / FOMO** («Не упусти X пока не поздно»)
- **Польза / how-to** («Как сделать X за Y»)

Зафиксируй: **тип** + **почему именно этот хук сработал в этой нише**.

### 2. Лид (первые 3–5 строк)
- Какая боль / обещание / интрига введена сразу?
- Есть ли «крючок продолжения чтения» (open loop)?
- Прямое обращение к читателю («ты», «вы»)?

### 3. Структура
- Лонгрид (>1500 слов) / средний (500–1500) / короткий (<500)
- Есть ли подзаголовки? Сколько разделов?
- Маркированные списки? Цитаты? Врезки?
- Как разбит ритм (короткие абзацы / длинные)?

### 4. Тон
- Экспертный / личный / провокационный / эмпатичный / разговорный / новостной
- Однородный или меняется по тексту?

### 5. Угол / формат
- Личная история / разбор кейса / список / how-to / контр-нарратив / экспертный обзор / новость с комментарием / интервью / FAQ

### 6. Целевая эмоция
- На какую эмоцию давит: страх / любопытство / гнев / удивление / надежда / зависть / умиление / гордость / ностальгия

### 7. CTA / финал
- Вопрос читателю в конце? Призыв подписаться? Ссылка на другую статью? Просто закончили?

### 8. Картинка-превью
- Что изображено (если удалось снять)? Лицо? Скриншот? Инфографика? Эмоциональное?

### 9. Гипотеза «почему зашло»
Твоя интерпретация в **2–4 предложениях**: почему именно эта статья собрала N прочтений. Что в ней есть, чего нет в средней статье по теме. Что повторяется у других хитов из этой же выборки (cross-reference).

## ⚠ Если по итогам прогона пишешь готовый контент (статью, лендинг, пост) для Z/Кора

**ОБЯЗАТЕЛЬНО** перед написанием открой и применяй [`second-brain/06_marketing/style-guide.md`](../../../second-brain/06_marketing/style-guide.md):

- **Ноль английских слов** в основном тексте — кроме брендов / компаний / научных терминов с переводом в скобках.
- Все аббревиатуры (KPI, CRM, HR, COO, P&L, SaaS, B2B) — заменять русскими по словарю замен в стайл-гайде.
- Все англицизмы (handover, feedback, фичи, дедлайн, продакт, инсайт, фаундер) — выкорчёвывать.
- Заголовок — на чистом русском, ещё строже основного текста.

Готовые хуки из Stage 4 синтеза тоже на чистом русском — не калькировать с английских образцов.

## Stage 4 — Синтез (один файл на весь прогон)

Создай `plans/analysis/YYYY-MM-DD-dzen-<query-slug>/99-synthesis.md`:

```markdown
# Синтез: что работает в нише «<query>» на Дзене

**Дата:** YYYY-MM-DD
**Проанализировано:** N статей с порогом ≥M прочтений

## 1. Паттерны хуков заголовков
- Топ-3 типа крючков, которые встретились у залетевших (с примерами из выборки)
- Какие хуки НЕ встретились (важно: что нишa не любит)

## 2. Угол / формат
- Какие форматы доминируют (личная история / разбор / список / контр-нарратив)
- Какая длина в среднем работает

## 3. Тон
- Какой тон преобладает у хитов
- Есть ли разница между «средне зашедшими» и «топ-хитами»

## 4. Темы-крючки
- Какие конкретные подтемы / триггеры повторяются («увольнение», «деньги», «секрет», «ошибка»)

## 5. Целевые эмоции
- На каких эмоциях работают хиты

## 6. Что НЕ работает
- Если в выборку попали статьи с малыми просмотрами (для контраста) — что у них общего, чем они проигрывают

## 7. Готовые крючки для своего контента
- 5–10 конкретных шаблонов заголовков, применимых к нашему продукту/позиционированию
- Какие из них честно совпадают с нашим продуктом (Z / Кора — память компании), а какие — соблазн, но мимо позиционирования

## 8. Сырые наблюдения / неожиданности
- Что удивило в процессе разбора (необычные форматы, неожиданные углы, аномалии)
```

## Эталонные сниппеты JS (проверены на практике)

### Stage 1 — извлечь все карточки выдачи (после 2-3 прокруток)
```javascript
() => {
  const cards = document.querySelectorAll('article');
  const results = [];
  cards.forEach((card, i) => {
    const links = card.querySelectorAll('a[href]');
    let titleText = '', articleUrl = '';
    for (const a of links) {
      const txt = (a.textContent || '').trim();
      if (a.href && (a.href.includes('/a/') || a.href.includes('/video/watch/')) && txt.length > titleText.length) {
        titleText = txt;
        articleUrl = a.href;
      }
    }
    const channelLink = card.querySelector('a[href*="dzen.ru/"]:not([href*="/a/"]):not([href*="/video/"])');
    const channelSlug = channelLink ? channelLink.href.split('?')[0].replace('https://dzen.ru/', '') : '';
    let metaText = '';
    const walker = document.createTreeWalker(card, NodeFilter.SHOW_TEXT, null);
    let node;
    while (node = walker.nextNode()) {
      const t = (node.textContent || '').trim();
      if (/(смотрели|читали|назад|мин|тыс|млн|день|неделю|месяц|год|дней)/i.test(t) && t.length < 200 && t.length > metaText.length) {
        metaText = t;
      }
    }
    const hasDuration = card.textContent.match(/\d{1,2}:\d{2}(?::\d{2})?/);
    results.push({ i, title: titleText, url: articleUrl.split('?')[0], channel_slug: channelSlug, meta: metaText, type: hasDuration ? 'video' : 'article' });
  });
  return JSON.stringify(results, null, 2);
}
```

### Stage 2 — извлечь полный текст статьи (после клика «Показать ещё»)
```javascript
() => {
  // Сначала раскрыть
  for (const b of document.querySelectorAll('button, a')) {
    if ((b.innerText || '').trim().startsWith('Показать ещё')) { b.click(); break; }
  }
  const body = document.body.innerText;
  const container = document.querySelector('[class*="article-render__container"]');
  let articleText = '';
  if (container) {
    const blocks = container.querySelectorAll('h2, h3, h4, p, li, blockquote');
    const parts = [];
    blocks.forEach(b => {
      const t = (b.innerText || '').trim();
      if (!t) return;
      const tag = b.tagName.toLowerCase();
      const prefix = {h2:'\n## ',h3:'\n### ',h4:'\n#### ',li:'- ',blockquote:'> '}[tag] || '';
      parts.push(prefix + t);
    });
    articleText = parts.join('\n\n');
  }
  return JSON.stringify({
    h1: (document.querySelector('h1')||{}).innerText || '',
    subs: (body.match(/(\d[\d\s,]*)\s*подписчик/)||['',''])[1],
    meta: (body.match(/Подписаться([\s\S]{0,250})/)||['',''])[1],  // содержит дату, просмотры, мин
    text_length: articleText.length,
    full_text: articleText
  });
}
```

## Что НЕ делать в этом скилле

- НЕ обходить капчу (если упёрлись — стоп, сообщить).
- НЕ копировать тексты статей в чат целиком (только сохранять в файлы).
- НЕ запускать без подтверждения пользователя, если выборка получится огромная (>20 статей в полном режиме = долго и дорого). При >20 спроси: «Сократить до топ-N или продолжать всё?»
- НЕ применять чек-лист Stage 3 механически — если в статье что-то нестандартное (например, нет лида, или это не текст, а длинное видео с одним абзацем описания), отметь это и пропусти неприменимые пункты.
- НЕ заменять этот скилл «парой playwright-вызовов». Если задача звучит как контентный research — иди полный цикл, иначе ценности не будет.
