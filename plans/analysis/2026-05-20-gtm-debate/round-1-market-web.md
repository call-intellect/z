## 2. AI-сервисы для встреч в РФ — свежий срез

### MyMeet.ai
- **Free:** до 5 встреч/мес, авто-транскрипт + summary.
- **Pro:** $19/мес — безлимит, приоритетная транскрипция.
- **Business:** custom, командный доступ.
- **>40 000 пользователей** по собственным данным.
- ARR публично не раскрыт.
- Источники: [mymeet.ai/pricing](https://mymeet.ai/pricing), [Capterra MyMeet.io](https://www.capterra.com/p/10021681/MyMeet-io/), [AIChief review](https://aichief.com/ai-productivity-tools/mymeet-ai/).

### НаВстрече (navstreche.com)
- AI-агент: запись + транскрипт + саммари + анализ ВКС, бот-присоединение.
- Тарифы публично детально не выложены (заявлены «прозрачные», есть тестовый доступ).
- ARR/MAU не раскрыты.
- Источник: [navstreche.com](https://navstreche.com/).

### FollowUp (follow-up.tech)
- AI-протокол + интеграция CRM, поддержка Zoom/Meet/Telemost/Контур.Толк/Teams/Skype.
- Доставка результатов: e-mail, ЛК, Telegram-бот.
- Цены 2026 не публичны.
- Источник: [follow-up.tech](https://follow-up.tech/), [peoplesplace — FollowUp обзор](https://www.peoplesplace.ru/tpost/7imvsdcip1-followup-ai-assistent-dlya-protokolirova).

## 4. Регуляторика

### Реестр отечественного ПО (Минцифры)
- Постановление № 1937 от 28.11.2025 публиковано 08.12.2025, **в силе с 01.03.2026** (часть положений — позже).
- **Критерий «контроль» вместо «владения»**: ≥50% голосов в правообладателе должны принадлежать гражданам РФ / РФ / муниципалитетам.
- **Для SaaS:** проверяется удалённый доступ к серверной части (исходный код + работающая инсталляция).
- **Совместимость с доверенными ОС** — поэтапно: офисный софт — с 01.09.2026, системное ПО / БД / средства разработки / облачные платформы — с 01.01.2027, прикладное ПО + СЗИ — с 01.06.2027, промышленное — с 01.01.2028.
- Процедура: формальная стадия → экспертная стадия.
- Источники: [it-lex — Реестр Минцифры 2026 полный гайд](https://www.it-lex.ru/article/registraciya-v-reestre-rossijskogo-po-mincifry-2026), [Zarlaw — нововведения 2026](https://zarlaw.ru/articles/pravila-vklyucheniya-v-reestr-otechestvennogo-po-i-pak-mintsifry-v-2026-godu-chto-novogo/), [PGPLaw — изменения правил](https://www.pgplaw.ru/analytics-and-brochures/alerts/pravila-vedeniya-reestra-rossiyskogo-po/).

### 152-ФЗ (персональные данные)
- **С 30.05.2025** — **оборотные штрафы за повторные утечки: 1-3% годовой выручки, мин. 20 млн ₽, макс. 500 млн ₽**.
- Штрафы за утечку: 3-5 млн ₽ (1-10 тыс. субъектов), 5-10 млн ₽ (10-100 тыс.), 15-20 млн ₽ (>100 тыс. или биометрия).
- Обработка без согласия: 300 тыс. ₽ → 1,5 млн ₽ (повтор).
- **С 01.09.2025** — согласие на обработку ПДн оформляется **отдельным документом**; штраф за нарушение формы: до 700 тыс. ₽.
- Источники: [Data-Sec — штрафы 2026](https://data-sec.ru/personal-data/fines/), [B-152 — изменения 2025-2026](https://b-152.ru/zakon-o-personalnyh-dannyh-2025), [КонсультантПлюс — новые штрафы](https://www.consultant.ru/legalnews/27142/), [Гарант — согласие с 01.09.2025](https://www.garant.ru/article/1862510/).

### КИИ / ФСТЭК
- **С 01.03.2026** — Приказ ФСТЭК России №117 от 11.04.2025 заменил Приказ №17 (>10 лет в действии). Новые правила аттестации ГИС и значимых объектов КИИ.
- **С 01.09.2025** — ужесточение: на значимых объектах КИИ обязательно ПО из реестра российского ПО.
- ВКС включена ФСТЭК в число технологических приоритетов 2025 г.
- Источники: [Anti-malware — Приказ ФСТЭК №117](https://www.anti-malware.ru/analytics/Technology_Analysis/Information-Security-Legislation-2025), [SecurityMedia — аттестация по правилам 2026](https://securitymedia.org/info/attestatsiya-gis-i-kii-po-novym-pravilam-2026-polnyy-razbor-prikaza-fstek-117.html), [Altirix — проверка ФСТЭК 2025](https://www.altirixgroup.com/blog/kak-projti-proverku-fstek-rossii-po-kii-v-2025-godu/).

⚡ **ИНСАЙТ:** Сочетание оборотных штрафов 152-ФЗ + требования реестра + новый приказ ФСТЭК = **окно для российских ВКС/AI** в крупных корпоратах и B2G; одновременно — **барьер входа** (стоимость комплаенса).

## 8. Бюджеты и средний чек

- **Средний SaaS-бюджет компании среднего сегмента в РФ: ~4 млн ₽/год** (косвенно: 2 млн ₽ интеграции = половина годового SaaS-бюджета). ([vc.ru — 72 из 80 SaaS ниже инфляции](https://vc.ru/services/2913143-pochemu-saas-kompanii-v-rossii-rastut-nizhe-inflyatsii)).
- Тренд: «крупный клиент перестает собирать стек из 10 нишевых, платит **одному вендору пакетом** — коммуникации + облако + приложения + CRM».
- ВКС-сегмент: типовой средний чек на корпоратив за облачный ВКС — **от ~1 100 ₽/мес/компания** (Контур.Толк нижний край) до **5-17 тыс. ₽/мес** (SaluteJazz Beta/вебинары).
- Yandex 360 (комплект Mail + Disk + Telemost + Wiki) — пакетные подписки на сотрудника (точный прайс зависит от размера и промо).

⚡ **ИНСАЙТ:** При среднем SaaS-бюджете SMB ~4 млн ₽/год реалистичный отъёд для Z = **6-15 тыс. ₽/мес** (= 72-180 тыс. ₽/год). На сегмент 700 млн ₽/мес ARR нужно **~5-10 тыс. платящих SMB** или эквивалент в enterprise-чеках.

## 9. Окно возможностей и угрозы 2026

### Окна:
1. **Замещение Microsoft 365 ещё не закончено.** 68% крупных и 45% среднего бизнеса завершают/ведут миграцию; 42% сменивших офис — пришли из Microsoft 365; 43% пользователей Я360 — из Microsoft. ([itweek — замена Zoom](https://itweek.ru/its/article/detail.php?ID=231554), [Obit — российские виртуальные офисы](https://obit.ru/blog/saas/rossiyskie-virtualnye-ofisy-dlya-biznesa-chem-zamenit-microsoft-365/)).
2. **AI-функции в ВКС: 3x рост за 3 года.** ([CNews — количество ВКС с ИИ вырастет в 3 раза](https://www.cnews.ru/reviews/videokonferentssvyaz_2025/articles/kolichestvo_vks_na_osnove_ii_v_blizhajshie)). Категория молодая, дифференциация по типу встречи ещё не занята.
3. **Company Brain — нет российского лейбла.** Sentra/Viven/Hyper набрали $40M+ за 9 месяцев — в РФ свободно.
4. **GigaAM open-source = себестоимость AI у Z может быть ~0.** Большое конкурентное преимущество перед игроками, использующими облачный SaluteSpeech.
5. **152-ФЗ + ФСТЭК + Реестр** делают западные сервисы **юридически не закупаемыми** в B2G и крупном корпорате с КИИ.

### Угрозы:
1. **AI-саммари → commodity.** МТС Линк, VK Звонки, IVA, Контур.Толк, Я360, SaluteJazz — все выкатили. Z должен дифференцироваться **глубиной анализа по типу встречи + памятью**, а не просто «AI-отчётом».
2. **Консолидация рынка ВКС.** MTS Link купил Vinteo. Дальше — потенциально другие. Малому игроку без узкой ниши тяжело.
3. **72 из 80 SaaS в РФ растут ниже инфляции.** Рынок жесток к «среднему» SaaS. Без чёткого позиционирования Z сольётся в «ещё один отечественный ВКС».
4. **B2G / enterprise = долгий цикл + комплаенс.** Реестр Минцифры — обязательная инвестиция; ФСТЭК — отдельный пласт; оборотные штрафы 152-ФЗ требуют DPO и аудита.
5. **Гигиена + GigaChat-снижение цен в 3 раза** — даёт встроенные AI-функции у Сбера и Яндекса фактически бесплатно для их экосистем. Z должен дать **что-то, чего у них нет** (Company Brain, multi-tenant memory, шаблоны по типам встреч).
6. **Реестр Минцифры с 01.09.2026** требует совместимости с доверенной ОС в офисном ПО → если Z позиционируется к юрлицам, нужно закладывать тесты на Astra/RED OS заранее.
