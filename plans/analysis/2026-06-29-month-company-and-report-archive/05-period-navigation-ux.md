# 05 — UX навигации по историческим периодам (добор фичи B)

Закрывает сбойный контур (исходный агент вернул заглушку). Независимый retrieval. Подтверждает рекомендацию синтеза (inline-навигатор + лёгкий архив, default = последний завершённый).

## Паттерны

| # | Паттерн | Следствие для Z | Тег |
|---|---|---|---|
| П1 | **Date stepper** (стрелки ‹ › у подписи периода) — листание на шаг | Довести stepper до дня и недели (шаг = активный ритм); Next **disabled** на последнем завершённом (не листать «в будущее»). Уже работает для месяца. | verified |
| П2 | Подпись периода **кликабельна → календарь** для прыжка на дальнюю дату | Stepper для соседних, календарь за кликом — для «3 недели назад». Для месяца — сетка месяцев года (zoom-out). | triangulated |
| П3 | **Switcher гранулярности** (день/неделя/месяц) отдельно от навигации по времени | Сегмент-контрол ритма держать визуально отдельно от стрелок — не смешивать «сменить масштаб» и «листнуть назад». | triangulated |
| П4 | **Archive/history list** — обратнохронологический список прошлых отчётов | Лёгкий «recent»-список последних завершённых отчётов, клик = прыжок навигатора. Тяжёлую страницу-архив (год→месяц) — позже, как накопится история. | verified |

## Антипаттерны

- Календарь как **единственный** способ дойти до периода (дальние даты — много кликов).
- Блокировка листания назад (пользователь хочет перепроверить).
- Раздельные дропдауны день/месяц/год (лишний interaction cost).
- Смешать «сменить масштаб» и «листнуть период» в один контрол.
- **Пустой экран без объяснения** при отсутствии данных за период.
- Дефолт = текущий незавершённый период (ломает сравнения).
- Мелкие тач-цели стрелок, неоднозначные даты (DD/MM, 2-значный год) — особенно в архиве.

## Рекомендация (подтверждает синтез)

Гибрид **inline-stepper ‹ › + кликабельная подпись→календарь**, БЕЗ отдельной тяжёлой страницы-архива на 1-м этапе. Лёгкий «архив» = компактный список последних завершённых отчётов (recent), клик = прыжок. Switcher ритма — отдельно от стрелок, в шапке (канон BI: навигатор top-right, заголовок слева). Default = последний завершённый период активного ритма + кнопка «К последнему».

**Empty-state «нет данных за период»** — различать два случая:
- «ещё нет ни одного отчёта» (первый запуск) → обучающий empty-state (что это + как наполнить);
- «за этот период пусто, но другие есть» → короткий статус + CTA «Перейти к ближайшему доступному отчёту».
Никогда не оставлять пустоту — читается как «грузится/сломалось».
