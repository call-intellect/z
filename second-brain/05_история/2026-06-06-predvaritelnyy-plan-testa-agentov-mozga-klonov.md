# Предварительный план теста агентов / второго мозга / клонов

## Что было поставлено
Владелец: разобраться, как устроены инструменты тестировщика из соседних сессий
(Playwright + read-only `diag.ts`), и предложить верхнеуровневый план теста
**внутрянки** — как работают агенты (падают/не падают, правильно ли), как
наполняется второй мозг (граф знаний), как создаются клоны. Затем уточнил:
оформить как **предварительный** план, не финальное ТЗ — скоро меняется код по
клонам и по доступу к базе знаний, после чего код надо изучить заново.

## Как решал
- Изучил два инструмента: Playwright (UI на прод-кабинете `meet.crossmark.ru`,
  аккаунт `mazursv39@gmail.com`) и [`backend/scripts/diag.ts`](../../backend/scripts/diag.ts)
  (7 read-only команд trace/report/meetings/logs/chain/llm-calls/call; логин
  `admin@crossmark.ru`, ключи в КОРНЕВОМ `.env`).
- Прочитал ядро: [[../02_architecture/knowledge-core]], [[../02_architecture/ai-agents-map]],
  [[../02_architecture/company-memory-overview]], [[../01_projects/workers-queues]] и
  свежий аудит [plans/analysis/2026-06-04-agent-system-full-audit.md] (критпуть B1–B7).
- Зафиксировал 3 решения владельца (гибрид окружения · снизить пороги + объём ·
  расширить diag) и оформил план: [plans/analysis/2026-06-06-agents-brain-clones-test-plan.md].
- Пометил документ как ПРЕДВАРИТЕЛЬНЫЙ (заголовок + блок-предупреждение + итог),
  добавил строку в [реестр не-сделанного](../04_не-сделано/README.md).
- Коммит `af0beaa0` (только мой новый файл; README с чужой строкой параллельной
  сессии в git не трогал — анти-бандл).

## Что вышло
План создан и запушен в `sergdev`. Прогон НЕ начат — ждём изменений кода
(клоны + доступ к знаниям), потом пересмотр и финал.

## Чему научился
- **Внутрянка второго мозга невидима в UI.** Нет пользовательских страниц для
  блоков/связей/тем (UI тем «вне Фазы 4», org-admin knowledge-debug вырезан из
  клиента). Главный наблюдатель — БД/метрики через `/org-admin/knowledge/*`, а
  текущий `diag` заточен под встречи. → чтобы тестировать граф, diag надо
  расширять командами «снимок графа».
- **Граф гейтится порогами объёма** (связи от 50 canonical-блоков, темы от 100,
  клон роли от ~10 reasoning-блоков, граф сущностей от 3 co-mention). На свежем
  кабинете с одной короткой встречей граф/темы/клоны физически не строятся — это
  порог, не баг (прогон 2 это подтвердил). → для теста нужно снизить пороги
  (B6: 3/5/2/1) + набить объём.
- **Демо «ТехноСтрим» наполнен сидом, не живым конвейером** — годится проверить
  рендер UI наполненного мозга, НЕ «наполняют ли его агенты».
- **Граф строят cron-агенты по расписанию**, а `diag` read-only — крон не дёрнет;
  на стенде нужен ручной запуск воркера/крона.
