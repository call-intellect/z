## Решение

**Имя:** `<value-name>`

**Семантика (1-2 предложения):** что это значит, какой класс высказываний попадает.

**Что говорит «нет»:** перечисли явно, какие близкие значения это НЕ покрывает
и почему. Это самая важная часть — без неё классификатор будет путать соседей.

## Последствия

- **Что меняется в коде:** `SIGNAL_TYPE_VALUES` пополняется, JSON Schema в
  `block-ingest.prompt.ts` обновляется, snapshot-тесты обновляются.
- **Метрики:** появляется новый bucket в `kc_signal_type_distribution{signal_type=...}` —
  первые 7д ожидаем шум, дальше Markov-матрица G.2 должна стабилизироваться.
- **Промпты:** возможно требуется правка system prompt в `block-extraction` —
  отметь явно.
- **Обратная совместимость:** старые IdeaBlock не получают новый тип
  автоматически (бэкфилл — отдельный план, если нужен).
