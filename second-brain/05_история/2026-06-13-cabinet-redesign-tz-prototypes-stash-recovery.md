## 🔴 Git-инцидент и восстановление (главный урок)
Под конец сессии файлы редизайна **исчезли** из рабочего дерева: `Read`/`wc` → «No such file». Диагностика `git reflog`: параллельная сессия (или ручной шаг) сделала `checkout fix/dashboard-500-and-decisions-404 → dev` + `git stash` («WIP правки редизайна кабинета (analysis+tz+prototypes+PNG)»). Локальный коммит `8d93c6c6` (создавший файлы) в `dev` отсутствует → файлы пропали; правки сессии ушли в `stash@{0}`.

**Восстановил без переключения ветки** (чтобы не мешать параллельной сессии на dev): `git show "stash@{0}:<path>" > <path>` для изменённых файлов (ТЗ/архитектура/index.html/design-system.css) + `git show 8d93c6c6:<path>` для неизменённых (mobile.html/_parts/build.mjs/shot-*.png). Проверил по маркерам (15 в ТЗ, 32 светлой темы). Закоммитил на `dev` (`6bf17bf6`) + push — закрепил намертво.

## Чему научился
- **«Движок есть, продюсеры — нет»** — частый паттерн в Z: инфраструктура построена (ActivityFeed: модель+API+realtime+RBAC), но в бою наполнена частично. Перед «достроить UI» грепать реальные вызовы `publish()`/эмиттеры, а не только enum/тесты — иначе оценка объёма врёт (было «лента почти готова» → стало «наполнена 2/8»).
- **Готовые данные контроля** — `Notification.responseStatus`+`status=read` (probe «прочитал-молчит»), `DailyCheckIn.completedAt=null` (пропуск) — фичи «контроль ответов» и «дисциплина чек-инов» = вьюха поверх готового, не стройка.
- **Git с параллельными сессиями** ([[feedback_parallel_sessions_git_check]]): чужой `checkout`+`stash` может молча унести мои незакоммиченные правки и удалить tracked-файлы локального коммита. Восстановление точечно через `git show "stash@{0}:<path>" > <path>` — безопаснее `stash pop`/`checkout` (не трогает ветки/HEAD/stash, не мешает параллельной сессии). **Вывод: при работе в `plans/` коммитить промежуточно чаще, не копить большую untracked-дельту.**
- Светлая тема через переопределение CSS-переменных `[data-theme]` покрывает ~90% за один блок; остаток — тёмные **инлайн**-стили (их CSS не переопределяет), их надо выносить в тема-зависимые классы. Проверять обязательно в браузере, скриншотом.
