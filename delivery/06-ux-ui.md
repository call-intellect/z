# 06 — UX / UI

Этот документ — спецификация пользовательского интерфейса. Полный реестр экранов — в `ui/screens.md`. Полный набор русских строк — в `ui/copy-strings.ru.md`. Голосовой флоу — в `ui/voice-flow.md`.

## Сквозные принципы UI

### 1. Никаких форм с выбором категории

Свободный текст или голос. Никаких выпадающих списков, чекбоксов, тегов, multi-select для пользовательских действий. Классификацию делает AI.

**Исключения** (явные):
- Админка — там стандартные формы, потому что аудитория другая (администраторы).
- Поиск — через диалог с AI, не через UI-фильтры.
- Подтверждения «да/нет/уточнить» в ответ на уточняющий вопрос AI — допустимы, это часть диалога.

### 2. Русский язык в UI обязателен

Все user-facing строки — на простом русском. Глоссарий и реестр — в [13-glossary.md](13-glossary.md) и `ui/copy-strings.ru.md`.

### 3. Streaming везде

Любой длительный ответ (AI, загрузка дашборда, поиск) показывается частями по мере появления.

### 4. Mobile-first

Большинство сотрудников работают с телефона. Все ключевые потоки должны работать на 360x640 минимум. Десктоп — расширение, не приоритет.

### 5. Доступность (WCAG AA)

- Цветовые контрасты — минимум 4.5:1.
- Все интерактивные элементы — клавиатурные.
- Все изображения — `alt`-тексты на русском.
- Скринридеры — `aria-label`.
- Без тёмного паттерна (cookie-стен, скрытых отписок и т.п.).

### 6. Внутренняя кухня скрыта

По умолчанию пользователь не видит:
- Какой агент ответил (CMO/CSO/Strategy и т.п.).
- Какая модель использована (Claude/GPT/локальная).
- Какие инструменты вызывал агент.
- Стоимость запроса в токенах.

Всё это можно включить в настройках «Расширенный режим». По умолчанию — чистый ответ + источники.

### 7. Тон голоса (TOV)

- Уважительный, но не сухой. На «вы».
- Без эмодзи в основных ответах. Эмодзи допустимы в admin-уведомлениях, но не в данных.
- Без восторженности и канцеляризма. Не «успешно создано», а «готово».
- Конкретно. Не «возможно стоит обратить внимание», а «вот что я заметил».

### 8. «Память, не контроль» в каждом экране

В UI запрещены:
- Уведомления-напоминания вида «вы обещали сделать X к Y».
- Блокирующие модалки до подтверждения.
- Push-нотификации о просрочках сотрудников.
- Лидерборды, очки, значки.
- Активный возврат AI «вы 3 недели назад сказали X».

Разрешено:
- Видимая польза после действия пользователя («вы сказали — я узнал и связал с темами A и B»).
- Уведомления о редких системных событиях (только опасные риски, существенные дрейфы стратегии).
- Запрос подтверждения от AI как часть диалога.

## Структура приложения

### Платформы

1. **Веб-приложение** (Next.js) — основной интерфейс.
2. **Telegram-бот** — быстрый ввод и быстрые запросы. Без полноценного дашборда.
3. **Мобильный PWA** (тот же Next.js) — кнопка «добавить на главный экран», offline-первичный ввод с фоновой синхронизацией.
4. **Голосовой клиент в браузере** — кнопка «нажми и говори» в основном UI.

### Экран «Карта»

Смысловая карта компании — визуализация графа знаний.

```
┌─────────────────────────────────────────────┐
│ Смысловая карта                          [⚙]│
├─────────────────────────────────────────────┤
│                                              │
│         ●  ●●                                │
│       ●─●●─●        ●                        │
│       │ │ │       ●─●─●                      │
│       ●─●─●         │                        │
│            ●        ●                        │
│                                              │
│  Перетащи или скажи:                         │
│  «Покажи карту по продажам за неделю»        │
└─────────────────────────────────────────────┘
```

- Узлы = темы, цели, идеи, риски, решения, люди, клиенты.
- Цвет = тип сущности.
- Размер = вес/важность.
- Толщина ребра = confidence связи.
- Time-travel — слайдер «как было N дней назад».
- Кликнул узел — sidebar с детализацией.
- Команда «покажи карту по X» — чат меняет рендер.

Технически: Cytoscape.js + force-directed layout, max 500 узлов на экран. Больше — кластеризация.

### Telegram-бот

Простой интерфейс:
- `/start` — приветствие, link на веб.
- Любое сообщение → дамп (то же что веб «Дамп»).
- `/спросить` или `?` в начале → переключение в режим чата.
- `/обещания` — список.
- `/настроение` — открыть чек-ин.
- Голосовое сообщение → транскрипция → дамп.
- Файл → загружается, обрабатывается.

После любого дампа — короткий feedback («Записал. Вижу 2 сигнала»). Без болтовни.

### Голосовой флоу

См. `ui/voice-flow.md`.

```
1. Пользователь нажимает [🎙] — начинается запись.
2. Streaming в WhisperX через WSS.
3. На экране — частичная транскрипция в реальном времени.
4. Отпустил кнопку — стрим закрывается.
5. Финальная транскрипция показывается (можно отредактировать).
6. Кнопка [Отправить] / [Переписать].
7. После отправки — видимая польза («записал, вижу X»).
```

Поддержка push-to-talk и hands-free (длительная запись). Авто-завершение по тишине 3 сек в hands-free режиме.

## Дизайн-система

### Цвета

Базовые токены (CSS variables):

```css
:root {
  --color-bg-base: #FBFBFB;       /* почти белый */
  --color-bg-elevated: #FFFFFF;
  --color-text-primary: #1A1A1A;
  --color-text-secondary: #555555;
  --color-text-muted: #999999;
  --color-border: #E5E5E5;
  --color-accent: #2D5BFF;        /* основной акцент */
  --color-success: #1F9D55;
  --color-warning: #C28B00;
  --color-danger: #D14545;
  --color-mood-bad: #D14545;
  --color-mood-neutral: #C28B00;
  --color-mood-good: #1F9D55;
}

[data-theme="dark"] {
  --color-bg-base: #131316;
  --color-bg-elevated: #1B1B20;
  --color-text-primary: #F0F0F0;
  --color-text-secondary: #A0A0A0;
  --color-border: #2A2A30;
}
```

Тема — light / dark / auto. Переключение в настройках.

### Типографика

- Основной шрифт: **Inter** (web fallback `system-ui, sans-serif`). Для русского — Inter имеет полную поддержку кириллицы.
- Заголовки: `font-weight: 600`.
- Текст: 16 px на mobile, 15 px на desktop.
- Линейная высота: 1.5 для текста, 1.2 для заголовков.

### Иконки

- **Lucide** (open-source, MIT). Простые контурные.
- Никаких эмодзи в данных, только в системных уведомлениях админу.

### Компоненты

Базируемся на **shadcn/ui** (копия в репо, без npm-зависимости):
- Button, Input, Textarea, Dialog, Popover, Sheet, Toast, Tooltip, Tabs, Card.
- Чат: собственный компонент на базе assistant-ui-паттернов.
- Граф: Cytoscape.js wrapper.
- Графики: Recharts с тёмной/светлой темой.

### Адаптивность

Брейкпоинты:
- `xs: 360`
- `sm: 640`
- `md: 768`
- `lg: 1024`
- `xl: 1280`

Mobile-first: дефолт = `xs`, расширяется к большим.

## Состояния экранов

Каждый экран должен поддерживать состояния:

1. **Загрузка** — skeleton-плейсхолдеры, не спиннеры.
2. **Пустое** — дружелюбный текст + кнопка действия.
3. **Ошибка** — что произошло, что можно сделать.
4. **Streaming** — приходящие токены / постепенное наполнение.
5. **Не аутентифицирован** — редирект на `/login`.
6. **Недостаточно прав (M-20)** — «Этот раздел вам пока не виден» (без раскрытия деталей).

## Что **не** строим в первом релизе

- Drag-and-drop редактор дашборда (фильтры через AI).
- Push-нотификации в браузере (только email-дайджесты + Telegram).
- Видеозвонки внутри приложения.
- Marketplace плагинов / интеграций (у нас фиксированный реестр в M-40).
- Public API для внешних разработчиков (только internal).
