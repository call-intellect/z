# Прототип стенда сотрудника (визуальный эталон)

Статичный HTML-прототип экрана «Мой день» (`/me/stand`), сделанный до реализации как дизайн-образец. Открывать файлы прямо в браузере (`file://…/index.html`) — всё self-contained, стили в `design-system.css` (токены кабинета: oklch, мятный accent, стекло).

## Файлы
| Файл | Что |
|---|---|
| `index.html` | **сам прототип стенда** — обложка-письмо + 4 оси + борд задач (4 колонки) + ленты блокеров/идей, в директорском «стекле». Переключатель тем и навигация сверху |
| `report.html` | отчёт 5 ролевых персон (админ/продажи/продукт/инженер/маркетолог) — боли и что каждая нарисовала |
| `blueprint.html` | человеческим языком: было → стало |
| `data-sources.html` | по каждому виджету — откуда берём данные (`file:line`) |
| `design-system.css` | дизайн-система (копия токенов кабинета) |
| `_report-body.html` | промежуточный фрагмент, из которого собран `report.html` (не рендерится отдельно) |
