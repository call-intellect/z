**Витрина-эталон:** [frontend/app/(design-preview)/redesign/page.tsx](../../frontend/app/(design-preview)/redesign/page.tsx) → URL `/redesign` (без авторизации).
**Аудит «как было»:** [plans/analysis/2026-06-08-dashboards-design-audit/README.md](../analysis/2026-06-08-dashboards-design-audit/README.md).

> **Контекст решения.** Старый дизайн-язык «Нервный центр» (плоский, минт ≤10%, без градиентов/стекла — `DESIGN.md` / `PRODUCT.md`) владельца НЕ устраивает: дашборды «унылые, как Excel». Владелец сознательно сменил вектор на **современный**: объёмные карточки с тенями, градиенты, стекло, свечение, богатая дата-виз — по референсам (см. вложения в чате 2026-06-08). Моё предупреждение про анти-бренд (фиолет/стекло = риск стать неотличимым SaaS) озвучено и отклонено владельцем. `DESIGN.md` / `PRODUCT.md` переписываются под новый язык (Фаза 1).

## 1. Цель

Привести ВСЕ дашборды Коры к единому современному визуальному языку: вместо текстовых строк — графики; вместо плоских блоков — объёмные стеклянные карточки; единый словарь компонентов на всех экранах. Тёмная тема — первая (светлая — отдельная фаза, владелец пришлёт референсы).

## 2. Принятые решения (locked)

| # | Решение | Значение |

## 3. Спецификация языка (из витрины)

**Фон страницы:** глубокий индиго-сланец + радиальные цветные «лужи» света (violet/blue) сверху.
**Стеклянная карточка:** `linear-gradient(180deg, oklch(0.30 0.035 280/.55), oklch(0.22 0.03 278/.5))`, border `oklch(1 0 0/.08)`, radius 20–22, тень `0 18px 40px -18px ...` + inset top highlight, `backdrop-filter: blur(14px) saturate(1.3)`.
**Палитра (oklch):** violet 0.66/.2/300 · indigo 0.62/.2/278 · blue 0.7/.16/245 · cyan 0.8/.13/205 · teal 0.82/.13/178 · mint 0.85/.15/165 · lime 0.86/.19/130 · amber 0.84/.16/80 · pink 0.74/.2/350 · red 0.66/.22/25. Текст 0.97/0.74/0.58.
**Градиенты-чипы:** violet / blue / teal / amber / pink (см. `GRAD` в витрине).
**Графики:** area с `linearGradient` заливкой (0.45→0), gauge `RadialBarChart` 210°→-30° с градиентной дугой, radar с залитым полигоном, donut `paddingAngle=3` + центр-лейбл, bars `radius=[8,8,0,0]` градиент cyan→violet, heatmap — div-ячейки с opacity по интенсивности + glow на пике.
**Типографика:** Geist; герой-число 30–40px/600, заголовок карточки 15px/600, тело 14, подпись 11–12 faint.

## 6. Раскатка по фазам

**Ф1 — Фундамент.** Токены + переписать `DESIGN.md` и `PRODUCT.md` (визуальные разделы; нарративное позиционирование «не PKM/не нотакер/не CRM» оставить) + вынести компоненты из витрины.

**Ф2 — Флагман + худшее.** `/dashboard` (+4 вкладки: Обзор/Команда/Знания/Цели и встречи), `/dashboard/operations` (Обзор/Сегодня/Неделя), `/dashboard/operations/daily`, `/dashboard/operations/weekly`.

**Ф3 — Кабинет.** `/goals`, `/me` (вкладка «Пульс» + остальные), `/actions`, `/maturity`.

**Ф4 — Админка (super-admin).** `/admin`, `/admin/analytics/*` (economics, functions, knowledge, meetings, concierge, orgs), `/admin/billing-overview`, `/admin/helpfulness-overview`, `/admin/health`, `/admin/media/storage`.

**Ф5 — Доводка.** Светлая тема (после референсов владельца — стекло/градиент на светлом = отдельная калибровка), a11y-контраст (WCAG AA на градиентах/стекле), perf `backdrop-blur` (ограничить число blur-слоёв, fallback для слабых машин), QA-обход (скилл qa-tester).

## 7. Риски

- **Светлая тема не задизайнена** — ждём референсы владельца; стекло/свечение на светлом фоне читается иначе.
- **Perf blur** — много `backdrop-filter` слоёв тормозят; лимит + media `(prefers-reduced-transparency)`.
- **Контраст** — текст на градиентах/стекле должен держать AA.
- **recharts измерение** — `minWidth={0}` + контейнеры с явной высотой.
- **Ship-On** — выкатываем экранами включёнными (принцип 8 CLAUDE.md), не «за флагом OFF».
