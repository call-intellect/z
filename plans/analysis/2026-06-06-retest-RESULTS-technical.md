## 1. 🔴 НОВОЕ — ChunkLoadError рушит детальные страницы (корень «задержек навигации»)

**Симптом.** При переходе на детальные страницы рендерится английский экран-ошибка **«This page couldn't load. Reload to try again, or go back»** (кнопки Reload/Back). Воспроизведено:
- `/tables/cmpwpjeal00brjvpds3acvw8l` — **краш стабильно** (2 перезагрузки подряд);
- `/meetings/01KTDHPTHS9T5YGXFANKES765J/result` — краш при первом заходе, после reload отрисовался.

**Консоль:** `ChunkLoadError: Failed to load chunk /_next/static/chunks/0ly-k3c_rg6_b.js from module 964893` + вторичный `Minified React error #185`.

**Корень (диагностика).** Сам чанк отдаётся корректно — прямой `fetch('/_next/static/chunks/0ly-k3c_rg6_b.js')` → **200, 119 144 байт, валидный `globalThis.TURBOPACK`**. Все прочие чанки той же сборки грузятся 200. То есть файл на месте, но динамический `import()` падает с «from module 964893» → **рассогласование манифеста рантайма и содержимого чанка в выкаченной сборке** (Next.js + **Turbopack** в проде). Рантайм ждёт модуль 964893 в этом чанке, его там по факту нет → ChunkLoadError → error-boundary.

**Связь с жалобой владельца.** «Долго грузится страница при создании встречи», «задержка при переходе на результат» = ретраи подгрузки битого чанка + периодический краш. Это **не** задержка AI-цепочки.

**Дополнительно:** сам экран ошибки — **на английском** (англицизм в error-boundary), даёт «Reload/Back» вместо русского.

**Рекомендации:** чистая пересборка фронта и проверка целостности графа чанков; рассмотреть отказ от Turbopack для prod-build (он experimental в этой роли) или фиксацию/апгрейд Next; убедиться, что静ика и HTML деплоятся атомарно одной сборкой (нет нескольких фронт-реплик с разными билдами); локализовать error-boundary.

## 2. 🔴 Видео-плеер записи (S5-01) — вечная крутилка, фикс неэффективен
