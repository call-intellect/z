# Удаление встречи по одной из журнала

## Что было поставлено
Владелец случайно создал встречи (тип «Командная», не запущенные) и не нашёл,
как удалить/закрыть конкретную из списка — в строке только «Войти» и
«Скопировать ссылку».

## Как решал
Сначала проверил, есть ли удаление вообще:
- **Бэкенд** — удаление уже реализовано: `DELETE /api/v1/meetings/:id` →
  `MeetingsService.softDelete` ([meetings.controller.ts:475](../../backend/src/modules/meetings/meetings.controller.ts#L475),
  [meetings.service.ts:876](../../backend/src/modules/meetings/meetings.service.ts#L876)).
  Soft-delete: проверяет владельца, ставит `deletedAt`, **без FSM-ограничений**
  (любой статус, включая `scheduled`/`failed`). Список фильтрует `deletedAt: null`.
- **Фронтенд** — метод `meetingsApi.softDelete` есть, и было **массовое**
  удаление (чекбоксы → `BulkActionsToolbar` → «Удалить»). Но per-row удаления
  в строке не было → пользователь его не находил.

Правка только в одном файле — [MeetingsJournalReal.tsx](../../frontend/src/ui/components/meetings-journal/MeetingsJournalReal.tsx):
добавил в каждую строку (`MeetingRowCard`) меню «⋮» (`DropdownMenu`) с пунктами
«Скопировать ссылку» и «Удалить» (destructive). Обработчик `onDeleteOne`
переиспользует `useConfirmDialog` + `softDelete`, после удаления — тост,
`mutate()`, сброс `selected` из URL если удалили открытую в detail-панели.
Кнопка «⋮»: на мобильном видна всегда (`opacity-100`), на десктопе —
`md:opacity-0 md:group-hover:opacity-100` (+ `data-[state=open]`).

Коммит `859fbfe6`. Ветка `feature/master-prompt-fleet-2026-06-10`.

## Что вышло
- `bun run typecheck` — чисто.
- `bun run lint` — 0 errors (1 warning в чужом `ChatsListClient.tsx`, не мой).
- Прод-операций нет: чисто фронт, без миграций/ENV/seed.
- Ручную приёмку в кабинете ещё не делал (предложил).

## Чему научился
- Прежде чем «делать фичу удаления» — проверять бэкенд: здесь функция целиком
  была готова (контроллер + сервис + api-метод + bulk-UI), не хватало только
  одной точки входа в UI. Классический разрыв «реализовано на 90%, не дотянуто
  до кнопки».
- Паттерн per-row меню действий в Z: `DropdownMenu` + `stopPropagation` на
  триггере и `DropdownMenuContent`, `useConfirmDialog` для подтверждения,
  `Trash2`/`Copy` из lucide, destructive-пункт через `text-danger focus:text-danger`.
