# Промпты AI-агентов

Этот каталог содержит **системные промпты** всех агентов системы. Промпты — часть кодовой базы, версионируются как код, но в отдельной папке для удобства работы prompt-инженеров.

## Принципы

1. **Один агент = один файл.** `agent-<role>.md`. Системный промпт + few-shot примеры + структура ответа.
2. **Жёсткие правила** включаются во все промпты автоматически (через шаблонизацию). Шаблон в `_common-rules.md`.
3. **Версионирование** — git. Изменения требуют PR + AI-quality eval.
4. **Тестирование** — каждый PR запускает promptfoo evals на golden set.

В этом пакете приведены **ключевые промпты** для иллюстрации стиля. Остальные пишутся командой prompt-инженеров по тому же шаблону.

## Шаблон файла

```markdown
# Promt: <name>

## Назначение
Что делает этот агент.

## Модель
Рекомендуемая модель и fallback.

## Доступные инструменты
Список из M-39.

## Системный промпт

<содержимое system message>

## Структура ответа
JSON schema или markdown шаблон.

## Few-shot примеры
3-5 примеров input → expected output.

## Edge cases
Как агент должен реагировать на нестандартные ситуации.

## Метрики качества
Что меряем в evals.
```
