# ТЗ: Страница `/settings/templates` — Шаблоны отчётов встреч

> Анализ: `plans/analysis/2026-05-28-settings-templates-page.md`

## Цель

Реализовать страницу `/settings/templates`, где owner/admin может просматривать, настраивать и создавать кастомные шаблоны AI-отчётов для типов встреч.

## 0. Контекст

Маршрут `/settings/templates` возвращает 404:
- Ссылка на него **есть** в главном сайдбаре (`Sidebar.tsx:352`)
- Страница **не создана** — отсутствует `frontend/app/(authenticated)/settings/templates/page.tsx`
- Пункт **отсутствует** во внутреннем `SettingsSidebar.tsx`

### Что планировалось (из user guide)

- 9 типов встреч имеют каждый свой шаблон AI-отчёта
- Можно открыть шаблон, поменять какие блоки должны быть в отчёте, сохранить
- Можно создать свой новый тип встречи (например, «Совет директоров»)
- Доступ: owner/admin

### Что есть на бэкенде

Два слоя API:

| Слой | API | Назначение |
|---|---|---|
| **UserTemplate** | `GET/POST/PATCH/DELETE /api/v1/templates` | Пользовательские шаблоны (лимит 20 на пользователя) |
| **PromptTemplate** | `/api/v1/admin/prompt-templates` | Админские шаблоны с версионированием, секциями, A/B-тестами |

### Проблема DTO

Frontend API клиент `templates.api.ts` **устарел**:

| Frontend ожидает | Backend возвращает |
|---|---|
| `isSystem: boolean` | _(нет такого поля)_ |
| `description: string` | _(нет такого поля)_ |
| `baseType: MeetingType` | `basedOnType: MeetingType` |
| `customPrompt: string` | `prompt: string` |
| _(нет)_ | `sectionsConfig: string[]` |

## 1. Scope

**Входит:**
- Обновление DTO в `templates.api.ts` и `template.ts` до реального бэкенда
- Создание страницы `/settings/templates` (заглушка → полноценная)
- Добавление пункта в `SettingsSidebar.tsx`
- UI: список шаблонов, редактирование, создание кастомных

**Не входит:**
- Админские `PromptTemplate` (уже есть `/admin/prompts`)
- Версионирование шаблонов
- A/B-тесты промптов
- Изменение системных шаблонов (только чтение для обычных пользователей)

## 5. Риски и ограничения

1. **Несовпадение DTO** — если не обновить `templates.api.ts`, создание/редактирование не будет работать
2. **RBAC** — нужно проверить, что `UserTemplate` API доступен только для owner/admin (сейчас доступно всем авторизованным)
3. **Секции отчёта** — список доступных секций хранится в `PromptTemplateSection`, нужен отдельный эндпоинт для их получения
4. **Лимиты** — бэкенд ограничивает 20 шаблонов на пользователя, нужно показать ошибку при превышении
