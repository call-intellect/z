## 5. Система тем — ТЁМНАЯ и СВЕТЛАЯ ЕСТЬ

- **Обе темы реализованы.** Свой лёгкий `ThemeProvider` (`frontend/src/ui/components/theme/ThemeProvider.tsx`), **без** `next-themes`.
- **Токены:** `frontend/src/ui/tokens.css` — OKLCH. Тёмная — палитра **«warm-mint»** (бирюзово-зелёный акцент); светлая — **«sage»** (приглушённый зелёный). Парные токены `bg-*` + `*-fg`, chip-статусы (success/warning/danger/info/lavender/sand), surface/text/accent/border/shadow.
- **Механизм:** атрибут `data-theme="dark|light"` на `<html>`; выбор в localStorage `z-theme`; поддержка `system` (`prefers-color-scheme`). Tailwind: `darkMode: ['class', '[data-theme="dark"]']`.
- **Дефолт — ТЁМНАЯ** (`app/layout.tsx` ставит `data-theme="dark"`).
- **Переключатель доступен пользователю:** сайдбар → меню аккаунта (внизу) → **Тема** → **Тёмная / Светлая / Системная** (показывает текущую). Есть и быстрый компонент-кнопка `ThemeToggle` (Sun/Moon).
- **Витрины токенов:** `/dark-theme` и `/light-theme` (route-группа `(design-preview)`, `DesignPreviewGallery`).
- **Проверено глазами:** переключил Тёмная→Светлая→Тёмная на `/dashboard` и `/dashboard/operations` — применяется мгновенно, сохраняется. Скрины `14`, `15` — светлая.
