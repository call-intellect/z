## Детали ключевых

### B1 — «В задачи» 400 (корень бага владельца №1)
Поток: Сегодня → Открыть очередь (/actions) → блок «Кандидаты в задачи» → «В задачи».
- Запрос: `POST /api/v1/pending-actions/confirm` body `{"source":"intake","resourceId":"…","resolution":"accept"}`
- Ответ **400**: `{"code":"target_project_required","message":"Не указан проект для создания задачи"}`
- Фронт не даёт выбрать целевой проект и шлёт confirm без него → бэк отклоняет.
- В логах прода ошибка повторяется десятками раз (8:45–9:36) → флоу системно сломан.

### B2 — Главная «valueStrip» 500
`[ERROR] SYSTEM/DirectorDashboardService director widget «valueStrip» fail (tenantId=cmpndk2tw…=Ооо луа, period=week): Invalid prisma.$queryRaw() … Code: 22023. Message: cannot get array length of a scalar`. Виджет деградирует (страница рисуется), но «Польза за период» считается с ошибкой. Повтор 8:49, 8:52, 9:39.

### B3 — должность не видна в «Я» (корень бага владельца №3)
Должности сотрудников Org «Ооо луа» (из API `/persons` и таблицы «Команда»):
- Айназ (ainaz860707) → руководитель отдела внедрения / отдел внедрения
- Настя (chydo_002) → менеджер технической поддержки / технический отдел
- Сергей (svmazur) → CEO
- Анастасия (chydo020) → не приглашён, без должности

То есть должности назначены в данных. Но раздел «Я» (/me) не читает `primaryRole` из `/api/v1/me/profile` и всегда показывает «Должность не назначена» + баннер «укажите должность». Доказано на владельце: API=CEO, UI «Я»=«не назначена». Это объясняет жалобу «должность указывал, почему просит снова».

### B4/B5 — тур (корень бага владельца №2 «должность не даёт выбрать»)
Backdrop тура (`div[aria-hidden] .fixed.inset-0 z-60`) перехватывает клики по всей странице → ни «В задачи», ни «Выбрать должность» нажать нельзя, пока тур открыт. «Пропустить» листает шаги вместо закрытия; закрыть удаётся только Escape/пройдя все 6 шагов. После прохождения combobox должностей работает штатно. Тур висит, пока онбординг компании не «завершён» (см. B6).

- «Проекты»: описание MTG «… `legacy` задач … (`action items`)»
