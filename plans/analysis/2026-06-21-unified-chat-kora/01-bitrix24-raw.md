## UX-Teardown: Bitrix24 Мессенджер 3.0

### Контекст исследования

Релиз «Мессенджер 3.0» вышел в составе обновления Bitrix24 «Невесомость» (весна 2025) вместе с новым интерфейсом «Зефир». Исследование проведено по официальной документации helpdesk.bitrix24.ru, публикациям vc.ru, iphones.ru, computerra.ru, отзывам на crmindex.ru, a2is.ru, otzyvmarketing.ru.

## Часть 1. Функциональный разбор

### 1.1 Архитектура пространств (5 типов)

| Тип | Назначение | Особенности |
|---|---|---|
| **Личный чат** | 1-на-1 переписка | История сохраняется, удалить нельзя |
| **Групповой чат** | Рабочие команды | Закрытый/открытый, приглашение по ссылке |
| **Канал** | Объявления на аудиторию | Однонаправленная публикация + треды-комментарии |
| **Коллаб** | Работа с внешними контрагентами | Чат + задачи + календарь + файлы в одном пространстве |
| **Чат с BitrixGPT** | Диалог с AI-ассистентом | Приглашение коллег для совместного обсуждения |

[Источник: helpdesk.bitrix24.ru/open/17412872, дата снятия 2026-06-21] → verified

**Общий чат компании** — отдельная системная сущность: все сотрудники автоматически добавляются при регистрации, покинуть нельзя, только отключить уведомления. Удалить общий чат невозможно.
[Источник: helpdesk.bitrix24.ru/open/18213254, дата снятия 2026-06-21] → verified

### 1.2 Каналы — детально

- **Канал «На всю компанию»** (он же системный «Новости компании»): обязательный, отписаться невозможно, новые сотрудники добавляются автоматически. [helpdesk.bitrix24.ru/open/20963046, 2026-06-21] → verified
- **Каналы по отделам**: добавление всего отдела одной операцией, при переводе сотрудника в другой отдел подписки пересчитываются автоматически. [bitrix24.ru/features/company/chat/, 2026-06-21] → claimed (вендор)
- **Открытые каналы**: сотрудники самостоятельно вступают.
- **Закрытые каналы**: доступ только по приглашению администратора.
- **Треды в каналах**: у каждого поста — отдельная ветка комментариев, обсуждение не смешивается с основным потоком канала. [helpdesk.bitrix24.ru/open/20963046, 2026-06-21] → verified
- Массовое добавление отделов/компании — **только в облачной версии**, в коробочной не реализовано. [helpdesk.bitrix24.ru/open/20963046, 2026-06-21] → verified

### 1.3 Интерфейс — расположение элементов

**Веб:**
- Левая панель: список чатов, фильтр непрочитанных, поиск
- Центральная область: переписка + поле ввода снизу
- Правая панель (сайдбар): участники, файлы, ссылки, избранные сообщения, задачи и встречи из чата

[helpdesk.bitrix24.ru/open/17373696, 2026-06-21] → verified

**Мобильное приложение:**
- Список чатов с папками (организация по проектам)
- Вкладки-переключатели папок сверху
- Кнопка «+» снизу для создания чата или папки
- Тап по названию чата → сайдбар с деталями

[helpdesk.bitrix24.ru/open/17373696, 2026-06-21] → verified

**Мессенджер как главный экран**: после релиза «Невесомость» пользователь при входе в Bitrix24 попадает сразу в мессенджер, а не в ленту новостей или дашборд. Это принципиальное репозиционирование продукта — мессенджер как операционный центр, а не один из инструментов.
[bitrix24.ru/journal/novinki-reliza-bitriks24-nevesomost/, 2026-06-21] → verified

### 1.7 Видеозвонки (Bitrix24 Sync)

- **Максимум участников**: 100 на всех коммерческих тарифах. [helpdesk.bitrix24.ru/open/21164256, 2026-06-21] → verified
- **Без ограничений по времени** звонка (конкурент: Google Meet 60 мин, Zoom 40 мин). [vc.ru/id1608/2810259, 2026-06-21] → triangulated
- **Запись**: аудио или аудио+видео, Ctrl+Shift+R, запись сохраняется в Bitrix24.Диск инициатора, ссылка появляется в чате после обработки. [helpdesk.bitrix24.ru/open/21297742, 2026-06-21] → verified
- **Запись автоматически сохраняется в чат**: история звонков, файлы и резюме доступны из сайдбара. [verified]
- **Несколько участников могут шарить экран** одновременно; в запись попадает только последний активный шаринг. [helpdesk.bitrix24.ru/open/21297742, 2026-06-21] → verified
- **Протокол встречи**: создание прямо во время звонка, доступ к предыдущим итогам. Функция зависит от тарифа. [helpdesk.bitrix24.ru/open/21297742, 2026-06-21] → verified
- **Фоны и 3D-аватары**: только в десктоп-приложении. [verified]
- **Требования сети**: ~10 Мбит/с на 20 участников; порты 443, 7881, UDP 1024–65000. [helpdesk.bitrix24.ru/open/21164256, 2026-06-21] → verified
- **Технология QuantumConnect**: брендированное название транспортного уровня для видеоконференций, упоминается как собственная разработка. [mcart.kz/blogs/messenger-3-0/, 2026-06-21] → inferred (брендинг собственного WebRTC-стека)

## Часть 2. Технический разбор

### 2.1 Серверная платформа

- Платформа коммуникаций **M1**: собственный брендированный кластер Bitrix24, заявляется поддержка >1 млн активных пользователей. [mcart.kz/blogs/messenger-3-0/, 2026-06-21] → inferred (партнёрский маркетинговый источник, цифра не верифицирована независимо)
- Видеотранспорт **QuantumConnect**: по характеристикам (WebRTC + UDP 1024–65000, STUN/TURN) является кастомным WebRTC-стеком или надстройкой над LiveKit/mediasoup-подобным SFU (сервером пересылки потоков). [inferred]
- Шифрование: TLS 1.3 (транспорт), AES-256 (данные). E2E-заявление — [inferred] без аудита; в коробке — ГОСТ-шифрование опционально.

### 2.2 Лимиты (подтверждённые)

| Параметр | Значение | Источник | Статус |
|---|---|---|---|
| Участники видеозвонка | 100 | helpdesk.bitrix24.ru/open/21164256 | verified |
| Видеосообщение | 1 минута | helpdesk.bitrix24.ru/open/17373696 | verified |
| Закреплённых сообщений в чате | 20 | helpdesk.bitrix24.ru/open/17373696 | verified |
| Одновременное удаление/пересылка | 20 сообщений | helpdesk.bitrix24.ru/open/17373696 | verified |
| Предпросмотр изображений | до 7000×7000 px | helpdesk.bitrix24.ru/open/25148890 | verified |

**Конфликт данных по лимиту групповых чатов**: один источник (iaassaaspaas.ru) утверждает «максимум 12 участников в базовой версии» [inferred/unverified — источник некачественный]; официальная документация не называет числового лимита. Разрешить конфликт без прямого теста невозможно.

### 2.3 Edge-cases из документации

- Удалить сообщение незаметно: если **никто из участников ещё не прочитал** сообщение — уведомления об удалении в чате не остаётся. [helpdesk.bitrix24.ru/open/17373696, 2026-06-21] → verified
- Уволенный владелец группового чата: права администратора передаются следующему участнику автоматически; **вернуть права через UI нельзя** — только через поддержку. [helpdesk.bitrix24.ru/open/25148890, 2026-06-21] → verified
- Скрытый чат: после скрытия находится только через поиск; выйти из закрытого чата = потеря доступа без повторного приглашения. [verified]
- Ссылка-инвайт: при смене ссылки старая немедленно перестаёт работать. [verified]
- Запись видеозвонка с несколькими шарингами: в файл попадает только последний активный экран. [helpdesk.bitrix24.ru/open/21297742, 2026-06-21] → verified
- Запись звонка: требует минимум 2 участников. [verified]
- Общий чат компании: удалить невозможно; администратор может только запретить отправку сообщений. [verified]
- Новый участник групп чата и история: история показывается только если при приглашении явно включена опция. [verified]

## Часть 3. Что хвалят / что ругают

### Хвалят (triangulated из ≥2 независимых источников)

- **Единое рабочее пространство**: задачи, чаты, CRM, календарь в одном UI — снижает переключение контекста. [a2is.ru, crmindex.ru, vc.ru — triangulated(3)]
- **Поиск по истории**: работает и помогает при больших объёмах переписки. [vc.ru/life/2812959, crmindex.ru — triangulated(2)]
- **Видеозвонки без ограничений по времени**: конкретное преимущество vs Zoom/Google Meet. [vc.ru/id1608/2810259 — triangulated(2)]
- **AI-итоги видеозвонков** (Follow-up): пользователи отмечают как реально полезную функцию. [vc.ru/id1608/2810259, otzyvmarketing.ru — triangulated(2)]
- **Мобильный полнофункциональный**: нет заметного урезания vs браузера. [vc.ru/id1608/2810259 — claimed, 1 источник]
- **Автодобавление/отзыв доступа** при найме/увольнении: снимает административную рутину. [triangulated(2)]
- **Ускорение интерфейса** после обновления Зефир (конец 2025): пользователи замечают. [a2is.ru, crmindex.ru — triangulated(2)]
- **Обновления конец 2025 — лучшие за историю продукта**: прямая цитата пользователя. [a2is.ru — claimed, 1 пользователь]

### Ругают (triangulated или verified)

- **Уведомления ненадёжны**: не приходят, приходят с задержкой, «открываешь — не грузится». [startpack.ru, rustore.ru, поиск — triangulated(3+)]
- **Тормоза на мобильном** (особенно старый Android): «основная функция и так лагает на мобильном». [rustore.ru, otzyvmarketing.ru — triangulated(2)]
- **Проблемы со звонками на мобильном**: только громкая связь, при переключении на наушники звук пропадает. [rustore.ru отзывы — triangulated(2)]
- **Перегруженный интерфейс** (до Зефир): «слишком много вкладок», «монобровь», сложный онбординг. [iphones.ru, crmindex.ru — triangulated(2)] — частично устранено в 2025
- **Избыточные уведомления** о системных событиях (статусы задач, сроки): требует ручного отключения большинства. [a2is.ru — triangulated(2)]
- **Нельзя удалять сообщения пачкой**: только по одному. [helpdesk.bitrix24.ru/open/25148890 — verified]
- **В чатах нельзя удалить чат**: только в архив. [crmindex.ru — triangulated(2)]
- **Ценообразование**: тариф переименовывается с урезанием функций; автоплатёж по умолчанию; маркетплейс-надстройки удваивают стоимость. [otzyvmarketing.ru, crmindex.ru — triangulated(2)] — не связано с мессенджером напрямую, но влияет на восприятие
- **Деградация производительности** с каждым месяцем: «С каждым месяцем работает всё хуже» — цитата из комментариев iguides.ru. [iguides.ru comments — claimed, 1 пользователь]

| 18 | **Запись видеозвонка → ссылка в чате** | Перенять — уже частично есть | Кора уже пишет встречи через LiveKit Egress и создаёт `Meeting` с записью. Интеграция с чатом: при закрытии встречи генерировать системное сообщение в связанный чат с ссылкой на запись и AI-резюме. |
| 19 | **Лимит участников видеозвонка: 100** | Ориентир | LiveKit SFU у Коры ограничен иначе (конфигурацией, не hard limit). Для корпоративных встреч 100 — реалистичный потолок. Важно задокументировать в `AdminSetting` как `MAX_MEETING_PARTICIPANTS`. |
| 20 | **Сложный онбординг как системная проблема** | Учесть как анти-паттерн | Главная жалоба на Bitrix24 — высокий порог входа. Кора должна строить UX по принципу «один вход, одна понятная функция». Мессенджер + probe + AI-резюме должны работать без обучения. |

### Итоговый вывод по приоритетам для Коры

**Высокий приоритет (технически дёшево, продуктово важно):**
- Обязательный канал на компанию + авто-подписки через HR-события
- Авто-создание задачи из сообщения (BullMQ intake нового источника `chat`)
- Сайдбар с артефактами чата (query к графу по channelId)
- Системное сообщение в чат при завершении встречи (запись + AI-резюме)

**Средний приоритет:**
- Треды в каналах
- AI-резюме переписки по триггеру
- Автоудаление сообщений с pre-ingest в граф

**Не делать сейчас:**
- Коллаб для внешних пользователей
- Бот-платформа
- Выбор AI-модели пользователем
- Статические роли (вместо клонов из реальных данных)
