## Чему научился

1. **`Participant` не хранит email** → идемпотентность `invitees` строится по
   `userId` / `personId` (а не по email). Повтор уже приглашённого = no-op
   (`skipped`); email-only адресаты не дедупаются по записи участника.
2. **Реальный `pluralRu` — вариадический** (`pluralRu(n, one, few, many)`), а не
   массив-форма из ТЗ. Урок: проверять сигнатуру утилиты в коде, не угадывать по
   тексту ТЗ. (Подтверждает правило «проверять поведение/утилиту, не интуицию».)
3. **`SprintArchiveSummaryApi` — backend-вычисляемая.** Тайлы «Завершены/Отменены»
   можно релейблить на фронте без смены данных; реальная семантика
   (`confirmed/rejected` vs `completed/cancelled`) остаётся бэк-долгом (вынесено в
   реестр «не сделано»).
4. **Хост авто-входит в `/m/:id`** — отдельного экрана «лобби хоста» нет; «лобби
   хоста» в ТЗ = зона нижнего блока shell. Кнопку «Скопировать ссылку» (B4) вешали
   именно туда, а не на несуществующий pre-join экран.
