# INDEX RULES

## Когда обновлять index.md
- При создании любого нового файла — сразу
- При удалении файла — убрать ссылку
- При переименовании — обновить ссылку

## Структура секций в index.md
Каждая секция = папка. Новые папки = новые секции.
Порядок секций: Система → Проекты → Архитектура → Баги → Архив.

## Запрещено
- Держать файл без записи в index.md
- Держать мёртвые ссылки в index.md

## Дата внизу
Всегда обновлять строку `_Обновлён: YYYY-MM-DD_` при каждом изменении index.md.
