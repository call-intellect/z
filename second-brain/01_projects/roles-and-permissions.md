# Roles & Permissions

Две роли в первой версии. Без сложной матрицы зрителей.

## Host

Авторизованный пользователь, создавший встречу.

**Права:**
- начать запись
- остановить запись
- выключить микрофон участнику
- удалить участника
- завершить встречу
- видеть итоговый AI-отчёт
- видеть запись встречи
- поднять/опустить свою руку
- _(вопрос открыт)_ опустить руку другому участнику — см. `plans/analysis/2026-05-06-raise-hand.md`
- **скопировать ссылку на встречу** — кнопка в комнате; даёт ту же самую ссылку `meet.crossmark.ru/m/<id>`, которую хост рассылает кому угодно (Telegram, почта, мессенджеры). Z сам никому ничего не рассылает.

## Guest

Гость по ссылке (без регистрации).

**Права:**
- войти без регистрации (указав имя)
- включить/выключить камеру
- включить/выключить микрофон
- показать экран
- писать в чат
- поднять/опустить свою руку
- выйти из встречи

**НЕТ прав:**
- управлять записью
- управлять другими участниками
- видеть AI-отчёт после встречи

## Принципы

- Все LiveKit-токены генерирует **только backend**.
- Гость **не получает** никаких секретов LiveKit.
- Guest token имеет ограниченный capability set (без admin-permissions комнаты).

## Чего пока нет (вне MVP)

- Co-host (несколько ведущих)
- Зритель без аудио/видео
- Зал ожидания
- Сложная матрица прав по типам встреч
