# Второй мозг для компаний — техническое задание для команды разработки

Эта папка — самодостаточный пакет для команды разработчиков. Здесь всё, что нужно, чтобы написать систему с нуля. Ни одного отсылочного файла за пределами этой папки читать не нужно.

Если у вас есть вопрос, на который нет ответа здесь, считайте его архитектурным открытым вопросом — поднимите его команде, не додумывайте.

---

## Что строим

«Второй мозг для компании» — корпоративная AI-система, которая:

1. **Собирает** всё, что говорится и пишется внутри компании (встречи, чаты, переписки, документы, CRM, метрики продукта).
2. **Хранит** оригиналы, не подменяя их интерпретацией.
3. **Понимает** смысл: вынимает сигналы, темы, идеи, риски, упоминания клиентов и сотрудников.
4. **Связывает** всё со всем через временной граф знаний — ищет неявные связи и переосмысляет их со временем.
5. **Подсказывает** руководителю и командам, что происходит, идёт ли компания к своим целям, какие появляются риски и идеи.

Продукт **не контролирует** сотрудников и **не заменяет** task-tracker. Это **память + анализ + подсказки**, не контролёр исполнения. См. [00-executive-summary.md](00-executive-summary.md), раздел «Память, не контроль».

## Кто заказчик

Компании в России, 20–500 сотрудников (стартовая аудитория), но архитектура поддерживает и более крупных. Любая отрасль. Подробнее — в [00-executive-summary.md](00-executive-summary.md).

## Жёсткие требования (нарушать нельзя)

1. **Self-host без внешних зависимостей.** Любая компания должна запустить продукт целиком на своих серверах. Никаких managed-сервисов в обязательном пути (без Pinecone, Supabase, OpenAI Embeddings as required, Auth0). LLM — единственное исключение, и то с возможностью fallback на локальные модели.
2. **Русский интерфейс.** Весь user-facing текст — на простом русском. Никаких англицизмов в UI («embedding», «pipeline», «retrieval» — недопустимо). Английский остаётся только в коде, API и технической документации.
3. **Никаких кнопок.** Пользователь вводит данные только свободным текстом или голосом. Никаких форм, чекбоксов, тегов, выпадающих списков, multi-select. Классификацию делает AI на стороне сервера.
4. **Полный продукт сразу, без MVP.** В scope все 40 модулей. Никакой поэтапной выкатки «сначала базовое, потом дифференциаторы». См. [DR-001](14-decisions-log.md#dr-001).
5. **Композиция open-source.** Если есть готовый open-source с подходящей лицензией и self-host — берём. Своё пишем только когда альтернатив нет. См. [DR-002](14-decisions-log.md#dr-002).
6. **LLM-провайдер любой умный.** Архитектура поддерживает Anthropic Claude, OpenAI, Google Gemini, локальные открытые (Llama, Qwen, DeepSeek). Российские LLM (YandexGPT, GigaChat) исключены из дефолтного маршрутизатора по качеству. См. [02-stack.md](02-stack.md), раздел «Маршрутизация моделей».
7. **Память, не контроль.** Никаких напоминалок «ты обещал», блокирующих подтверждений, активного давления на сотрудников. Подробно — в [00-executive-summary.md](00-executive-summary.md), раздел «Этические рамки».
8. **152-ФЗ и российский периметр.** Хранение персональных данных — в России. Это влияет на выбор хостинга и доставки. См. [08-security-privacy.md](08-security-privacy.md).
