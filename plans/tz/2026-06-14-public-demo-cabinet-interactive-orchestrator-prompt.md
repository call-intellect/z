## Failure-modes
- Суб-агент «починил» вкладку точечным `onclick` → вернуть к единому `data-action`/`activateTab`.
- Числа на экране разошлись с `DEMO` → правка + запись пары в README §checks.
- Светлая тема нечитаема на новой поверхности → заменить хардкод на токены `var(--*)`.
- Чат отвечает невпопад → поднять порог матчера, проверить `keywords`, убедиться в fallback.
- Регресс базовой навигации после переноса скрипта в `app.js` → перенос делать дословным.
