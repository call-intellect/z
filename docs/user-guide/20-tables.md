# Таблицы

Таблицы — это место, где у компании живут списки. Клиенты, сотрудники, проекты, сделки, идеи, гипотезы, риски — всё, что естественно выглядит строками и колонками. Главное отличие от Excel и Google-таблиц в том, что таблица в Коре — не отдельный файл, а **срез памяти компании**. Строки в ней — это реальные люди, организации, встречи и документы, которые уже хранятся у Коры.

Подробно про память компании — [Знания и карточки](./03-knowledge-and-cards.md). Про то, как Кора слушает встречи и пополняет память, — [Встречи](./02-meetings.md).

## Что Кора делает за вас

- Хранит таблицы внутри организации — никто из другой компании их не видит.
- Помнит, кто и когда последний раз менял каждую ячейку.
- Связывает строки с людьми, организациями и проектами из памяти компании (если включена привязка).
- Подгоняет ширину колонок, плотность строк и порядок — так, как привычно вам.
- Даёт быстрый поиск и фильтр по тысячам строк без тормозов.
- Сохраняет ваши настройки фильтров и порядка колонок как именованные «виды», которыми можно делиться ссылкой.

## Что вы делаете сами

- Создаёте таблицу, даёте ей имя, описание и эмодзи-иконку.
- Добавляете колонки и выбираете их тип (текст, число, дата, статус и т.д.).
- Заполняете строки или копируете данные из Excel прямо в сетку.
- Пишете свободные заметки в карточке-странице каждой строки.
- Архивируете и восстанавливаете таблицы, когда они теряют актуальность.

## Где найти

| Что | URL | Описание |
|---|---|---|
| Список таблиц | `/tables` | Все таблицы организации с поиском |
| Создать таблицу | `/tables` → кнопка «+ Создать таблицу» | Открывается окно ввода названия |
| Открыть таблицу | `/tables/[id]` | Сетка со строками и колонками + карточка строки |
| Вид таблицы | `/tables/[id]?view=[viewId]` | Ссылка на сохранённый вид |

Пункт «Таблицы» с иконкой сетки находится в боковой панели в слое «Каждый день», между «Карточки» и «Проекты». Подробнее о навигации — [Карта кабинета](./00-navigation.md).

## Главный экран — список таблиц

На странице `/tables` карточная сетка: каждая таблица — карточка с иконкой, названием, описанием, временем последнего изменения и чипом-меткой, к какой сущности привязана (Организации / Люди / Встречи / Документы). Сверху — счётчик и кнопка «+ Создать таблицу».

Если таблиц ещё нет — Кора покажет пустой экран с подсказкой и той же кнопкой создания.

### Создание

Жмёте «+ Создать таблицу» → вводите название → попадаете внутрь новой таблицы. Пока пусто: ни колонок, ни строк. Дальше — добавляете колонки и заполняете строки.

> На ближайшем обновлении кнопка создания будет открывать Кору-ассистента: вы говорите словами, какой список нужен, — Кора предложит готовый набор колонок и сразу подтянет подходящие записи из памяти компании. Подробнее — [Консьерж-помощник](./05-concierge.md).

## Внутри таблицы

Страница `/tables/[id]` состоит из трёх частей: шапка, сетка, выезжающая карточка строки.

### Шапка

- **Название и иконка** — клик по названию редактирует.
- **Переключатель видов** — выпадающий список «Все колонки» / ваши сохранённые виды.
- **Настройка колонок** — кнопка «Колонки»: видимость каждой колонки и плотность строк (компактная / обычная / просторная).
- **Метки «Изменения не сохранены»** и **«Сохранить вид»** — появляются, если вы что-то поменяли в текущем виде.
- **«+ Колонка»** и **«+ Строка»** — добавляют новую колонку или строку.
- **В архив** — мягкое скрытие таблицы (всегда можно вернуть).

### Сетка

Сетка работает на быстром канвасе — не тормозит даже на тысячах строк. Возможности:

- **Редактирование в ячейке** — двойной клик / Enter.
- **Перетаскивание колонок** — за заголовок, мышью.
- **Перетаскивание строк** — за номер слева.
- **Копи-паст из Excel** — выделите ячейки в Excel, скопируйте, вставьте в Кору. Структура сохранится.
- **Клик по номеру строки** — открывает карточку-страницу строки справа.

### Карточка строки — мини-страница

Клик по номеру строки → справа выезжает панель. В шапке — название (берётся из главной колонки таблицы), дата создания и обновления. Ниже — все поля этой строки с возможностью редактировать прямо здесь. Ещё ниже — пустое поле «Содержимое»: туда пишете свободные заметки, мысли, цитаты, договорённости. Это ваше пространство — Кора его не трогает.

В карточке есть мини-редактор форматирования: жирный, курсив, заголовки, списки, ссылки. Содержимое сохраняется автоматически.

## Колонки — 13 типов

При нажатии «+ Колонка» открывается выбор типа. Доступны:

| Тип | Что подходит |
|---|---|
| **Текст** | Короткая строка до 255 символов: фамилия, бренд, короткое описание |
| **Длинный текст** | Абзацы: подробное описание, конспект, цитата |
| **Число** | Целое или дробное: количество, баллы, рейтинг |
| **Сумма ₽** | Денежные суммы в рублях |
| **Процент** | Доля, прогресс, конверсия |
| **Дата** | Дата и время: дедлайн, дата встречи, дата сделки |
| **Статус** | Цветная метка с фиксированным списком значений: «новый», «в работе», «завершён» |
| **Один из** | Выпадающий список: один вариант из набора |
| **Несколько из** | То же, но можно выбрать несколько меток |
| **Чекбокс** | Да / нет: оплачено, готово, проверено |
| **Сотрудник** | Привязка к человеку из вашей команды |
| **Ссылка** | URL с проверкой формата |
| **Электронная почта** | Email с проверкой формата |
| **Телефон** | Номер телефона |

Тип можно поменять после создания — Кора предупредит, если данные не подойдут под новый тип.

## Виды — сохранённые срезы

Один и тот же набор данных можно показывать по-разному, и для каждого способа есть свой «вид».

**Как создать вид:**
1. Скройте лишние колонки через кнопку «Колонки».
2. Перетащите оставшиеся в нужном порядке.
3. Выберите плотность строк.
4. Появится плашка «Изменения не сохранены» и кнопка **«Сохранить как новый вид»**.
5. В диалоге — название вида и видимость:
   - **Только мне** — личный вид, никто его не увидит.
   - **Всей команде** — общий вид для всех в организации.
   - **Публичная ссылка** — отдаваемая ссылка для тех, у кого есть URL.

Активный вид показывается в URL: `/tables/[id]?view=[viewId]`. Эту ссылку можно отправить коллеге — у него откроется тот же срез.

Изменения в чужом виде сохранить нельзя — можно сделать на их основе свой.

## Привязка к памяти компании

У таблицы есть необязательная привязка к сущности графа: организация, человек, встреча или документ. Если привязка включена — Кора понимает, что каждая строка таблицы соответствует реальной записи в памяти компании. Это даёт два эффекта:

1. **Колонки-атрибуты сущности** (имя, домен, дата создания) — read-only: правки автоматически уходят в саму запись памяти, а не в локальную ячейку.
2. **Связанные данные подгружаются автоматически** — например, в таблице «Клиенты» рядом со строкой видны последние встречи с этим клиентом.

На карточке таблицы тип привязки отображается чипом-меткой.

> На ближайших обновлениях привязка станет «живой»: новые записи в памяти (например, новый клиент из транскрипта встречи) будут сами появляться в таблице как новые строки. Подробнее — [Знания и карточки](./03-knowledge-and-cards.md).

## Архив и удаление

В шапке таблицы есть кнопка **«В архив»** — таблица мягко скрывается. Архивированные таблицы всё ещё видны на странице `/tables` при включённом фильтре «Архив», и их можно вернуть кнопкой «Из архива».

Полное удаление возможно только из архива — это двухшаговая защита от случайной потери. После полного удаления сама таблица и все её данные удаляются безвозвратно.

## Типовые сценарии

### Реестр клиентов
Создайте таблицу «Клиенты», привяжите к сущности «Организации». Колонки: название, контактное лицо (Сотрудник), email, телефон, статус сделки (Статус), сумма (Сумма ₽), дата следующего касания (Дата). Сохраните вид «Активные сделки» с фильтром по статусу и видимостью «Всей команде».

### Реестр гипотез
Таблица «Гипотезы». Колонки: формулировка (Длинный текст), статус (Статус: «новая» / «в проверке» / «подтверждена» / «опровергнута»), ответственный (Сотрудник), дата старта (Дата), результат (Длинный текст). В карточке каждой строки пишите ход проверки.

### Реестр поставщиков
Таблица «Поставщики». Колонки: название, услуга (Один из), стоимость в месяц (Сумма ₽), договор (Ссылка), контакт (Email), активен (Чекбокс).

### Список входящих идей
Таблица «Идеи на изучение». Колонки: формулировка, источник (Один из: «встреча» / «чат» / «лично»), важность (Статус), кто отвечает (Сотрудник).

## Что нельзя в Таблицах

- **Формулы между ячейками** (как `=SUM(A1:A10)` в Excel) — пока не поддерживаются.
- **Связи между таблицами** (one-to-many, lookup, rollup) — на следующих обновлениях.
- **Канбан, календарь, диаграмма Ганта по таблице** — пока только сеточный вид.
- **Импорт Excel со схема-инференсом** — пока копируйте через буфер обмена.

Для трекинга задач с канбан-доской, календарём и Гантом используйте **[Проекты и трекер](./14-projects-tracker.md)** — это другая, специально заточенная вкладка.

## Безопасность

- Таблица всегда видна только в пределах вашей организации.
- Видимость отдельных видов настраивается (личное / команде / по публичной ссылке).
- Любое изменение фиксируется: видно, кто и когда менял запись.
- Сотрудник без доступа к разделу «Память компании» увидит таблицы, привязанные только к публичным сущностям.

## Частые вопросы

**Можно ли импортировать Excel-файл?**
Пока — копированием через буфер обмена: выделите данные в Excel, скопируйте, вставьте в Кору. Структура колонок и строк сохраняется. Полноценный импорт файла с автоматическим распознаванием колонок появится в следующих обновлениях.

**Можно ли выгрузить таблицу в Excel или CSV?**
Да, выгрузка из любого вида доступна. Подробнее — раздел «Экспорты» в настройках, см. [Карту кабинета](./00-navigation.md#настройки).

**Что будет с таблицами, если уйдёт сотрудник, который их вёл?**
Ничего — таблицы хранятся в организации, а не у сотрудника. Доступ переназначается через [Участников](./09-admin-and-economics.md). Виды этого сотрудника со статусом «Только мне» останутся скрытыми и могут быть переданы новому владельцу или удалены админом.

**Сколько таблиц можно создать?**
Технический предел — 1000 таблиц на одну организацию, до 100 000 строк и 200 колонок на таблицу. Если упёрлись — напишите в [поддержку](./10-faq-and-troubleshooting.md).

**Где задавать вопрос про таблицы?**
Откройте Кору-ассистента (значок справа внизу) или напишите боту в Telegram — спросите как у живого помощника. См. [Консьерж-помощник](./05-concierge.md).
