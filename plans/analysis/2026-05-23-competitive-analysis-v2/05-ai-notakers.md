# Сегмент 6 — AI-нотакеры

## Главные открытия

1. **Granola установила вектор pivot**: чистый нотакер → memory layer для AI-агентов. Series C $125M (март 2026), оценка $1.5B (x6 за 10 мес от $250M в мае 2025). MCP-сервер (фев 2026), Enterprise API (март 2026), Spaces. Все за ней потянутся.
2. **mymeet.ai** — главный РФ конкурент. **100k+ пользователей** (не 80k — обновлено), интеграция с МТС Линк (апр 2026), реестр Минцифры, диаризация 96-98%, on-prem на Business-тарифе.
3. **Hardware-сегмент схлопывается**: Limitless куплен Meta (дек 2025), заморожен. Остался Plaud (нишевый для оффлайн-встреч).
4. **РФ-рынок консолидируется**: МТС Линк купил Vinteo, IVA с Ростех+МегаФон, mymeet интегрируется с МТС Линк. «Отдельные нотакеры» становятся фичей ВКС.
5. **IVA Technologies — лидер серверного ВКС РФ (29.6%)** + Ростех + МегаФон (май 2026 альянс) — формируется гос-периметровый альянс.
6. **Ценовая война в SMB достигла дна** ($0 free → $8-32/мес). Дальше дифференциация в Enterprise (Scorecards, Series Analysis, Spaces, API).

## Реальные угрозы

### В РФ (Топ-3)

1. **mymeet.ai** — главный bottom-up. 100k users, дешёво, в реестре, со всеми ВКС интегрирован. Опередят нас в SMB по цене.
2. **IVA Technologies** — 29.6% серверного ВКС, AI-ассистент включён, гос/корп через Ростех+МегаФон. Прямая угроза Enterprise/Gov.
3. **МТС Линк + mymeet (в связке)** — экосистема ВКС+нотакер для крупного бизнеса.

### Глобально (Топ-3)

1. **Granola** — категорийный лидер, идёт в context-layer (наш ровный конкурент на горизонте 18-24 мес).
2. **Otter.ai** — ARR $100M, лидер по узнаваемости, Enterprise-движение.
3. **Fireflies.ai** — $1B оценка, 20% доли, лучшие CRM-интеграции.

## Главный вопрос: wedge A (встречи как точка входа) — реалистичен?

**Ответ: только при двух условиях:**

1. **Не позиционируемся как нотакер** — иначе сразу ценовая война с mymeet/FollowUp ($8-32 vs 200 ₽/час). Категория «память компании / AI-COO» с встречами как первым источником ingest — единственно жизнеспособная.
2. **Wedge A — крюк, а не центр предложения**. Покупатель приходит за нотакером, мы продаём «нотакер + граф + дашборд + клонов» по Enterprise-цене (~3-10k ₽/user/мес как НаВстрече Enterprise, не как Pro mymeet $28).

**Если wedge A — это «AI-нотакер с типами встреч на LiveKit»**, вход в рынок невозможен против mymeet (100k users, bottom-up, в реестре, со всеми ВКС интегрирован). Wedge A должен быть **«корпоративная память, где встречи — первый канал ingest, а LiveKit — опция»**, и параллельно — wedge B/C через почту/Slack/CRM-сигналы.

**Альтернатива**: начать с Employee Clones / AI-COO (новая категория, нет прямых конкурентов), встречи добавить позже. Этот путь длиннее в монетизации, но не сталкивает нас с mymeet/FollowUp лбом.

## Что украсть у конкурентов

1. **Avoma**: шаблоны под тип встречи как first-class FSM (Discovery/Demo/Onboarding) + AI Scorecards.
2. **Sembly**: Meeting Series Analysis = аналог нашего «истории сущности» в графе; Voice ID enrollment.
3. **MeetGeek**: 11 форматов отчётов под scenario.
4. **Granola**: no-bot-режим как опция для приватных встреч; MCP-сервер; Spaces (фолдеры с гранулярным доступом).
5. **tl;dv**: multi-meeting reports + кастомные GPT-форматы.
6. **Fireflies**: глубина CRM (Salesforce/HubSpot/Pipedrive/Bitrix24/amoCRM).
7. **TrueConf**: семантический поиск по аудио/видео в on-prem.
8. **mymeet**: интеграция со ВСЕМИ РФ ВКС (Telemost/Jazz/Контур/МТС Линк/TrueConf) — must-have.

## Где Кора реально дифференцируется (7 пунктов)

1. **Per-Org граф знаний с типизацией Entity/IdeaBlock/Theme/EntityLink** — никто из нотакеров (включая Granola) графа не строит.
2. **Multi-source ingest** (встречи + почта + Slack/Telegram + чек-ины + CRM-сигналы) — все конкуренты заперты во встречах.
3. **Отдельные дорожки на участника через LiveKit + 9 типов встреч** — даёт качественный потолок выше 95% mymeet/Sembly.
4. **AI-COO + Employee Clones** — категория за пределами нотакеров.
5. **152-ФЗ + реестр Минцифры + on-prem из коробки** — Granola/Otter/Fireflies этого не дадут.
6. **Дашборд CEO «пульс компании за 30 секунд»** — Read.ai даёт sentiment, но не org-level pulse.
7. **AI-чат компании по всему корпусу знаний** — Granola делает по своим встречам, Кора — по всему графу.

## Особо ценные insights

1. **Granola x6 оценки за 10 мес (250M → 1.5B)** — инвесторы верят в «memory layer for AI», а не в «лучший нотакер». Категория Z попадает в тренд раньше, чем конкуренты успеют развернуться.
2. **Limitless куплен Meta** — wearable AI освобождается, Plaud единственный. Не приоритет, но потенциальный wedge D через 2-3 года.
3. **IVA + Ростех + МегаФон** — формируется гос-периметровый альянс. Если Кора метит в Mega-Ent/Gov, нужен партнёр уровня Ростех или жёсткая ФСТЭК-готовность.
4. **mymeet интегрировался с МТС Линк** — эталон, как нотакер становится частью ВКС-экосистемы РФ. Z должен либо повторить (партнёрство с Контур.Толк / Телемост / TrueConf), либо строить свой ВКС (что Z уже делает на LiveKit).
5. **Granola SOC 2 за 3 месяца через Vanta** — compliance закрывают быстро под Enterprise. Для Коры: 152-ФЗ + реестр + ФСТЭК — должны быть готовы до первой Enterprise-сделки.
6. **Avoma — самый близкий референс продуктового слоя** «тип встречи × шаблон отчёта». Z уже делает 9 типов, но Avoma довёл до Scorecards с 100% coverage — следующий шаг.
7. **Зарубежные нотакеры в РФ не работают** (платежи, 152-ФЗ, локализация). Granola выходит в RU как язык, не как compliance. Кора имеет «защитный ров» 2-3 года.
