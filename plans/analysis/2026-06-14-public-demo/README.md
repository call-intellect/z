# Кора — публичное интерактивное демо кабинета

Интерактивная витрина кабинета Коры (памяти компании) для сайта. Полностью статическая страница (HTML/CSS/JS): **без бэкенда, без сети, без сборки**. Открывается прямо из файла, работает офлайн. Все данные вымышленные, чат отвечает по локальной базе знаний (без реального ИИ).

## Состав файлов

| Файл | Назначение |
|---|---|
| `index.html` | Десктопная версия кабинета (все экраны: Сегодня, Неделя, Итоги месяца, Требует вас, Встречи, Задачи, Память, Лента Коры, Команда, Я, Настройки). |
| `mobile.html` | Мобильная версия (та же логика, мобильная вёрстка). |
| `design-system.css` | Дизайн-система: токены, тёмная и светлая темы, стекло/градиенты, стили демо-интерактива (оверлей, тост, чат). |
| `app.js` | Движок взаимодействия (vanilla JS): экраны/роли/тема, делегированный диспетчер `data-action`, рендереры деталей (встреча/задача/решение/человек/отдел/клон), оверлей, тосты, фильтры, вкладки, чат «Спросить Кору». Подключается и к `index.html`, и к `mobile.html`. |
| `demo-data.js` | Все выдуманные данные (`window.DEMO`): люди, отделы, встречи, задачи, решения, клоны + база знаний чата (`kbCompany`, `kbProduct`). |

## Как открыть локально

**Самый простой способ** — двойной клик по `index.html`. Страница работает прямо из `file://`, без сервера: движок и данные подключаются локальными `<script>`-тегами.

**Через простой статик-сервер** (если хочется «как в браузере по http»):

```bash
# из папки демо
python -m http.server 8099
# затем открыть http://127.0.0.1:8099/index.html
```

`mobile.html` — мобильная версия того же кабинета (откройте её отдельно или сузьте окно браузера для проверки адаптива).

## Как встроить на сайт

**Вариант А — статика по ссылке.** Скопируйте папку целиком в публичную статику сайта (например `/<сайт>/demo/`) и дайте прямую ссылку на `index.html`. Никаких зависимостей и переменных окружения не нужно — всё работает офлайн.

**Вариант Б — встраивание через iframe.** Вставьте кадр на любую страницу:

```html
<iframe src="/demo/index.html" style="width:100%;height:100vh;border:0"></iframe>
```

Всё работает офлайн, данные вымышленные, чат «Спросить Кору» отвечает по локальной базе знаний (это не реальный ИИ, а заготовленные ответы из `demo-data.js`).

## Что можно «потыкать»

- **Переключатель роли** (вверху): Владелец / COO / Сотрудник — меняет видимые блоки и стартовый экран.
- **Переключатель темы**: тёмная / светлая.
- **Вкладки и фильтры** внутри экранов (например на «Неделе»: вердикт / Кто держит слово / KPI; в «Задачах»: список / спринты / инбокс; в «Ленте Коры» фильтры по типу события).
- **Клик по встрече** → деталь встречи: участники, краткое содержание, транскрипт, AI-отчёт, извлечённые задачи и решения (все кликабельны дальше).
- **Клик по задаче** → деталь задачи: исполнитель, источник-встреча, история, мок-смена статуса.
- **Клик по человеку** → профиль: роль, отдел, «держит слово», недавняя активность, клон роли.
- **Очередь «Требует вас»** → карточки решений с действиями владельца (Принять / Вернуть / Отложить) — счётчик очереди уменьшается.
- **Чат «Спросить Кору»** (плавающий значок справа внизу): задайте вопрос или выберите подсказку — ответ приходит с цитатами-источниками (кликабельны → встреча).

## Проверки консистентности (checks)

Статичные числа на экранах сверены с длинами массивов в `demo-data.js` (`window.DEMO`):

| Что показано на экране | Значение | Источник в DEMO | Сходится |
|---|---|---|---|
| «13 встреч» (подзаголовок «Встречи») | 13 | `DEMO.meetings.length` = 13 | ✅ |
| «Требует вас 6» / «Очередь решений · 6 ждут вас» | 6 | `DEMO.decisions.length` = 6 | ✅ |
| «20 задач» (чип «Все задачи списком») | 20 | `DEMO.tasks.length` = 20 | ✅ (было «21», исправлено в Ф8) |
| Люди в «Кто держит слово» / профили | p-serg, p-anna, p-dmit, p-elena, p-igor, p-marina | `DEMO.people` (6 человек) | ✅ все имена канонические |
| Отделы | 4 | `DEMO.departments.length` = 4 | ✅ |

Известные сознательные расхождения (не баг, продуктовый ракурс демо):

- Таблица «Сотрудники» на экране «Команда» и её подпись «4 сотрудника» показывают 4 человек из 6 (вошедших в Кору), что согласуется с её собственными чипами «3 активны · 1 не приглашён». Полный список людей в `DEMO.people` — 6.
- Исторические подписи в «Итогах месяца» («Собрано 38 встреч…», май/апрель) — это ретроспективные сводки прошлых периодов, не привязаны к текущему `DEMO.meetings` (демонстрируют накопление памяти во времени).
