### Итог по всему эксперименту 3

**Победитель — Variant Б+ (один объединённый вызов на 8 типов сущностей).**

Принципиальный вывод: для извлечения сущностей разных типов из одного контекста (одной встречи) **объединённый вызов выигрывает не только по экономике, но и по качеству**. Это потому что одна модель в одном thinking-проходе:
- держит ВСЕ 8 типов в одном поле зрения и принимает согласованные решения о типизации;
- не дублирует блоки (как Г из-за независимых специалистов);
- использует соседние блоки для глубины естественно;
- кэш-префикс DeepSeek (тестировался в Г) даёт всего ~21% экономии, а не обещанные 90% — стратегия с разделением вызовов не окупается.

Этот паттерн рекомендован для применения в `knowledge-core` — заменяет 5+ раздельных специалистов одним вызовом `submit_all_8_entities`.
