# РФ-рынок: память компании, распределение задач по компетенциям, ассистенты на обратной связи

Срез на 2026-06-21. Три направления для Коры:
- **Н1** — корпоративная AI-база знаний / профиль компании для ассистента;
- **Н2** — распределение/постановка задач по компетенциям сотрудников;
- **Н3** — AI-ассистенты, обучающиеся на обратной связи (правках).

Оговорка по данным: на РФ-рынке открытых review-данных (отзывы, цифры внедрений, цены) очень мало; почти все числа — из маркетинга вендоров (claimed) или одной публикации (слабый сигнал). Триангуляция возможна редко.

## Н2 — распределение задач по компетенциям

### Bitrix24 CoPilot / BitrixGPT — единственный с явной фичей matching
- [verified] CoPilot «может добавлять детали к задачам и **распределять задания между сотрудниками**». URL: https://helpdesk.bitrix24.ru/open/19092894/
- [claimed] «Распределение задач с учётом загрузки сотрудников и приоритетов» + автогенерация чек-листов из вводных. URL: https://www.bitrix24.ru/journal/raspredelenie-zadach-mezhdu-sotrudnikami/ ; https://www.bitrix24.ru/features/ai/
- Слабость: распределение — по загрузке/приоритету; **компетенции/навыки как явный сигнал не подтверждены** (в отличие от заявленного matching по навыкам).

### Pyrus
- [verified] Маршрутизация заявок: формы с поэтапной маршрутизацией, многоэтапные согласования с условными переходами; AI-классификация заявок и авто-маршрутизация. URL: https://pyrus.com/ru/help/workflow/editor ; https://www.tadviser.ru/.../Pyrus
- [verified] В реестре российского ПО. URL: https://ru.wikipedia.org/wiki/Pyrus_(программное_обеспечение)
- Слабость: маршрутизация по **правилам/процессу**, не по компетенциям из реальной работы человека.

### Яндекс Трекер
- [verified] Автодействия: проверять задачи и назначать исполнителя, если не назначен. URL: https://yandex.ru/support/tracker/ru/automation
- [claimed, слабый сигнал] AI-агент-руководитель «назначает по загрузке и компетенциям», но на практике первые 2 недели назначал формально по загрузке — потребовалась **ручная разметка тегов компетенций** у исполнителей. URL: https://shtab.app/blog/tri-tipa-ai-assistentov-v-upravlenii-proektami/
- Вывод по Н2: matching задача↔компетенция в РФ **держится на ручной матрице компетенций / тегах**, не на авто-выводе кто-чем-занимается. URL: https://lovkiyya.ru/match-zadach-i-navykov-raspredelenie-po-kompetencijam/ ; https://www.bitrix24.ru/journal/raspredelenie-zadach-mezhdu-sotrudnikami/

**Главный пробел рынка / возможность Коры:** никто не выводит профиль компетенций сотрудника **автоматически** из его активности (встречи/чаты/решения/выполненные задачи). Все РФ-решения требуют ручной матрицы навыков или тегов → задача нужному человеку определяется людьми, не графом.

## Н3 — ассистенты, обучающиеся на обратной связи (правках)

- [claimed] GigaChat Enterprise — «самообучается на базе знаний и истории диалогов» (единственный явный РФ-claim, но не «учится на правках оператора»). URL: https://developers.sber.ru/help/gigachat-api/ai-assistant-for-business
- [verified] Рыночная боль зафиксирована: «боты учатся на ошибках, **только если кто-то их анализирует**»; типовой провал — запуск без обучения на своей БЗ и игнор логов первых недель. URL: https://vc.ru/ai/2913600-neyroseti-v-podderzhke (2026-05-06)
- [verified] «23% внедрений ИИ проваливаются — автоматизируют всё сразу без проверки гипотезы на реальных данных». URL: https://vc.ru/id1175613/2832067 (2026-03-30)
- Вывод: явного продукта «ассистент дообучается на правках пользователя автоматически» на РФ-рынке **не найдено**. Самообучение либо декларативно (Сбер), либо это ручной цикл «человек правит статью / анализирует логи» (Minerva, TEAMLY). Это **белое пятно**, совпадающее с фичей Коры (клоны/промпты учатся на DIFF без human-approval).

## Где РФ-продукты сильнее Коры
- Enterprise-доверие и инфра: Сбер/Яндекс — бренд, on-prem, готовые интеграции (1С), реестр ПО.
- UX доверия: istok.ai/Minerva — цитаты + ссылки на страницу, честные ответы только по данным.
- Зрелость KMS-редактора и ролевого доступа (TEAMLY, Minerva).
- Готовая фича распределения задач (Bitrix24) и маршрутизации (Pyrus) — у них уже в проде.

## Где Кора сильнее / отличие (для всех трёх Н)
- **Источник знаний:** авто-граф из событий (встречи/чаты/решения) vs у всех РФ — **ручная загрузка файлов / ведение wiki**. Ближе всех Контур.Толк/Таймлист/НаВстрече, но они дают «протокол → поиск», не связный граф + профиль.
- **Н2:** Кора может выводить компетенции сотрудника **автоматически** из активности → задача нужному; РФ держится на ручной матрице навыков/тегов.
- **Н3:** Кора — обучение клонов/промптов на DIFF без human-approval; РФ — либо декларативно (Сбер), либо ручной цикл.
- **Память при увольнении / клоны роли** — у РФ-конкурентов аналога не найдено.
