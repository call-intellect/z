# Design System: Z / Кора

## 1. Overview

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

**Creative North Star: «Современный пульт компании»**

Кора — это память компании, и интерфейс показывает эту память как живую панораму, а не как таблицу. Глубокая индиго-сланцевая основа с радиальными цветными «лужами» света (фиолет/синий) сверху создаёт ощущение объёмного пространства. На ней плавают стеклянные карточки (glass-карточки — полупрозрачные, с размытием фона), за которыми угадывается подсветка. Данные не лежат строками — они дышат: графики, шкалы, тренды.

Иерархия строится не плотностью, а ритмом размеров: крупный hero-визуал (главный график экрана) задаёт фокус, вокруг него — сетка поддерживающих карточек разного калибра, внизу — деталь или таблица. Экран читается как разворот журнала, а не как стопка одинаковых полос.

Цвет здесь работает, а не молчит. Фиолет→индиго — герой (главный акцент и заголовки), мята/бирюза/циан — фирменная нить Коры, янтарь/розовый/синий/красный — семантические категории и серии графиков. Каждая серия данных получает свой осмысленный hue, а не случайный.

**Key Characteristics:**
- Тёмная основа: индиго-сланец (`oklch(0.17 0.035 280)` → `oklch(0.13 0.025 275)`) с радиальными бликами фиолет/синий сверху
- Стеклянные карточки (glass): размытие (blur) + полупрозрачный градиентный фон + мягкая объёмная тень + верхний внутренний блик (inset highlight), радиус 20–22px
- Hero-градиент фиолет→индиго как главный акцент; мята/бирюза/циан — фирменная нить; янтарь/розовый/синий/красный — категории
- Богатая дата-виз через `recharts` (библиотека графиков React): area+градиент, radial-gauge, radar, donut, bars, heatmap, sparkline
- Единая гарнитура Geist; герой-число 30–40px/600, объём передаётся не только шрифтом, но и формой и светом
- Грамматика экрана: KPI-строка → hero-визуал → сетка поддержки → деталь/таблица; размеры разные, не стопка одинаковых блоков
- Тёмная тема — первая и единственная сейчас; светлая тема — отдельная фаза калибровки
- Источник правды по стилю — витрина-эталон `/redesign` ([frontend/app/(design-preview)/redesign/page.tsx](frontend/app/(design-preview)/redesign/page.tsx)) и токены [frontend/src/ui/components/dashboard/modern/tokens.ts](frontend/src/ui/components/dashboard/modern/tokens.ts)

## 2. Colors: Палитра современного языка

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

Три слоя цвета: **герой** (фиолет→индиго) задаёт фокус, **фирменная нить** (мята/бирюза/циан) держит узнаваемость Коры, **категории** (янтарь/розовый/синий/красный/лайм/оранжевый) кодируют серии данных и статусы. Все литералы — `oklch`, взяты 1-в-1 из объекта `CHART` в [tokens.ts](frontend/src/ui/components/dashboard/modern/tokens.ts) и витрины `/redesign`. Для градиентов `recharts` (`<stop stopColor>`) нужны именно литеральные цвета, а не CSS-переменные.

### Hero (фиолет→индиго)
- **Фиолет** (`oklch(0.66 0.2 300)`): Главный акцент. Заголовки-чипы, hero-визуалы, первичные действия, активные состояния.
- **Индиго** (`oklch(0.62 0.2 278)`): Вторая точка hero-градиента, вторая серия в графиках.
- **Hero-градиент чипа** (`linear-gradient(135deg, oklch(0.7 0.2 300), oklch(0.58 0.2 268))`): иконка-чип заголовка карточки, ключевые KPI-иконки.

### Brand thread (фирменная нить Коры)
- **Мята** (`oklch(0.85 0.15 165)`): Позитив, успех, статус «ок», основная brand-серия. Заменяет прежний «Сигнальный минт» — теперь это часть полной палитры, а не единственный голос.
- **Бирюза** (`oklch(0.82 0.13 178)`): Связующая серия, вторичный позитив.
- **Циан** (`oklch(0.8 0.13 205)`): Третья brand-серия; в bars-градиенте циан→фиолет.

### Category hues (серии графиков, чипы, статусы)
- **Синий** (`oklch(0.7 0.16 245)`): Info, нейтральная серия.
- **Лайм** (`oklch(0.86 0.19 130)`): Рост, дополнительная позитивная серия.
- **Янтарь** (`oklch(0.84 0.16 80)`): Warning, статус «внимание».
- **Оранжевый** (`oklch(0.74 0.18 50)`): Акцент категории, переход янтарь→красный.
- **Розовый** (`oklch(0.74 0.2 350)`): Категория, выделение, hero-вариант чипа.
- **Красный** (`oklch(0.66 0.22 25)`): Danger, статус «риск».

### Surfaces (стекло + фон страницы)
- **Стеклянная карточка** (`linear-gradient(180deg, oklch(0.3 0.035 280 / 0.55), oklch(0.22 0.03 278 / 0.5))`): полупрозрачный градиентный фон карточки; поверх — `backdrop-filter: blur(14px) saturate(1.3)`.
- **Рамка стекла** (`oklch(1 0 0 / 0.08)`): тонкая светлая граница 1px по периметру карточки.
- **Фон страницы**: индиго-сланец `linear-gradient(180deg, oklch(0.17 0.035 280), oklch(0.13 0.025 275))` + два радиальных блика сверху (`radial-gradient(... oklch(0.3 0.09 290 / 0.55) ...)` фиолет слева, `oklch(0.28 0.08 235 / 0.45)` синий справа). См. `MODERN_PAGE_BG` в tokens.ts.

### Text
- **Основной текст** (`oklch(0.97 0.01 280)`): Заголовки, hero-числа, основной контент.
- **Вторичный текст** (`oklch(0.74 0.02 280)`): Подписи осей, описания, вторичные метки.
- **Третичный/faint** (`oklch(0.58 0.02 280)`): Подписи 11–12px, вспомогательный текст, неактивные деления.

### Named Rules
**Правило семантики серий.** Каждая серия данных получает осмысленный hue по смыслу (позитив → мята/лайм, внимание → янтарь, риск → красный, нейтраль → синий/индиго), а не случайный цвет. Дробить палитру на серии — да; раскрашивать ради красоты — нет.

**Правило статус-тонов.** Статусы кодируются парой «текст + фон-плашка» из `STATUS_TONE`: ок → мята на `oklch(0.85 0.15 165 / 0.14)`, внимание → янтарь на `oklch(0.84 0.16 80 / 0.14)`, риск → красный на `oklch(0.66 0.22 25 / 0.16)`.

**Правило hero-фокуса.** Фиолет→индиго ведёт глаз к главному на экране (hero-визуал, заголовок). Не размазывать hero-градиент по всем элементам — иначе фокус теряется.

## 3. Typography

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

**Display Font:** Geist Sans (fallback: system-ui, sans-serif)
**Body Font:** Geist Sans
**Mono Font:** Geist Mono (fallback: JetBrains Mono, monospace)

**Character:** Единая гуманистическая гротескная гарнитура Geist. Иерархия строится на масштабе, весе и роли в грамматике экрана. Отрицательный кернинг на крупных размерах добавляет весомость. Hero-числа на дашбордах — крупные (30–40px / 600), они якорят карточку KPI и hero-визуал.

### Hierarchy
- **Display** (700, 48px, lh 1.05, –0.025em): Hero-заголовки, splash-экраны. Используется редко.
- **Headline** (600, 32px, lh 1.15, –0.02em): Заголовки крупных секций, пустые состояния, подтверждающие экраны.
- **Hero-число** (600, 30–40px): Главное значение KPI-карточки и центр donut/gauge. Рядом — дельта (рост/спад) и спарклайн.
- **Title** (600, 20px, lh 1.3, –0.01em): Заголовки карточек, модальных окон, боковых панелей. На дашбордных glass-карточках заголовок — 15px/600 рядом с градиентным иконка-чипом.
- **Body** (400, 14px, lh 1.5): Основной текст интерфейса. Максимальная длина строки — 65-75ch.
- **Label** (500, 12px, lh 1.4): Навигационные пункты, метки фильтров, статусы, подписи.
- **Faint** (400–500, 11–12px, цвет `oklch(0.58 0.02 280)`): Подписи осей графиков, мелкие сноски, неактивные деления.
- **Mono** (400, 13px, lh 1.45): Транскрипты встреч, временны́е метки, технические идентификаторы.

### Named Rules
**Правило весового контраста.** Между соседними уровнями иерархии — минимум 1.25× разницы в размере или переход в font-weight. Hero-число должно явно доминировать над подписью.

**Правило моноширинного контекста.** Mono-шрифт используется только для машинно-генерированного контента: транскрипты, ID встреч, временны́е метки. Никогда как декоративный или акцентный элемент.

## 4. Elevation: Стекло и объём

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

Глубина теперь — часть языка, а не запрет. Карточки физически приподняты над фоном: объёмная тень, размытие фона за стеклом и верхний внутренний блик создают ощущение слоистого пространства. Базовый рецепт собран в хелпере `glass()` ([tokens.ts](frontend/src/ui/components/dashboard/modern/tokens.ts)) — он применяется на все дашбордные карточки.

### Рецепт стеклянной карточки (`glass()`)
- **Фон:** `linear-gradient(180deg, oklch(0.3 0.035 280 / 0.55), oklch(0.22 0.03 278 / 0.5))` — полупрозрачный, чтобы сквозь стекло проступал фон страницы.
- **Рамка:** `1px solid oklch(1 0 0 / 0.08)` — тонкая светлая кромка.
- **Радиус:** 22px (`rounded-xl`); допустимо 20px для компактных карточек.
- **Тень + блик:** `0 1px 0 0 oklch(1 0 0 / 0.06) inset` (верхний внутренний блик) `, 0 18px 40px -18px oklch(0.05 0.05 280 / 0.9)` (мягкая объёмная тень вниз) `, 0 2px 8px oklch(0.05 0.05 280 / 0.4)` (контактная тень).
- **Размытие:** `backdrop-filter: blur(14px) saturate(1.3)` (+ `-webkit-` префикс).

### Shadow / Glow Vocabulary
- **glass-rest:** базовый рецепт выше — карточка в покое уже объёмная.
- **glass-hover:** при hover усиливается тень и/или появляется лёгкий цветной glow (свечение) hue карточки. Движение мягкое (`transform: translateY(-1px)`), без резкости.
- **ai-glow:** карточки AI-инсайтов (`AiCard`) несут отдельное цветное свечение (фиолет/индиго) как маркер «это сгенерировано Корой».
- **accent-focus:** для клавиатурной навигации (`:focus-visible`) — кольцо в hero-фиолете `0 0 0 3px oklch(0.66 0.2 300 / 0.3)`.
- **modal:** диалоги — самая тяжёлая тень + затемнённый backdrop.

### Named Rules
**Правило «Объём по умолчанию».** Дашбордные карточки приподняты и стеклянны в покое — это норма нового языка, а не реакция на состояние. Плоские блоки без тени и размытия на дашбордах — отклонены владельцем.

**Правило лимита blur-слоёв.** `backdrop-filter` дорог для GPU: не вкладывать стекло в стекло без нужды, держать число одновременных blur-слоёв на экране умеренным, предусмотреть fallback для слабых машин и `prefers-reduced-transparency` (см. Ф5 ТЗ редизайна).

## 5. Components

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

### Buttons

Тактильные и мгновенные. Каждый вариант несёт чёткую ролевую нагрузку; смешивать роли запрещено.

- **Shape:** Слегка скруглённые (8px, `rounded-sm`)
- **Primary:** hero-градиент фиолет→индиго (`linear-gradient(135deg, oklch(0.7 0.2 300), oklch(0.58 0.2 268))`) + `text-accent-fg` (`oklch(0.97 0.01 280)`). Padding 0 16px, height 36px. Hover: лёгкий glow в фиолете. Нажатие: `scale(0.98)` за 75ms.
- **Secondary:** полупрозрачная стеклянная подложка + тонкая граница `glass-border`. Hover: фон чуть светлее.
- **Outline:** `border` в фиолете + `text` фиолет, прозрачный фон. Hover: лёгкая фиолетовая заливка.
- **Ghost:** `text-secondary`, без фона и границы. Hover: полупрозрачная подложка + `text-primary`.
- **Destructive:** `bg-danger/15` + `border-danger/30` + `text-danger` (красный `oklch(0.66 0.22 25)`). Hover: `bg-danger/25`.
- **Focus:** `ring-2` в hero-фиолете + тень `accent-focus`. Всегда через `:focus-visible`.

### Chips / Badges

Семантические пары тон-на-тон. Смысл несёт только цвет; форма нейтральна.

- **Style:** `rounded-md` (12px), полупрозрачный фон + fg того же hue. Семантические роли из палитры: ок → мята (165), внимание → янтарь (80), риск → красный (25), info → синий (245), категории → фиолет/индиго/циан/розовый/лайм.
- **Status-пилюли (`StatusPill`):** пара «текст + фон» из `STATUS_TONE` — ок/внимание/риск.
- **Dark theme:** фон через overlay opacity (~14–16%), fg — насыщенный вариант того же hue из `CHART`.
- **Light theme:** отдельная фаза калибровки (пока не задизайнена).

### Cards / Containers — стеклянные карточки

Объёмные стеклянные контейнеры — основа дашбордов. Базовый компонент — `GlassCard`; рецепт — хелпер `glass()`.

- **Corner Style:** Сильно скруглённые (22px, `rounded-xl`; 20px для компактных)
- **Background:** полупрозрачный градиент `linear-gradient(180deg, oklch(0.3 0.035 280 / 0.55), oklch(0.22 0.03 278 / 0.5))`
- **Blur:** `backdrop-filter: blur(14px) saturate(1.3)` — сквозь стекло проступает фон страницы
- **Shadow + блик:** объёмная тень `0 18px 40px -18px ...` + верхний внутренний блик `inset 0 1px 0 oklch(1 0 0 / 0.06)` + контактная тень
- **Border:** `1px solid oklch(1 0 0 / 0.08)` — тонкая светлая кромка
- **Hover:** усиление тени и/или цветной glow hue карточки, мягкий `translateY(-1px)`
- **Internal Padding:** 24px (`p-6`)
- **Заголовок карточки:** компонент `CardTitle` — градиентный иконка-чип (hero/teal/amber/pink) + заголовок 15px/600

### Inputs / Fields

Ясные и спокойные на фоне насыщенных дашбордов.

- **Style:** тонкая граница `glass-border` + полупрозрачная подложка + `rounded-md` (12px). Текст `text-primary`, placeholder — `text-secondary`.
- **Focus:** `ring-2` в hero-фиолете + граница смещается в фиолет. Строго через `:focus-visible`.
- **Error:** `border-danger` (красный) + hint-текст `text-danger` под полем.
- **Disabled:** `opacity-50 cursor-not-allowed`.

### Navigation

App Shell: sidebar (248px, collapsed до 64px) + header (64px).

- **Typography:** Label (12px, 500) для пунктов меню
- **Active state:** `text` в hero-фиолете + полупрозрачная фиолетовая подложка. Допустима ведущая иконка-чип; цветная `border-left`-полоса не нужна — фокус держит подложка.
- **Hover:** полупрозрачная подложка + `text-primary`
- **Collapsed:** только иконки, tooltip при hover показывает название
- **Mobile:** Sheet (Radix) снизу или слева; transition `ease-out-quart` 200ms

### Дата-виз (Signature) — графики на recharts

Главная подпись нового языка дашбордов: данные показываются графиками, а не строками. Все построены на `recharts` (библиотека графиков React, в проекте `^3.8.1`) и вынесены в переиспользуемые компоненты `modern/*`. Палитра серий — из `CHART` (oklch-литералы; CSS-переменные в `<stop>` не работают).

- **Area + градиент (`AreaTrend` / `AreaHero`):** тренд с заливкой `linearGradient` от `0.45` к `0`. Hero-вариант — крупный главный график экрана.
- **Radial-gauge (`GaugeCard`):** `RadialBarChart` 210°→−30° с градиентной дугой; в центре — hero-число.
- **Radar (`RadarCard`):** профиль/срез по осям, залитый полупрозрачный полигон.
- **Donut (`DonutCard`):** `paddingAngle=3` + центр-лейбл со значением.
- **Bars (`BarTrend`):** столбцы `radius=[8,8,0,0]`, градиент циан→фиолет.
- **Heatmap (`Heatmap`):** сетка div-ячеек, opacity по интенсивности + glow на пике.
- **Sparkline:** мини-тренд внутри `StatCard` рядом с hero-числом и дельтой.
- **Tooltip/легенда:** `ChartTip` (стеклянный tooltip) + `Legend`.
- **Важно (recharts-измерение):** контейнеру задавать явную высоту и `minWidth={0}`, иначе ловятся `width(-1)` warnings (на витрине графики восстанавливались, но в проде это убираем).

### Граф знаний

Граф связей сущностей остаётся ключевым продуктовым UI и переезжает на стеклянный язык: узлы — компактные стеклянные карточки с заголовком сущности, связанные рёбрами.

- **Node в покое:** `GlassCard`-стиль (полупрозрачный градиент + рамка `glass-border`), `rounded-xl`
- **Node hover:** усиление тени + цветное свечение на рёбрах связи (фиолет/мята)
- **Node active:** фиолетовая подложка + рамка в hero-фиолете
- **Edges (рёбра):** полупрозрачный нейтральный stroke в покое; при hover узла — подсветка в hero-фиолете

### Библиотека компонентов (`src/ui/components/dashboard/modern/`)

Переиспользуемый словарь нового языка живёт в [frontend/src/ui/components/dashboard/modern/](frontend/src/ui/components/dashboard/modern/). Все боевые дашборды собираются из него — не из ад-хок-вёрстки.

- **Каркас:** `GlassCard` (стеклянная карточка), `CardTitle` (градиентный иконка-чип + заголовок).
- **KPI:** `StatCard` (иконка-градиент + hero-значение + дельта + спарклайн), `AiCard` (карточка AI-инсайта с glow).
- **Графики:** `AreaTrend`, `BarTrend`, `GaugeCard`, `RadarCard`, `DonutCard`, `Heatmap`.
- **Вспомогательное:** `ChartTip` (стеклянный tooltip), `Legend`.
- **Таблица:** `ModernTable` (+ `Avatar`, `ProgressBar`, `StatusPill`, тип `ModernTableColumn`) — аватар + прогресс-бар + статус-пилюля.
- **Токены/хелперы:** `CHART` (палитра серий), `GRAD` (градиенты-чипы), `glass()` (рецепт стекла), `MODERN_PAGE_BG` (фон страницы), `STATUS_TONE` (тона статусов).

## 6. Do's and Don'ts

> Визуальный язык обновлён 2026-06-08 (редизайн «современный»: стекло/градиент/объём/дата-виз). Старый «Нервный центр» (плоский) отклонён владельцем.

### Do:
- **Do** строить дашборды по грамматике: KPI-строка → hero-визуал → сетка поддержки → деталь/таблица. Размеры карточек разные, не стопка одинаковых полос.
- **Do** показывать данные графиками (`recharts`), а не текстовыми строками: area+градиент, gauge, radar, donut, bars, heatmap, sparkline.
- **Do** собирать экраны из библиотеки `modern/*` (`GlassCard`, `StatCard`, `GaugeCard`, …), а не из ад-хок-вёрстки.
- **Do** использовать стеклянные карточки (`glass()`) с blur + полупрозрачным градиентом + объёмной тенью + верхним внутренним бликом, радиус 20–22px.
- **Do** вести глаз hero-градиентом фиолет→индиго к главному на экране; фирменную нить (мята/бирюза/циан) и категории (янтарь/розовый/синий/красный) использовать осмысленно по семантике серий.
- **Do** копировать цвета графиков из `CHART` (oklch-литералы) — recharts-градиентам (`<stop>`) нужны литералы, не CSS-переменные.
- **Do** задавать графикам явную высоту и `minWidth={0}`, чтобы избежать `width(-1)` warnings.
- **Do** ограничивать длину строки тела текста диапазоном 65-75ch.
- **Do** анимировать только `color`, `opacity`, `transform`, `box-shadow`. Движение мягкое (hover: `translateY(-1px)`, glow).
- **Do** писать весь текст интерфейса по-русски. Кора — инструмент для российского рынка.
- **Do** соблюдать touch-target ≥40px для всех интерактивных элементов на мобильных (`min-h-10`).
- **Do** держать тёмную тему первой; светлая — отдельная фаза калибровки (после референсов владельца).
- **Do** сверяться с витриной-эталоном `/redesign` ([frontend/app/(design-preview)/redesign/page.tsx](frontend/app/(design-preview)/redesign/page.tsx)) — это источник правды по стилю.

### Don't:
- **Don't** возвращать плоские блоки без тени и стекла на дашбордах — это отклонённый владельцем «Нервный центр» («унылый Excel»).
- **Don't** раскрашивать серии графиков случайно: каждый hue несёт смысл (позитив/внимание/риск/нейтраль/категория).
- **Don't** размазывать hero-градиент фиолет→индиго по всем элементам — иначе теряется фокус экрана.
- **Don't** вкладывать стекло в стекло без нужды: `backdrop-filter` дорог для GPU — лимит blur-слоёв + fallback для слабых машин и `prefers-reduced-transparency`.
- **Don't** выстраивать однообразные сетки одинаковых карточек: иконка + заголовок + текст без вариации. Меняй калибр и тип визуала.
- **Don't** открывать модальное окно первым делом. Исчерпай inline- и прогрессивные варианты.
- **Don't** копировать корпоративный синий с кнопками везде (Bitrix24 / amoCRM-стиль) — это перегруженный интерфейс, не наш.
- **Don't** забывать про контраст: текст на градиентах/стекле должен держать WCAG AA.
- **Don't** использовать чистый `#000` или `#fff` — любой цвет с тинтом hue 280 (индиго).
