# Интерактивное демо кабинета Коры

Самодостаточная статическая витрина кабинета «Кора» для сайта: только HTML/CSS/JS, без бэкенда, сборки и сети.

**Как открыть:** двойной клик по `index.html` (работает из `file://`). Мобильная версия — `mobile.html`.

**Файлы:** `index.html` / `mobile.html` — экраны; `design-system.css` — стили и токены; `app.js` — единый движок взаимодействия; `demo-data.js` — данные демо-компании.

> Детальный README (встраивание на сайт, чек-лист консистентности) дополняется в Ф8.
