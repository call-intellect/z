# 05 — РФ-аналоги: как структурируют знания из встреч/переписок

## По игрокам
- **Таймлист** (1С:Совещание): транскрипт (~97%, спикеры+таймкоды) + авто-протокол (мысли/решения/задачи); база = все протоколы+транскрипты с полнотекст.+AI-поиском; автономно, реестр ПО №20728, данные в контуре. Источник — только встречи. → timelist.ru/vc.ru → claimed/triangulated(2). **Не граф**, нет «сути» поверх многих встреч, нет мульти-источника.
- **НаВстрече**: конспект по категориям (ход/решения/задачи/сроки/ответственные); источники — онлайн-ВКС + файлы, чаты НЕ интегрированы; цитирование таймкода не заявлено. → navstreche.com → verified/claimed. Протокол на одну встречу, не граф.
- **istok.ai**: документ-RAG, **цитата файл+стр.** («Finance_Q4.pdf · стр.14»), мульти-док-ответ, on-prem 152-ФЗ. Источники — документы (переписка как тип документа), встреча НЕ источник, графа нет. → istok.ai → verified. **Сильнее всех по цитированию.**
- **Контур.Толк** (раскрыт технически): транскрипт+LLM-саммари (решения+задачи); ASR FastConformer WER 11-17%, саммари Gemma 2 27B, ~10k встреч/день, таймкод-навигация. → habr skbkontur 928404 → verified. Плоский протокол, без графа/мульти-источника.
- **МТС Линк / VK / SaluteJazz(GigaChat)**: AI-протокол внутри ВКС (саммари/решения/задачи). → mts-link/sber → claimed. Не отдельный слой памяти, без графа.
- **Нестор.BRIEF (ЦРТ)**: гос/on-prem, поручения/сроки/исполнители, реестр №9023, Astra Linux. → speechpro.ru → claimed/verified. Плоский протокол, без графа/мульти-источника.

## Конфликт/неопределённость
- Граф знаний в РФ есть только как **методология/самопал** (Habr 974992, «Комплекс Медиа»: граф сущностей, wiki-ссылки `[[…]]`, источник в ответе) — но источники = интервью+Markdown, НЕ встречи/чаты; это «KB as Code» (LangChain/ChromaDB), не продукт. → verified.
- RU review-данных мало → «слабый сигнал».

## Главный вывод (дифференциация Коры)
Ни один РФ-игрок (2026-06-23) НЕ строит **единый граф из встреч + переписок** как продукт. Два лагеря: (а) транскрипт+протокол на встречу, (б) документ-RAG с цитатой (istok.ai). «Суть встречи как объект графа», «слияние встреч+чатов+решений», ролевые клоны — пустая ниша.
