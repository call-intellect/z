> Цель: пересмотреть «стенд сотрудника» по образцу того, как переделали дашборд руководителя (День/Неделя/Месяц компании). Метод — посадить за Кору 5 разных сотрудников (разные роли/интеллект/компании, не знающих друг о друге), собрать их обратную связь и прототипы первого экрана, свести в рекомендацию. Наглядная версия со всеми прототипами — в артефакте (ссылка выше).

# Стенд сотрудника — персона-исследование

## 1. Отправная точка (baseline по коду на 2026-07-06)

Директорский дашборд рядовому сотруднику НЕ показывают — с `/dashboard` его редиректит на `/me` ([DashboardRouter.tsx:22-24](../../frontend/app/(authenticated)/dashboard/DashboardRouter.tsx#L22-L24)). «Рядовой сотрудник» на фронте = роль `manager` (базовый неадминский член; `normalizeRole` в [nav-config.ts:424-426](../../frontend/src/ui/components/app-shell/nav-config.ts#L424-L426)), руководство отделено `LEADERSHIP_ROLES=[owner,admin,coo]`. Свой стенд у сотрудника есть, но собран неудобно:

- **Вход открывается на `/meetings`** (журнал видеовстреч), а не на «мой день» ([LoginForm.tsx:34-40](../../frontend/app/login/LoginForm.tsx#L34-L40)).
- **Actionable размазан по 5 экранам:** `/me` вкладка «Обзор» · `/me/daily-brief` («Твой день») · `/me/inbox` («Мои дела») · `/actions` («Требует вас») · `/me/check-ins` («Чек-ин»). Границы между ними не считываются.
- **Дефолтная вкладка `/me` «Обзор» — HR-профиль,** а не рабочий экран: баннер «заполните профиль/Telegram», «Моя должность», «Моя карта должности» (% полноты), «Моя польза за неделю» (4 виджета: план/факт · чем память помогла · судьба идей · благодарности), «Мои документы», «Мои встречи», лента Коры ([MeClient.tsx:125-176](../../frontend/app/(authenticated)/me/MeClient.tsx#L125-L176)).
- **Настоящий «Твой день»** (задачи на сегодня · под риском · кто знает) существует в [MyDailyBriefClient.tsx](../../frontend/app/(authenticated)/me/daily-brief/MyDailyBriefClient.tsx), но лежит спрятанным под-роутом и по умолчанию не открывается.
- **Клонов должностей в меню нет** (функция есть, вход только окольно через «Должности»). `coo`/`hr_partner` тоже редиректятся на `/me` — проверить, ожидаемо ли.

Итог: стенд «HR-профильный», а не «рабочий»; первый экран не отвечает на «что мне сегодня делать и что от меня ждут».

## 2. Пять персон (метод)

Независимый fan-out, спред от «самого простого» до системного:

| Персона | Роль · компания | Склад | Вердикт |
|---|---|---|---|
| **Ирина** | офис-админ · стоматология 12 чел. | нетехническая, боится софта | слишком много |
| **Дмитрий** | продажи B2B · оборудование 30 чел. | прагматик, живёт в CRM | слишком много |
| **Аня** | продакт · IT-продукт 60 чел. | системный мыслитель | слишком много |
| **Костя** | backend-dev · аутсорс 25 чел. | минималист-скептик | слишком много |
| **Марина** | маркетолог/SMM · e-commerce 18 чел. | про причастность/признание | слишком много |

Все пятеро независимо вынесли вердикт «слишком много» и дословно назвали одни и те же корневые проблемы (см. §3).

## 3. Что хотят ВСЕ пятеро (пересечение — берём в каркас)

1. **Единый первый экран «Сегодня» на входе** вместо журнала встреч (все пятеро: `/meetings` как домашняя = абсурд).
2. **Свести 5 actionable-экранов в ОДИН** (Обзор/Твой день/Мои дела/Требует вас/Чек-ин) — дословно главная претензия каждого.
3. **Очередь «ждут ответа / ты обещал» с подсветкой просрочки** — общая боль №1 (Ирина «ты обещала перезвонить», Дмитрий «забытый follow-up = потерянная сделка», Аня «мои обещания», Костя «кого не подвесить», Марина «что ждут ответа»).
4. **Задачи на сегодня с чекбоксом — закрыть прямо тут**, без прыжков по вкладкам.
5. **Прибитая сверху строка «Спросить Кору»** с ответом по источникам — единственная функция, которую хвалят все пятеро.
6. **Короткое меню 5–6 пунктов** вместо простыни; журнал встреч и справочники руководителя — вон со старта.

## 4. Где роли расходятся (решаем одним адаптивным слотом)

- **Ирина (админ):** тупо-простой список с галочками, БОЛЬШИЕ кнопки, ввод голосом/из WhatsApp, чек-лист заказов, «перенести на завтра». Потолок навигации — 3 кнопки. Встречи/память/граф/клоны — убрать полностью.
- **Костя (инженер):** «молча вытащи задачи и не мешай». Минимум, чекбоксы на месте, авто-задачи из встреч с молнией+ссылкой на расшифровку, ОДИН тумблер тихого режима, Cmd+K. HR-театр (польза/пульс/благодарности) — аллергия.
- **Дмитрий (продажи):** живёт КЛИЕНТАМИ — разрез «решили → обещал → следующий шаг → дата», follow-up с просрочкой, связка с Битрикс24, после звонка в один тап «шаг + напоминание».
- **Аня (продукт):** нужны СВЯЗИ, не список — «решение → задача → исполнитель → статус → блокер», доска фич «где застряло и кто держит», пометка «решение повисло без задачи».
- **Марина (маркетинг):** ПРИЧАСТНОСТЬ — блок «тебя касается: решения руководства», лента «что важно компании», вклад за неделю на видном месте. **Прямое столкновение с Костей** (он это требует убрать) → решается тумблером (см. §6, развилка 2).

## 5. Рекомендация — минимальный стенд сотрудника

**Первый экран «Сегодня», сверху вниз:**
0. Прибитая строка «Спросить Кору» (цитаты-источники, не уводит со страницы).
1. «Ждут ответа / ты обещал» — короткая очередь, просрочка красным.
2. «Сегодня» — задачи с чекбоксами; авто из встреч помечены молнией+ссылкой на источник; крупная «+ добавить дело» (голос/мессенджер).
3. Адаптивный ролевой блок (один слот по данным сотрудника): продажи → клиенты; продукт → блокеры+«решение без задачи»; маркетинг → «тебя касается»; админ → чек-лист; инженер → «новое из встреч»+тихий режим.
4. Встречи сегодня — компактной строкой (у кого есть), не журналом; вход в AI-отчёт.
5. Вечерний хвост (сворачиваемый): «перенести на завтра» + мягкий вклад/причастность.

**Показываем / прячем / убираем:**
- **Показываем** (первый экран): очередь ждут/обещал; задачи+чекбокс+источник; «+добавить»; строка «Спросить»; ролевой блок; компактные встречи.
- **Прячем за клик** (не удаляем — упрощаем=оптимизируем): память/12 областей/реестры как справка через «Спросить»; клоны как «Спросить клон»; задачи-доска целиком; встречи-журнал.
- **Убираем в профиль** (под аватар, вне навигации): карта должности+%; «Моя польза за неделю»; благодарности; «чем полезен/помогаю коллегам»; пульс/настроение; баннеры «заполни профиль».

**Ритм дня:** утро — экран сам собирает картину (что горит + обещания + авто-задачи со вчерашних встреч + «тебя коснулось решение»); день — скорость ввода/закрытия, нуджи приглушены; вечер — «перенести на завтра», авто-чек-ин из закрытых задач, мягкий дайджест вклада.

**Навигация:** узкая панель 5–6 пунктов (Сегодня · Задачи · Спросить · Память · ролевой · 👤); «Спросить» прибита сверху везде; Cmd+K для технических; «простой режим» (3 кнопки) для нетехнических; клоны → «Спросить клон».

**Два пресета плотности:** «плотный/системный» (продажи/продукт/инженер — ролевой блок, статусы, Cmd+K) и «простой» (админ/нетехнические — 3 большие кнопки, крупные чекбоксы, без встреч/памяти).

## 6. Развилки для владельца (каждая с рекомендацией)

1. **Ролевой блок — подтипы или по данным?** Рекомендую: не плодить роли, один «слот» по признакам данных (карточки клиентов/Битрикс → клиентский; фичи с блокерами → продуктовый; входящие решения → «тебя касается») + ручной выбор вида. MVP — эвристика.
2. **Вклад/признание на главной (Марина ↔ Костя):** Рекомендую по умолчанию НЕ на первом экране, но включаемый блок + вечерний дайджест; для нетехнических развёрнут, для инженерных свёрнут; тумблер в профиле.
3. **Тихий режим нуджей:** Рекомендую глобальный тихий режим с белым списком «тебя реально ждёт человек» (обещания/прямые вопросы всегда проходят, авто-нуджи глушатся).
4. **Простой vs плотный режим:** Рекомендую два пресета, авто-выбор по роли + ручное переключение.
5. **Ввод голосом/из мессенджера:** Рекомендую MVP — inline «+добавить» + голос; следом приём задач из Telegram/WhatsApp/Slack как источник.
6. **Чек-ин:** Рекомендую убрать как отдельный маршрут, собирать план↔факт авто из закрытых задач + опц. строчка вечером (Дмитрий/Костя: ручной чек-ин = двойная работа).
7. **Заказы-чек-лист (кейс Ирины):** Рекомендую не спецсущность, а тип личной задачи «список-чеклист» со статусом «уже сделано».
8. **Клоны в навигации:** Рекомендую как «Спросить клон должности» внутри «Спросить».

## 7. Чем это отличается от сегодняшнего

Вход /meetings → «Сегодня»; 5 экранов → 1; дефолт HR-профиль → рабочий экран (HR под аватар); спрятанный «Твой день» → он и есть первый экран; меню ~20 → 5–6+слот; задачи плоско → с источником/статусом/блокером; «Спросить» из /chat → прибита везде; клоны нет в меню → «Спросить клон»; чек-ин-обязаловка → авто-сборка; один обрезанный экран всем → ролевой блок + 2 пресета плотности.
