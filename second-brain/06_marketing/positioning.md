# Позиционирование — Z / Кора

> Финальная формулировка зафиксирована 2026-05-20 после виртуального GTM-обсуждения (4 круга, 6 ролей + 4 арбитра). История — в [[../../plans/analysis/2026-05-20-gtm-debate/2026-05-20-gtm-debate-history|GTM debate history]]. Головной документ — [[../../plans/analysis/2026-05-20-gtm-700m|GTM 700M]].

## Категория

**«Память компании»** — единственный лейбл на лендинге, в PR и продажах. Дисциплинированно везде.

Оболочки нарратива по контексту:
- **«Второй мозг компании»** — для PR/контента/блога/конференций.
- **«Институциональная память бизнеса»** — для инвесторов и формальных документов.

## Бренд

- Текущее имя: **Z**.
- Ребрендинг: **Z → Кора** (kora.tech). Дата запуска ребренда — **M9-M12 (Q4 2026 - Q1 2027)**, одна PR-волна с раундом А.
- Запасные имена: Memora (безопасный), Mneme (премиум).
- Tagline: **«Память вашей компании»**.

## Positioning statement (универсальный, один для всех ICP)

> Для CEO и руководителей компаний 50-300 человек, которые **выросли быстрее своей памяти** и теряют контекст при увольнениях и фрагментации,
>
> **Кора — это память компании**, которая автоматически собирается из встреч, чатов и решений в единый граф знаний и помнит за всю команду.
>
> В отличие от AI-нотакеров (mymeet, Контур.Толк, Я.Телемост), которые дают саммари одной встречи, **мы строим память всей компании**.

## Hero на лендинге

- **Headline:** «Память вашей компании. То, что было сказано, решено и сделано — теперь не теряется.»
- **Sub:** «Кора слушает встречи, читает чаты и собирает решения в единую память. Когда кто-то увольняется — его знания остаются.»
- **3 benefit:**
  1. «Ничего больше не пропадает» — каждая встреча, каждое решение, каждый клиентский контекст становятся частью графа.
  2. «CEO видит компанию за 30 секунд» — дашборд директора показывает горячие сигналы, активные темы, согласованность с целями.
  3. «Знание остаётся в компании, а не уходит с людьми» — Employee Clone сохраняет stylistic profile и personal subgraph.

## Ключевые отличия от конкурентов

| Что делаем | Почему это важно |
|---|---|
| 9 типов встреч × специализированных шаблонов AI-отчётов | Конкуренты дают одинаковое саммари для всех встреч |
| Event-sourced Knowledge Core + per-Org граф знаний | Per-Org граф растёт с накоплением данных, конкурент не может скопировать |
| Отдельные аудиодорожки на каждого участника | Диаризация ≥90% (vs 70-75% у mymeet) |
| Гость без регистрации | Нет трения для внешних участников |
| 152-ФЗ + Реестр Минцифры compliance by design | Granola/Sentra/Viven в РФ юридически не зайдут |
| On-prem на 100% российском open-source стэке (GigaAM + T-Pro 32B) | Self-hosted для enterprise и B2G без vendor lock-in |
| Per-Org Memory-as-a-Service через MCP (M12-M18) | Distribution через AI-агенты Cursor/Claude/западные dev-маркетплейсы |

## Антинарратив — против чего НЕ позиционируемся

- **НЕ против Сбера/Яндекса** — мы partner / orthogonal через LlmRouter.
- **НЕ против Bitrix24 / amoCRM** — мы дополняем их через двустороннюю интеграцию.
- **НЕ против Notion / TEAMLY** — мы не PKM, мы memory layer для AI-агентов.
- **НЕ против AI-агентов** — мы memory layer для них (MCP-server).

Sales-говорилка: «mymeet даёт 100 саммари в месяц. Кора даёт одну живую память.»

## Готовые ответы на топ-5 возражений

| Возражение | Ответ |
|---|---|
| «У нас уже есть Я.Телемост / Сбер с AI» | Они дают саммари. Кора строит память — граф клиентов/проектов/решений, который вы запрашиваете на любой вопрос компании. |
| «Боимся утечки в облако» | Реестр Минцифры (M9-M12), on-prem GA (M18) на 100% российском стэке. Сервера в РФ-юрисдикции с M6 (single-tenant private cloud). |
| «Дорого vs Контур.Толк» | Контур даёт 1 саммари. У нас — память на 700+ встреч и роллап в CRM-карточку клиента. ROI 1.5 мес на 250-чел компании. |
| «А что если Сбер сделает такое же?» | Сбер строит общую память LLM-аккаунта, не per-Org граф. Архитектурно — другая ставка. Окно 12-18 мес. |
| «У нас уже CRM (Bitrix24/amoCRM)» | Двусторонняя интеграция: встречи Коры → задачи Bitrix24, контакты Bitrix24 → Card Коры. Дополняем, не заменяем. |
