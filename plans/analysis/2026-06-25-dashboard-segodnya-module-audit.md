## Системные проблемы дашборда «Сегодня»

1. **Двойная загрузка.** Весь набор запросов выполняется дважды за один заход; `director?period=week` дёргается 4–5 раз. Лишние ререндеры → тормоза, ощущение «висит».
2. **Схлопнутые графики** (Recharts). Консоль: `width(-1) height(-1) of chart` — контейнеры без minHeight → пустые тёмные полосы вместо диаграмм. Это и есть «пустые места».
3. **Рассинхрон одинаковых метрик.** «Польза» (month) 18/30/64 vs week 11/15/37; цель считается в `director.goalsCount=1`, но `goalsTree=[]`, `goalVector.goalId=null`; «Решения 0 из 0» vs «16 застряли».
4. **Перегруз длинными лентами.** «Что зависло» (20), «Решения» (16), «Идеи» (22) — без приоритизации и лимитов, страница на 5–6 экранов. Противоречит слогану «за 30 секунд».
5. **Дублирование между ритмами.** Модули 5–9 (Что зависло / Идеи / Решения / Лента / Польза) + План-факт повторяются 1-в-1 на «Сегодня», «Неделе», «Месяце».
6. **Нет drill-down к содержанию плана/отчёта.** «План и факт» даёт только счётчики; экрана «что человек запланировал → какие задачи → что в отчёте» в продукте нет (эндпоинты содержания 404).

## Рекомендации по «Сегодня» (приоритет)
1. Починить связку с целью (модуль 2) — подхватывать активную цель / CTA «подтвердите».
2. «План и факт» — формула «сдали/ожидалось/всего», единый источник «кто отметился», ссылка на содержание чек-ина.
3. Recharts minHeight — убрать пустые полосы.
4. Лимиты топ-5 + «показать все» для модулей 5/6/7; скрыть «Без темы», дедуп идей.
5. Привести «Польза за период» к периоду экрана (день/неделя), а не месяц.
6. Убрать двойную загрузку; не повторять одни и те же модули на трёх ритмах.
