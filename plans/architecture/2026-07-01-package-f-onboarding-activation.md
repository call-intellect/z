# Пакет F — DEMO-режим (pay-to-use)

> **Важно:** первоначальная версия этого пакета предлагала «trial-окно наполнения» (`billing.trial_days`). Владелец уточнил модель — **эта идея снята**. Ниже — верная модель.

## Решённая модель монетизации (владелец, 2026-07-01)
- **Нет trial. Нет бесплатных дней.** Пока компания не оплатила — **пользоваться (наполнять свой кабинет) нельзя вообще**.
- Что получает неоплативший — **DEMO-режим: заранее заполненный showcase-кабинет** (образцовая компания с готовыми данными), только чтобы **посмотреть и понять ценность**, не работать в нём.
- Оплатил → получает свой (пустой) рабочий кабинет и наполняет его.

## Что это значит для N16 (биллинг-гейт)
**N16 — корректен и намеренен. Действий по коду нет.** Гейт `canCreate = status === 'ACTIVE'` (DEMO = read-only + paywall) — это и есть задуманная pay-to-use модель, не баг и не «активационный блокер», который надо смягчать. Прежняя рекомендация «trial-окно» — **снята**. Крутилка `billing.trial_days` — **не вводится**.

## Реальный рычаг активации — качество DEMO showcase-кабинета
Раз неоплативший видит именно заполненный образцовый кабинет, ценность продаёт **богатство и правдоподобие этого демо-контента** (готовые встречи, граф, «письмо COO», трекер). Это то, что надо сделать сильным.

**Задача (ОТЛОЖЕНО, «позже» — по слову владельца):** перезалить/обновить содержимое DEMO showcase-кабинета — качественный обезличенный образец (у нас уже есть богатая синтетическая «Стрела» как основа). Вне текущего объёма фиксов A–E.

## Итог
