## Чему научился

1. **Prisma: JSON `null` (JsonNull) ≠ SQL NULL (DbNull).** Колонка, добавленная миграцией без DEFAULT,
   у существующих строк = **DbNull**. Фильтр `{ equals: Prisma.JsonNull }` матчит ТОЛЬКО JSON-литерал
   `null`, не DbNull → backfill находил 0 таблиц → **фича была бы no-op на всех существующих Org**.
   Юнит-тесты с моками это НЕ ловят (мок отдаёт данные напрямую). Поймал только адверсариальный ревьюер.
   Урок: **любой код, пишущий строки в тенант, — под адверсариальное ревью**; для «непустой JSON»
   грузить безусловно или `OR:[JsonNull, DbNull]`. Кандидат в `code-pitfalls`.
2. **Не доверять картографии для значений enum.** Explore-агент дал `IdeaBlockStatus` как
   `draft/active/archived/merged/superseded` — на деле `draft/canonical/merged_into/archived`. Я
   заложил это в брифинг → кодер написал `status: { notIn: ['merged','superseded','archived'] as never[] }`
   (несуществующие значения; `as never[]` заглушил ошибку типов; спасал только `mergedIntoId:null`).
   Урок: значения enum сверять из `schema.prisma` напрямую (`sed -n '/enum X/,/}/p'`), не по summary;
   `as never[]` в Prisma-фильтре — красный флаг замаскированной ошибки.
3. **Составной unique ломает cursor-пагинацию по одному полю.** `IdeaBlock` имеет `@@unique([id,tenantId])`
   → `IdeaBlockWhereUniqueInput` требует `id_tenantId`, а `cursor: { id }` не типизируется (Goal/Experiment
   прошли бы). Решение — offset-пагинация (`skip`/`take`, модель-агностично). typecheck поймал (vitest
   пропустил — не тайпчекает).
4. **Дедуп без UNIQUE-индекса = дубли при гонке.** `findFirst`→`create` без транзакции: два параллельных
   вызова оба увидят null. `@@unique` (Postgres допускает много NULL — ручные строки с `sourceObjectId=null`
   не конфликтуют) + ловля P2002 → fill-existing. Важно ДО event-триггеров.
5. **graphSync — детерминированный, без LLM** (маппинг полей граф-объекта → ячейки), в отличие от
   entitySync и enrich-LLM-пути. Рычаг recall = сам факт данных; связка с чатом уже была прошита —
   не переделывать готовое.
6. **Ship-On для reconcile-фичи:** одного backfill мало (owner-триггер), нужен крон (авто, eventual
   consistency), иначе `enabled=true` есть, а работать нечему (O1 ревью).
