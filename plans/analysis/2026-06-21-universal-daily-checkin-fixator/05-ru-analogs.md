# РФ-аналоги

## TL;DR
На рынке РФ **нет** массового продукта «сотрудники кидают отчёт в существующий рабочий чат → бот атрибутирует к человеку и показывает кто сдал/не сдал». Все идут одним из двух путей:
1. **Опросный путь** (Pulse bot, «боты-отчёты»): бот пишет в **личку**, собирает структурированный ответ, в группу публикует готовую сводку.
2. **AI-встречи** (НаВстрече, Таймлист, Кора): фиксируют созвон, не текстовые чат-отчёты.

Прямой захват свободного текста из общего чата с распознаванием автора/темы — только самопис по хештегам. **Это окно для Коры.**

## Кто решает «кинул отчёт → руководитель видит сводку»
- **Pulse bot** (ближайший): ежедневный стендап-опрос по GRS (goals/results/setbacks), 19:00 сбор фидбека, 20:00 сводка в группу. Сбор через личку бот↔сотрудник, атрибуция к человеку. Базово бесплатно; платно — 360°/оценка/on-prem. Telegram. [verified — vc.ru/tribuna/126414, статья 2020-05-12; слабый сигнал по актуальности]
- **«Боты-отчёты» (агентства/конструкторы):** ежедневный отчёт по проектам в боте → таблица; в 19:00 бот напоминает, повтор через 2ч; «не сдавших» тегают по username. Конструкторы BotHelp/BotPad/Jinn/BorisBot/imakebots → форма-опросник, выгрузка в Sheets/Excel/CRM. [claimed — vc.ru/id5404321, informbox.ru, bothelp.io, hr.jinn.ru]
- **Самописный «репост по хештегам»:** канал-лог + бот репостит из рабочего чата по хештегам — единственный реальный случай захвата из группы, но кастом, не продукт. [claimed]
- **Bitrix24 «Рабочие отчёты»:** сотрудник пишет отчёт за день/неделю, руководитель утверждает/возвращает, периодичность + сводки. Но внутри Битрикса, не из Telegram-чата. [claimed — helpdesk.bitrix24.ru/open/17875598]
- **НаВстрече / Таймлист / Shtab — соседи, НЕ про чат-отчёты:** НаВстрече — AI-расшифровка встреч [verified navstreche.com]; Таймлист — AI-транскрибация встреч, тарифы поминутные (10ч/4500₽·год, 50ч/22000₽, 100ч/42000₽) [verified timelist.ru/pricefl]; Shtab — таск-трекер, AI-сводки из задач/трекинга, не из чата [claimed shtab.app].
- **Standuply** поддерживает русский, но это западный опросный бот, не «забор из RU-Telegram-группы». [claimed stackshare.io]

## Отсев
- **Планёрка.app** — календарь/бронирование встреч, отчёты не собирает. [verified planerka.app]
- **Yoolla, Aktivo** — как «фиксаторы отчётов» не подтверждены. [inferred, weak]

## Атрибуция / личка vs группа / забор
| Решение | Атрибуция | Личка/группа | Забор раз в сутки | Тег |
|---|---|---|---|---|
| Pulse bot | да, к человеку, в группу сводка | сбор в личке, публикация в группу | да (опрос+19:00+20:00) | [verified] |
| «Боты-отчёты» | да (по user) | личка/форма; редко репост по хештегам | да (19:00, повтор 2ч; тег не сдавших) | [claimed] |
| Bitrix24 | да (по сотруднику) | внутри Битрикса | да (периодичность+статус) | [claimed] |
| Самопис хештеги | частично (по автору) | из группового чата | лог, контроль «не сдал» слабый | [claimed] |
| НаВстрече/Таймлист | да, по спикерам | — (встречи) | — (не модель сдал/не сдал) | [verified] |

**Инсайт для Коры:** доминирующий паттерн рынка — «бот в личку → сводка в группу». Захват свободного текста прямо из существующего группового чата с авто-атрибуцией почти никто не делает как продукт. Если Кора умеет «забрать из рабочего чата без личек/форм, понять кто что написал, собрать сдал/не сдал» — это дифференциатор. Риск: восприятие «ещё один standup-бот»; снимается тем, что отчёт = узел памяти компании, а не строка таблицы.

## Цена/зрелость
- Pulse bot: базово бесплатно; запуск 2020, статус не подтверждён [verified/inferred-weak].
- НаВстрече: Business ≈20000₽/мес (~50 чел), триал [claimed цена / verified продукт].
- Таймлист: 10ч/4500₽·год … 100ч/42000₽ [verified].
- Shtab: платный SaaS, цены не зафиксированы [claimed]; запуск 2021.
- VK WorkSpace (таск-бот, сравнение): от 259₽/мес·польз [claimed].
