# Meeting Result Page — карточка результата встречи

Страница, на которую попадает хост после того, как AI-пайплайн отработал. URL: `meet.crossmark.ru/meetings/<id>/result`.

## Раскладка (по образцу Zoom Pro / Google Meet с Gemini)

```
┌─────────────────────────────────────────────────────────┐
│ Шапка                                                    │
│ ─ Название встречи                                       │
│ ─ Тип • дата • длительность                              │
│ ─ Список участников                                      │
│ ─ Кнопки: [📋 Копировать ссылку]  [⬇ Скачать запись]      │
│           [🗑 Удалить]                                    │
├─────────────────────────────────────────────────────────┤
│ ▶ Видео-плеер (общая запись)                             │
├─────────────────────────────────────────────────────────┤
```

## Кто видит

- **Хост** — всегда.
- **Гости** — нет в MVP. Если хост хочет поделиться результатом — копирует ссылку и шлёт сам (как и приглашение). Открытая публичная версия страницы — V2-фича.

## Состояния

- **AI ещё не отработал** (`recording_processing` / `transcription_processing` / `ai_processing`) → страница показывает прогресс: «Распознано 7 из 10 дорожек → Склейка → Готовим отчёт». Опрос статуса каждые 5 секунд.
- **AI готов** (`ai_ready`) → полная карточка как выше.
- **AI упал** (`failed`) → состояние «Не удалось обработать встречу. [Повторить попытку]» — действие повторно дёргает пайплайн.

## Что НЕ делаем в MVP

- Комментарии под видео.
- Реакции на саммари.
- «Поделиться в соцсетях».
- Публичный URL для гостей (без аккаунта).
- Редактирование отчёта руками.
- Повторный прогон AI с другим промптом (V2).
