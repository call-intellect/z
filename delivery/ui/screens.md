# Реестр экранов

Подробные wireframe и состояния для каждого экрана. Идентификатор экрана = маршрут.

## Структура файла

Каждый экран:
- **Маршрут** — URL.
- **Цель** — для чего пользователь приходит.
- **Состояния** — empty / loading / error / success / streaming.
- **Действия** — что можно сделать.
- **Доступ** — кто видит.

---

## `/` — Сегодня (default)

**Цель:** быстрый обзор — что произошло, что AI узнал, что ждёт подтверждения.

**Состояния:**
- Empty (новая компания, мало данных): «Тут будет ваше «сегодня», когда накопится первый день данных. Пока — расскажите, что у вас в голове.» + кнопка «Дамп».
- Loading: skeleton-карточки.
- Default: 5 карточек (см. ниже).

**Карточки (mobile vertical):**
1. **Согласованность стратегии** — большой индикатор + дельта.
2. **Что узнали сегодня** — bullet-list 3-5 позиций.
3. **Голос клиентов** — топ боль / просьба за неделю.
4. **Что я переосмыслил ночью** — результаты M-14 + кнопки `подтвердить`/`отклонить`/`подробнее`.
5. **AI ждёт подтверждения** — список candidates от M-26 (никогда не блокирует).

**Действия:**
- Тап на карточку → детальный экран.
- Подтвердить/отклонить candidate → запись в M-26.
- `[⊕ Дамп]` → `/dump`.
- `[💬 Спросить]` → `/chat`.

**Доступ:** все авторизованные пользователи. Содержимое карточек применяет M-20 на каждый элемент.

---

## `/today`, `/week`, `/month`

Аналогично `/`, но с расширенным охватом.

**`/month`** дополнительно содержит:
- Месячный свод (большой блок, AI-сгенерированный).
- Ссылку на «выслать на email».

---

## `/dump` — Свободный дамп

**Цель:** главная точка входа. Расскажи что угодно.

**Состояния:**
- Default: огромный textarea + кнопка голоса.
- Streaming (после отправки): «Записываю...», частями появляется feedback.
- Saved: feedback от AI («Записал. Вижу 2 сигнала: ...»).

**Действия:**
- Ввод текста.
- Запись голоса (push-to-talk + hands-free).
- Прикрепить файл / скриншот.
- Отправить.

**Доступ:** все авторизованные.

---

## `/chat` — Полноэкранный чат

**Цель:** диалог с памятью.

**Состояния:**
- Empty (новая сессия): приветствие + примеры запросов.
- Streaming: текст появляется частями, индикатор «Думаю».
- Done: финальный текст + список источников + uplinking-questions.

**Действия:**
- Ввод текста / голос.
- Открыть конкретный источник inline.
- Открыть полный RawEvent в боковой панели.
- Начать новую сессию.

**Доступ:** все.

---

## `/map` — Смысловая карта

**Цель:** визуализация графа связей.

**Состояния:**
- Loading: skeleton + «Стрйю карту...».
- Default: force-directed layout, до 500 узлов.
- Filtered: после команды через чат.

**Действия:**
- Перетаскивание.
- Зум.
- Клик по узлу → sidebar с детализацией.
- Команда «покажи карту по X» (через чат внизу) → перерисовка.
- Slider time-travel «как было N дней назад».

**Доступ:** все, граф фильтруется по M-20.

---

## `/branches/{branch}` — Ветка

**Цель:** срез по одной ветке компании.

**Состояния:**
- Loading.
- Default: список тем по убыванию веса + детали ветки.

**Действия:**
- Drill-down на тему.
- Команда уточнения через чат.

---

## `/themes/{theme}` — Подробно по теме

**Цель:** всё про конкретную тему.

**Состояния:**
- Loading.
- Default: имя, описание, ветка, сигналы (с пагинацией), связи, версии.

**Действия:**
- Откорректировать описание (через чат-AI).
- Подтвердить/изменить уровень confirmation.
- Перейти к связанным сущностям.

---

## `/decisions`, `/decisions/{id}`

ADR-style лента и детальный просмотр.

---

## `/ideas`, `/risks`, `/goals` — Списки сущностей

Аналогично — список + детали.

`/goals` дополнительно содержит большой блок согласованности стратегии (M-16) с трёхуровневой детализацией.

---

## `/knowledge`, `/knowledge/{slug}` — База знаний

**Цель:** wiki компании.

**Состояния:**
- Главная: оглавление по веткам + поиск через чат.
- Статья: текст + связанные сущности + история.

**Действия:**
- Чтение.
- Корректировка через чат («исправь это в статье»).
- Полный редактор — только в админке.

## Telegram-бот — поток

```
/start
  → "Я — память вашей компании. Пишите всё, что важно. Голосом тоже можно."

любое сообщение
  → если содержит "?" в начале → режим чата
  → иначе → дамп

голос
  → транскрипция → дамп

файл
  → загружается → раз в M-02 → ingest

команды
  /спросить — переключение в чат
  /обещания — список своих обещаний
  /настроение — открыть чек-ин
  /настройки — переход в веб
  /выйти — logout
```

## Состояния, общие для всех экранов

### Loading

Skeleton-плейсхолдеры. Не спиннеры. Подсказка «Минуту…» в правом нижнем углу через 2 секунды.

### Error

Карточка с дружелюбным текстом + кнопкой `Попробовать ещё раз`.

### Empty

Дружелюбный текст + кнопка действия. Никаких «No data found», только «Пока ничего».

### Permission denied (M-20)

«Этот раздел вам пока не виден» — без раскрытия деталей.

### Streaming

Частями появляются токены. Индикатор «...». Без блокировки UI.

## Адаптивность

Все экраны должны работать на ≥ 360 px. Главный приоритет — mobile.

Десктоп — расширение (увеличенные карточки, sidebar появляется на ≥ 1024 px).

---

## Tablet- / desktop-специфичные элементы

- Sidebar справа на `/themes/{id}` с деталями узла графа.
- Multi-column layout на `/today` (3 колонки на ≥ 1280 px).
- **Keyboard shortcuts — опциональное удобство для desktop power-users, НЕ часть основного UX.** Главный способ работы — плавающий значок «Кора-помощник» (виден всегда на любом устройстве) и видимые кнопки «Создать ...». ЦА — не разработчики, шорткаты они не запоминают и не обязаны знать. На мобиле этих сочетаний нет физически.
  - `?` — открыть help.
  - `g+t` → today, `g+w` → week, `g+m` → map, `g+c` → chat.
  - `cmd+k` или `ctrl+k` — открывает то же окно концьержа (= тап по плавающему значку).
  - `j/k` — навигация по списку.

- На «вы».
- Без эмодзи в данных и ответах.
- Без восторженности и канцеляризма.
- Конкретно.
