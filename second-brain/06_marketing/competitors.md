### Российский рынок: **прямых конкурентов нет**

Ближайший — **TEAMLY** (RAG по корпусу), но без атрибуции к конкретному человеку. Детальная разведка → [[competitor-teamly]].

**istok.ai** (непрямой, добавлен 2026-06-11) — document-centric платформа управления знаниями: загрузи документы → семантический поиск → Q&A-чат с цитатами + on-prem/152-ФЗ + смежные модули (Istok Connect git-ревью, Istok Code CLI, API-платформа no-code ботов, HR-скоринг). Юрлицо ООО «ИСТОК» (ОГРН 1267800028011, регистрация **2026**, СПб), продукт в **Beta**, тарифы 0 / 2 490 / 7 990 ₽/мес + Self-hosted 52 000 ₽/год. **ICP смещён к разработчикам** (категории документов architecture/api/runbook/adr, Istok Code). Пересечение с Корой: AI-чат поверх корп-данных, ответы с источниками, on-prem/152-ФЗ. Водораздел: они — **ручная загрузка файлов → RAG**, Кора — **авто-граф из событий**. Зрелость как игрока низкая, но **UX доверия/онбординга зрелее нашего** (честный отказ + «Уверенность 25%» + «Полезно/Не полезно» — у нашего ChatV2 этого нет). Полный teardown + что перенять → [[../../plans/analysis/2026-06-11-istok-ai-competitor-teardown]].

Краткие тезисы по TEAMLY (май 2026):
- Юрлицо ООО «Кьюсофт», основатели Митрофанов (75%) и Чесноков (25%, гендир).
- 2023 → 2025: 265 → 393 млн ₽ выручки, в 2025 ушли в **убыток 39,5 млн ₽** (инвест-фаза).
- 235+ компаний, 35 000+ пользователей. Lamoda, 2ГИС, ОАК, ВкусВилл, KAMAZ, SPLAT, Контур, Dodo.
- **Категориально другой продукт:** PKM/KMS (wiki + LMS + задачи), где люди **руками вписывают** знания. Кора — память компании, **автоматически собирает** граф из событий + Employee Clones. См. антинарратив в [[positioning]]: «НЕ против Notion/TEAMLY — мы memory layer для AI-агентов».
- Пересечение: AI-чат поверх корп.данных, IT-бюджет крупного RU-enterprise, требования compliance (реестр Минцифры, on-prem).
- Сильное: реестр ПО, on-prem, RAG, миграция с Notion «за дни», 29 публичных кейсов.
- Слабое: слабый таск-трекер, UX редактора отстаёт от Notion, долгая поддержка, нет внешних инвестиций.

## Обновление 2026-06-11 — категория «память компании» перестала быть свободной

> Свежая разведка (17 суб-агентов, 8 сегментов) для разбора рва. Полный анализ — [[../../plans/analysis/2026-06-11-kora-moat-and-competitive-defensibility]]. Главный сдвиг: нарратив «авто-память/граф из встреч» в 2026 заняли все — и глобально, и в РФ.

**РФ — нарратив уже занят (угроза `high`):**
- **НаВстрече** — позиционирует себя «системой организационной памяти» + AI-чат по всей истории + «Радар сигналов» (риски/конфликты/возможности) + on-prem + 152-ФЗ. Заняли территорию Коры по нарративу; архитектура — транскрипт-ретрив, не event-граф.
- **Таймлист (1С:Совещание)** — манифест «Вторая память — тренд 2026»; **сильнее Коры по регуляторике:** реестр ПО №20728, канал 1С, автономный on-prem **без внешних LLM** (Кора ходит во внешний роутер). ASR ~96.5%.
- **МТС Линк** (`medium`) — >7,6 млн встреч/2025, соединяет встречи+чаты+знания в один ассистент (граф = фича, не продукт). Сбер GigaChat Enterprise (публ. 03.03.2026), Яндекс Нейроэксперт (ручная загрузка), Битрикс CoPilot (владеет потоком событий МСБ) — опасны дистрибуцией.

**Глобал meeting→граф (в РФ не зайдут, но задают рынок):**
- **Otter.ai** — «longitudinal knowledge graph» анонсирован 28.04.2026 (авто-граф из транскриптов, связь решения↔люди↔время, MCP) — буквально тезис Коры на 35 млн юзеров.
- **Gong** — «Revenue Graph» = living memory из событий + агенты (зрелейшая реализация «графа из событий», ARR >$500M).
- **Granola** — $125M Series C, оценка **$1.5B**, ARR +400%; но **сознательно НЕ строит граф** (integration-first/MCP) → окно для Коры.

**Глобал knowledge (мейнстрим авто-графа):** Glean ($7.2B, ARR $300M, Enterprise Graph), **Atlassian Rovo** (Teamwork Graph 150 млрд связей, **узлы «РЕШЕНИЯ»**), Microsoft Copilot (Work IQ), Notion AI ($11B). Идея «авто-граф знаний» = консенсус 2025-2026.

**Memory-layer (инфра, НЕ конкуренты, но угроза-субстрат):** Zep/**Graphiti** (open-source bitemporal-граф, местами зрелее Кориного), Mem0 ($24M), Cognee ($7.5M). **RU-интегратор может собрать «память компании» на форке Graphiti+GigaAM за недели** — это biggest risk Коры.

**Company-brain плеи (прямые категорийные, YC-волна):** YC объявил «company brain» missing primitive → **Hyper** («self-driving company brain», паразитирует на чужих транскриптах), **Continuum** (YC W26, $5M, memory-as-protocol через MCP — строит roadmap-ров Коры), Cerenovus, Convictional, Bond/Donna (AI Chief of Staff).

**Ниша 2 (двойники) — свежее:** Viven ($35M Khosla, per-employee), Interloom ($16.5M, **авто-граф из событий — архитектурно ближе всех**, Commerzbank). Уникальность Коры: **ролевой клон должности** (не персональный) + push-сбор со встреч.

**MENA / арабский рынок:** бежит в другую сторону — арабский ASR/LLM (Intella $12.5M, Munsit/CNTXT, WideBot, ALLAM) + CX/контакт-центры (Lucidya $30M, DXwand). Авто-памяти компании из событий **нет ни у кого**. Их ров — арабский язык + господдержка (зеркало 152-ФЗ Коры); на РФ не выйдут.
