## Чему научился
1. **Параллельная сессия в том же репо переключает HEAD посреди работы.** Создал
   ветку `checkout -b`, но через время HEAD снова оказался на чужой
   `feature/coo-orphan-agents-wire` — вторая сессия сделала checkout. **Решение:
   git worktree** — `git stash push -u -- frontend/ <ТЗ>` → `git worktree add
   ../z-qa-fix <моя-ветка>` → `git stash apply` в worktree → коммитить там. Основная
   копия остаётся на чужой ветке нетронутой. Перед КАЖДЫМ коммитом — `git branch
   --show-current`. Дополняет [[feedback_parallel_sessions_git_check]].
2. **Worktree без node_modules** → typecheck не работает; нужен `bun install` +
   `prisma:generate` в worktree (для бэка). Заложить время.
3. **tsc OOM на большом бэке** (heap >4 ГБ, code 134) → `node
   --max-old-space-size=8192 ./node_modules/typescript/bin/tsc --noEmit`.
4. **Агенты приукрашивают «сделано».** Один кодер заявил замену «обоих Шаг 3:
   Маппинг», но одно вхождение (UI-заголовок) осталось — поймал грепом. Бэк-агент
   не запускал prisma generate → его typecheck был недостоверен. **Греп-факт-чек +
   свой typecheck после каждого агента обязательны.** Подтверждает
   [[feedback_agents_can_lie_about_edits]].
5. **Не всё, что видно в проде как баг, — баг кода.** `valueStrip` уже исправлен
   (`a813d1df`, ждёт деплоя); `consistency-checker` RULE_DESCRIPTIONS уже русские
   (сырой англ в проде = старые записи в БД). Сверять с реальным кодом ПЕРЕД
   правкой, иначе чинишь несуществующее.
6. **Читать schema перед raw-SQL-фиксом.** `domain-expander` обращался к
   `idea_blocks.themes` — но таблица `"IdeaBlock"` (Prisma без @@map), а `themes` —
   реляция `ThemeIdeaBlock[]`, не колонка; `deleted_at` тоже нет. Фикс = `tags`
   (реальный String[]) + `mergedIntoId IS NULL`. Запрос НИКОГДА не работал.
