# Главная страница КОРА — 12 инструментов + editorial-лендинг

## Что было поставлено

1. Доработать светлый HTML-лендинг (`second-brain/06_marketing/landings/2026-05-24-landing-light.html`) — убрать «детский» вид (клетка-фон, разноцветные стикеры, пластиковые булавки, скотчи, рукописные приписки, красные нити), сделать editorial-люкс.
2. На основе этого лендинга сделать новую публичную главную `/` — но с цветовой схемой текущей dark+mint темы. 12 карточек разнести по 4 секциям: встречи → задачи → AI-директор → память.
3. Ребренд Z → КОРА (кириллицей), CTA на реальные `/signup` и `/login`, упоминание вечерних отчётов сотрудников и переписок, трекер позиционировать как «привычный для команды».
4. Подкрутить шрифты (italic-акценты, веса заголовков).

## Как решал

### Editorial-черновик лендинга
- Переписал весь `<style>` блок одним Edit-вызовом. Фон без клетки (только мягкие световые пятна), тонкое бумажное зерно через SVG-noise.
- Карточки в одной кремовой тональной семье (5 оттенков) с hairline-border (rgba 0.10-0.18).
- Пин = плоская латунная точка 6×6, без 3D-эффекта. Скотчи и `.scribble` спрятаны через `display:none` (HTML не тронут, легко вернуть).
- Нити в SVG: переопределил презентационные атрибуты SVG (`stroke="#8C3F3F"` в HTML → `stroke: var(--brass) opacity 0.28` в CSS). CSS-правила побеждают presentation-атрибуты SVG без `!important`.
- Повороты карточек: вместо правки 12 inline `--rot` значений в HTML ввёл `transform: rotate(calc(var(--rot, 0deg) * 0.18))` — масштабирует всё в 18% автоматически.

### Главная React-страница
- Полностью переписал `frontend/app/HomeClient.tsx` (156 → 376 строк): 4 секции + 2 акцентных моста + helper-компоненты `<Section>` и `<Card>` внизу файла.
- Использовал существующие токены (`bg-bg-base`, `text-accent`, `bg-bg-card/60`, `backdrop-blur-glass`) и motion-пресеты (`fadeIn`, `slideUp`). `whileInView` с margin для секций ниже фолда.
- AI-директор — выделенный полноширинный gradient-блок (`from-accent-muted via-bg-card to-bg-card`) с двумя bg-blur пятнами.
- Bridge-секция — большой H2 с центрированными tracking-хайрлайнами по бокам.

### Fix «синего экрана»
- Пользователь сообщил: страница — пустой синий фон.
- Грепнул HTML curl-ом: SSR возвращает только `<div className="min-h-screen bg-bg-base" />` — моя guard-заглушка.
- Проверил бэк: `curl http://localhost:3000/api/v1/auth/me` → HTTP 000, 1.7s timeout (бэк не запущен).
- Прочитал `AuthProvider`: стартует с `isLoading: true`, дёргает `accountsApi.me()` — при недоступном бэке `isLoading` зависает.
- Старый guard `if (isLoading || user) return <заглушка />` бесконечно показывал заглушку.
- Fix: `if (user) return <заглушка />` — лендинг публичный, ждать auth не нужно. Заглушка только под `user` (момент до `router.replace`).

## Чему научился

1. **Публичная страница не должна ждать auth.** Guard `if (isLoading || user)` для public landing — баг. При недоступном бэке `isLoading` зависает → бесконечный «синий экран». Правильно: `if (user)` только. `isLoading` нужен только для приватных страниц.
2. **Кириллица требует меньше letter-spacing**, чем латиница. «КОРА» с tracking 0.18em смотрится растянуто; 0.14em — нормально. Буквы К, О, Р, А — широкие.
3. **Italic + accent + font-medium на span внутри large H** — устоявшийся editorial pattern. Использован и в HTML-лендинге, и в новой главной. Курсив снижает оптическую тяжесть → `font-medium` на курсиве оптически = `font-semibold` обычным.
4. **CSS-rotation через CSS-variable + calc()** — элегантный способ массово править inline-rotations в HTML без правки HTML. `transform: rotate(calc(var(--rot, 0deg) * 0.18))`. Тот же приём подходит для любых других inline-стилей где нужно «scale» всё разом.
5. **CSS-правила побеждают presentation-атрибуты SVG** без `!important` — можно переопределять `stroke`/`fill`/`opacity` SVG-элементов через обычный CSS.
6. **vexp в этой сессии не был доступен** — fallback на Glob/Grep сработал, но для крупных рефакторингов фронтенда vexp удобнее.
