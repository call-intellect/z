## Чему научился
- **Полный backend `tsc --noEmit` OOM-ит на дефолтном heap** — нужно `NODE_OPTIONS=--max-old-space-size=8192` (известная грабля проекта). Без этого SIGABRT, не «ошибки типов».
- **Новое обязательное поле в общем DTO ломает чужие тест-фикстуры** — `goalContributionNet` (required) в `WeeklyPersonRowApi/Ui` повалил `weekly-per-person.test.ts` и `mobile/exec/deals-rows.test.ts` (строят строку вручную). Кодер фазы их не видел (вне scope) — поймала независимая приёмка (полный typecheck), починил `goalContributionNet: null`. Урок: при добавлении required-поля в широко используемый DTO — грепать все конструкторы фикстур.
- **`WeeklyPerPersonService.compute` хардкодил `weekEnd=weekStart+6`** — для пн–пт пришлось вводить опц. параметр окна и включать его в `cacheKey`, иначе коллизия кэша пн–пт vs пн–вс. Граничный контракт «не сломать страницу операций» = дефолт сохраняет старое поведение.
- **`PersonGoalContribution.weekStart` — DateTime (UTC-полночь пн)**, а per-person оперирует строкой 'YYYY-MM-DD'. Матч через `new Date(weekStart+'T00:00:00.000Z')` — точное равенство, иначе тихий промах в null. Проверил `computeWeekStart` = `Date.UTC(y,m,d)` понедельника.
- **clamp клиентской оси из дневных вердиктов** — `hasNegativeClientSignal = days.some(clients==='risk')` транзитивно покрывает «severity high/critical за неделю» (дневной clamp уже форсит clients=risk), без лишнего запроса и без инжекта CustomerRisk/BlockerSynthesis — минимизировало mock-поверхность сервиса (конструктор += только `WeeklyPerPersonService`).
- **`useSearchParams` в App Router даёт CSR-деопт/Suspense-требование** — для чтения `?rhythm=` взял SSR-safe `useEffect`+`window.location.search`, билд чист.
- **Параллелизация непересекающихся фаз** ускорила: Ф4(backend)∥Ф5a(frontend), Ф5b-backend∥Ф5a — disjoint файлы, приёмка независимая, без worktree (коммичу только я). Ф5b-frontend и Ф5c — последовательно (оба правят `WeekCompanyHero`).
