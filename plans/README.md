# plans/ — технические планы функций

Один план = одна функция.

## Структура

```
plans/
  analysis/   — анализ фичи: суть, цель, открытые вопросы
  tz/         — техническое задание: scope, изменения, DoD
  archive/    — завершённые или отменённые планы
  README.md   — этот файл
```

## Жизненный цикл

1. **Анализ** → `analysis/YYYY-MM-DD-название.md`
2. **ТЗ** → `tz/YYYY-MM-DD-название-tz.md`
3. **Реализация** → агент отмечает фазы `[ ]` → `[x]`
4. **Завершение** → файлы переносятся в `archive/`

## Правила

- Имя: `YYYY-MM-DD-название.md` (kebab-case).
- План делится на фазы. У каждой статус `[ ]` или `[x]`.
- В конце ТЗ — итоговый блок: реализован целиком или нет, что осталось.
- **Любой агент обязан актуализировать план** после каждой сессии.
- Шаблоны: `analysis/_template.md`, `tz/_template.md`.
