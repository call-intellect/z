# РФ — цели / OKR / идеи (11 игроков)

**Сквозной вывод `[verified, triangulated]`:** в РФ ровно **одна** зрелая визуальная карта целей с богатым цветом — **ELMA365 «Карты целей»** (mindmap). Остальные — список+KR (Я.Трекер, Weeek, Аспро), mind-map без OKR-семантики (Goalton), KPI-приложение (Битрикс24). **Связку «идеи↔цели в одном визуальном поле не делает НИКТО** — белое пятно рынка РФ.

## ELMA365 — «Карты целей» (🇷🇺 ЭТАЛОН)
- Раздел Показатели→Цели: цветные блоки целей соединены линиями в дерево, mind-map-канва, правый клик = создать цель/группу/мероприятие/SMART-задачу, счётчик прогресса прямо на узле. `[verified]` elma-3-4.elma365.ru/KB/help/KPI/.../User_UP_aim_maps_index.html · 2026-06-20
- Тип: **mindmap — диаграмма связей** (свободная раскладка, ручное позиционирование). `[verified]`
- **Богатейшее цветовое кодирование (один узел = 4 измерения)**: рамка голубая=цель / жёлтая=группа; зелёный=в работе, зачёркнут=завершена, курсив=низкий приоритет, красная стрелка=высокий; кружок-светофор справа = ниже/в пределах/выше плана KPI. `[verified]`

## Яндекс Трекер — «Цели» (🇷🇺, список, не карта)
- Цели с фев 2025, подцели через «Создать связь», прогресс через KR; **сертифицирован по OKR** (апр 2025). `[verified]` yandex.ru/support/tracker/ru/goals · computerra.ru/317651 · 2026-06-20
- **Визуальной карты/графа НЕТ** — страница-список. `[verified]`

## Goalton (🇷🇺, mind-map есть, OKR-семантики нет)
- mind-map + outliner, режим фокуса, % выполнения при наведении; **цвет узла задаёт пользователь** (декор, не статус). `[verified]` lifehacker.ru/goalton · 2026-06-20

## Weeek OKR (🇷🇺, список+KR)
- Цепочка стратег. цели → портфели → проекты → задачи; канбан/календарь, **графовой карты целей нет**. `[verified/inferred]` weeek.net/reestr · 2026-06-20

## Битрикс24 (🇷🇺, KPI, не дерево целей)
- «Воронка целей» = воронка CRM; полноценное управление целями — сторонние приложения (KPI-шкала, геймификация), графа целей нет. `[verified]` habr.com/.../890712 · bitrix24.ru/apps/app/apikit.kpi · 2026-06-20

## Платрум (🇷🇺, OKR + ОТДЕЛЬНЫЙ модуль идей)
- OKR-метод, дашборды, % в таблице; есть модуль «Управление идеями» (формирование/статус/рейтинг), но **модуль идей и модуль целей раздельны, связь идея→цель не описана**. `[verified]` picktech.ru/product/platrum · 2026-06-20. Цена от 1425 ₽/польз/мес, есть free.

## Что перенять (вход в синтез)
1. Карта целей (DAG из `parentGoalId`+`horizon`, `isPrimary`=корень) — **прямое преимущество**: у Я.Трекера/Weeek/Платрум только списки.
2. **Цветовая легенда ELMA365** как образец (4 канала на узле: тип-рамка / статус-цвет / приоритет MoSCoW / KR-светофор) — у Z все 4 данных уже есть; парные токены вместо hex.
3. **Единая карта «идеи+цели» — белое пятно всего рынка РФ** (ни ELMA, ни Платрум, ни «4И» не показывают идею и цель в одном поле).
4. **Прогресс прямо на узле** (есть у ELMA/Goalton/Платрум — значит обязателен): бейдж «KR N из M» + кольцо.
