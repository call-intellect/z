# STRUCTURE RULES

## Структура папок

```
second-brain/
├── index.md              ← единственная точка входа
├── 00_system/            ← протоколы и правила (этот уровень)
├── 01_projects/          ← заметки по фичам и задачам
├── 02_architecture/      ← архитектурные решения (ADR)
├── 03_processes/         ← процессы и регламенты
├── 04_не-сделано/        ← реестр отложенного и пробелов
├── 05_история/           ← рефлексия после push
├── 06_marketing/         ← позиционирование и messaging
└── 13_glossary/          ← глоссарий терминов
```

## Именование файлов
- Протоколы: `UPPER_CASE.md`
- Заметки: `kebab-case.md`
- ADR: `ADR-001-название.md`
- Рефлексия: `YYYY-MM-DD-краткое-название.md`

## Правила
- Один файл = одна тема
- Файл без ссылки в index.md не существует
- Не создавать вложенность глубже 2 уровней
