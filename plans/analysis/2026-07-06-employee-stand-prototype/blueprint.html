Стенд сотрудника — что делаем и как это будет выглядеть

Пересобираем стенд сотрудника по образцу того, как переделали дашборд руководителя. Основано на исследовании 5 персон. Владелец читает, одобряет — потом ТЗ.

● status: draft — ждёт твоего одобрения → Открыть живой прототип

1Что есть сейчас

Свой стенд у сотрудника есть (директорский не показывают — редиректит на /me), но собран неудобно.

  • Вход открывается на журнал встреч (/meetings), а не на «мой день».
  • «Что делать» размазано по 5 экранам: Обзор · Твой день · Мои дела · Требует вас · Чек-ин.
  • Дефолтная вкладка «Обзор» — HR-профиль (карта должности, польза, благодарности), а не рабочая повестка.
  • Настоящий «Твой день» есть, но спрятан в под-роут; клонов в меню нет.

2Что делаем

Один рабочий экран «Сегодня» на входе — за 30 секунд отвечает «что мне сделать и кого не подвесить». В том же визуальном языке, что директорский дашборд (тёмное стекло + мятный акцент, обложка дня с осями-статусом).

0

Строка «Спросить Кору» прибита сверху — ответ с цитатами-источниками, на всех экранах.

1

«Ждут ответа / ты обещал» — короткая очередь, просрочка красным. Общая боль №1 у всех пяти.

2

Мои задачи на сегодня — чекбокс закрыть на месте; авто из встреч помечены молнией + ссылкой на источник; крупная «+ добавить» (голос/мессенджер).

3

Один адаптивный ролевой блок — наполняется по данным: продажи → клиенты; продукт → блокеры; маркетинг → «тебя касается»; админ → чек-лист; инженер → «новое из встреч».

4

Встречи сегодня компактно + вечерний хвост (перенести на завтра, авто-чек-ин из закрытых задач).

HR-профиль, метрики вклада, признание и директорская аналитика — уходят с глаз (под аватар / за клик).

4Ритм дня

☀ Утро — сборка

Экран сам собирает картину: что горит + обещания с просрочкой + авто-задачи со вчерашних встреч + «тебя коснулось решение». То же — в утренний бриф в Telegram.

◑ День — на ходу

Скорость ввода/закрытия: «+добавить» голосом, чекбокс на месте, «Спросить: что по клиенту X?», после встречи «шаг + напоминание». Нуджи приглушены.

☾ Вечер — закрытие

«Перенести на завтра». Чек-ин план↔факт собирается сам из закрытых задач. Мягкий дайджест вклада — для кого важно.

5Показываем / прячем / убираем

Показываем

первый экран, каждый день
  • Очередь «ждут / обещал»
  • Задачи + чекбокс + источник
  • «+ добавить»
  • Строка «Спросить»
  • Ролевой блок
  • Встречи сегодня

Прячем за клик

не на глаза, не удаляем
  • Память / реестры → справка через «Спросить»
  • Клоны → «Спросить клон»
  • Задачи-доска
  • Встречи-журнал

Убираем в профиль

под аватар, вне навигации
  • Карта должности + %
  • «Моя польза за неделю»
  • Благодарности, «чем помогаю»
  • Пульс / настроение
  • Баннеры «заполни профиль»

6Развилки — нужно твоё решение

Каждая с моей рекомендацией. Одобришь — идём в ТЗ.

1. Ролевой блок — по данным, а не новые роли?
Рекомендую: один слот, наполнение по признакам данных (клиенты/Битрикс → клиентский; блокеры → продуктовый; входящие решения → «тебя касается») + ручной выбор. MVP — эвристика.
2. Вклад/признание — куда (Марина хочет, Костя против)?
Рекомендую: по умолчанию НЕ на первом экране, включаемый блок + вечерний дайджест; для нетехнических развёрнут, для инженеров свёрнут; тумблер в профиле.
3. Тихий режим нуджей — один тумблер?
Рекомендую: глобальный тумблер с белым списком «тебя реально ждёт человек» (обещания/прямые вопросы проходят, авто-нуджи глушатся).
4. Два пресета плотности — простой vs плотный?
Рекомендую: да. Простой = 3 кнопки, крупные чекбоксы; плотный = ролевой блок, Cmd+K, статусы. Авто по роли + ручное переключение.
5. Ввод голосом / из мессенджера — насколько глубоко?
Рекомендую: MVP — inline «+добавить» + голос; следом приём задач из Telegram/WhatsApp/Slack как источник.
6. Чек-ин — оставлять ручным экраном?
Рекомендую: убрать как отдельный маршрут, собирать план↔факт авто из закрытых задач + опц. строчка вечером.
7. Заказы-чек-лист (Ирина) — спецсущность?
Рекомендую: не спецсущность, а тип личной задачи «список-чеклист» со статусом «уже сделано».
8. Клоны в навигации — куда вернуть?
Рекомендую: «Спросить клон должности» внутри «Спросить».

7Границы: что переиспользуем, что новое

  • ✅ Переиспользуем: содержимое /me/daily-brief → становится первым экраном; /me/inbox, /actions, чек-ин, «Спросить», авто-задачи из встреч. Это консолидация, а не постройка с нуля.
  • 🆕 Новое: единый экран «Сегодня» как дефолтный роут (сменить старт с /meetings); адаптивный ролевой слот; глобальный тихий режим; простой пресет.
  • 🚫 Не делаем: директорские виджеты сотруднику; новый LLM-агент; дефолт-OFF флаги (Ship-On).
