# Пробел во встречах: ссылка-приглашение во время встречи + возврат организатора

> Источник запроса — владелец (2026-06-06): «Создал встречу, перешёл в неё. Внутри нужно кого-то ещё пригласить — а ссылки нигде нет. Вернулся на платформу — встреча идёт, аналитика, но переслать ссылку/пригласить нечем. Случайно нажал крестик, вышел — люди остались, а я, организатор, обратно попасть не могу.»
> Метод: живой прогон (Playwright, прод) + чтение кода (frontend + backend) двумя агентами.

## 3. Суть пробела (3 дыры)

1. **Нет платформенного доступа к идущей встрече.** Карточка/деталь/список не дают «Войти» и «Скопировать ссылку» для `scheduled/active` — только «результат» (аналитику). Ссылка `/m/{id}` известна клиенту, но нигде не предложена.
2. **Хост не может вернуться после выхода.** Бэкенд rejoin умеет, но фронт после `onLeave` показывает пустой скелет (флаг `autoJoinAttempted`), и нет кнопки «Вернуться»/«Войти снова». У хоста к тому же нет «Выйти» (только «Завершить» = конец для всех), поэтому «крестик» вкладки = висящая active-встреча без пути назад.
3. **В комнате «Ссылка» без фидбэка.** Кнопка есть, но при клике нет тоста и clipboard может упасть (`NotAllowedError`) — пользователь думает «ссылки нет».

## 4. Решение — доказательство выбора (A vs B)

| Критерий | A. Фронт: предложить `/m/{id}` и rejoin везде (карточка/деталь/лобби/комната) | B. Бэк: новый share-токен + эндпоинт `GET /invite-link` + share-страница |
|---|---|---|
| Закрывает «переслать ссылку» | ✓ (копия `/m/{id}`) | ✓ |
| Закрывает «вернуться» | ✓ (join уже работает) | частично (всё равно нужен фронт) |
| Изменения в бэке/схеме | нет (для ядра) | да (токен, эндпоинт, миграция) |
| Безопасность host-ссылки | ок (вход хоста — по cookie, не по секрету в URL) | избыточно |
| Когда оправдан | сейчас | если нужны **отзываемые per-guest** ссылки (вне запроса) |

**Выбор — A.** Challenge-loop: (1) корень — «нет аффорданса войти/переслать у существующей встречи» → добавляем его, переиспользуя готовые join + детерминированную ссылку; (2) эффективнее — без новых эндпоинтов/миграций для ядра; (3) без кода ради кода — никаких новых токенов (host-вход не по секрету). Per-guest отзываемые ссылки и «пригласить по email/Telegram во время встречи» — отдельно (нужен бэкенд-эндпоинт), это **vNext / опциональная фаза**, т.к. заявленную потребность («скопировать и отправить ссылку») полностью закрывает копи-линк.
