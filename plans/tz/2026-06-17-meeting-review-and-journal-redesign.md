# Редизайн просмотра встречи (единое окно, без модалок) + журнал встреч

## Цель
Переделать пост-встречные экраны видеовстреч так, чтобы:
1. **Экран просмотра встречи** (`/meetings/[id]/result`) был «единым окном без всплывающих»: видео — компактный закреплённый плеер (не на весь экран), отчёт открывается **прямо на странице во всю ширину** (никаких модалок с внутренним скроллом), список отчётов — отдельным переключателем слева, правая колонка AI-чата — **сворачиваемая** (даёт отчёту всю ширину).
2. **Журнал встреч** (`/meetings`) перестал «прыгать» и читался: статус — словом-чипом (а не безымянной точкой), кнопка «Удалить» — **видна на десктопе без наведения**.

## Зачем (болезненное состояние, со слов владельца)
- «Видео открывается на весь экран, огромное; отчёт где-то внизу, надо перекручивать» → плеер `aspect-video w-full` занимает всю ширину колонки и сталкивает контент вниз.
- «Отчёты открываются всплывающим окном в узком окне — супер неудобно» → отчёт рендерится в `Modal` (`max-w-3xl`) с внутренним скроллом `max-h-[60vh]`.
- «Лента готовых встреч выглядит коряво» → строки журнала скачут по высоте, статус — крошечная цветная точка без подписи.
- «Кнопка Удалить — не вижу её» → кнопка есть, но на десктопе скрыта до наведения (`md:opacity-0`).

Всё — **frontend-only**. Backend (включая `DELETE /api/v1/meetings/:id`) уже готов, не трогаем.

## Доказательство выбора (раскладка экрана результата)
Проход A: единая страница, вкладки-режимы, отчёт inline, видео sticky-компакт (текущая структура, доведённая). Проход B (иная ось — модель навигации): отдельные роуты `/meetings/[id]/recording` и `/meetings/[id]/report`.

| Критерий (ограничение фичи) | A: единое окно | B: отдельные роуты |
|---|---|---|
| «Никаких всплывающих окон» | да (inline) | да |
| Отчёт во всю ширину | да | да |
| Смотреть видео и читать отчёт одновременно | да (sticky-плеер) | нет |
| Стоимость (загрузка данных встречи) | один набор SWR-хуков | дублируется на 2 роута |
| Глубокая ссылка на отчёт | `?tab=reports&report=<id>` | естественно роутом |
| Объём правки | средний (рефактор одной страницы) | высокий (новый layout + дубли) |

→ **A** (Р1). Challenge-loop: решает корень (модалка + гигантское видео), не плодит дубли загрузки (не код ради кода), глубокая ссылка добирается параметром URL без отдельного роута.

## Scope

- Изменения в `OverviewTab`/«Главы»/«Транскрипт»/«Чат комнаты»/«Задачи» — структуру не трогаем (кроме URL-sync вкладок, Ф5).
